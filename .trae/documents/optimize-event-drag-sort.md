# Event 拖拽排序功能优化计划

## 现状分析

当前实现使用原生 HTML5 拖放 API，存在以下问题：

1. **用户体验问题**
    - 拖拽图标只有 hover 时才显示，不够明显
    - 拖拽过程中缺少视觉反馈
    - 没有拖拽动画效果
    - 拖拽指示器（橙色线条）样式简单，不够醒目

2. **功能问题**
    - 排序算法简单，只是加减 sortId，可能导致冲突
    - 拖拽时元素位置变化不流畅
    - 没有拖拽时的占位效果

3. **代码问题**
    - 直接操作 DOM，不够 Vue 化
    - 缺少 TypeScript 类型完善

## 优化方案

### 1. 优化拖拽触发器

- 将拖拽图标从绝对定位改为固定可见
- 增大拖拽图标尺寸，提高可点击区域
- 添加光标样式提示
- 优化 hover 效果

### 2. 改进视觉反馈

- 拖拽时给被拖拽元素添加半透明和缩放效果
- 添加拖拽占位符，显示原位置的空白区域
- 优化拖拽指示器（橙色线条）的样式，使其更醒目
- 添加拖拽过程中的动画过渡

### 3. 完善排序算法

- 实现更健壮的排序逻辑，避免 sortId 冲突
- 确保排序后所有事件的 sortId 是连续的
- 优化本地状态更新逻辑

### 4. 优化拖拽交互

- 改进 `use-event-dragger.ts` 的实现
- 添加更好的拖拽边界检测
- 优化拖拽开始和结束的状态管理

### 5. 增强样式和动画

- 添加平滑的 CSS 过渡动画
- 优化拖拽过程中的视觉效果
- 确保移动端体验良好

## 技术细节

### 排序算法改进

当前问题：简单的 sortId 加减可能导致冲突

改进方案：

1. 获取所有事件并按当前 sortId 排序
2. 找到被拖拽事件和目标事件的位置
3. 重新计算并分配所有事件的连续 sortId
4. 批量更新本地状态和后端

### 视觉反馈改进

1. 拖拽开始时：
    - 被拖拽元素：半透明 + 轻微缩放
    - 原位置：显示占位符

2. 拖拽过程中：
    - 优化拖拽指示器（更粗、更明显的颜色）
    - 目标位置高亮

3. 拖拽结束时：
    - 平滑过渡到新位置
    - 移除所有临时样式
