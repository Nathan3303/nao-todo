# 检查事项快速筛选功能实现计划

## 需求分析

用户需要在 TaskDetails 组件中实现检查事项的快速筛选功能：

- 当待办任务检查事项列表过长时，能够快速找到某个或某些项
- 支持按关键词筛选，判定是否包含相关字眼的检查事项

## 技术方案

### 1. 修改文件

**文件路径**: `/home/nathan/Development/nao-todo/apps/web/src/layouts/tasks/task-details/main/events.vue`

### 2. 实现方案

在检查事项列表上方添加搜索输入框：

- 使用 `nue-input` 组件作为搜索框
- 添加 `searchQuery` 响应式状态存储搜索关键词
- 创建 `filteredEvents` 计算属性，根据搜索关键词筛选检查事项
- 支持模糊匹配（不区分大小写）
- 当搜索框为空时，显示所有检查事项

### 3. 修改内容

1. 添加搜索输入框组件
2. 添加搜索状态和筛选逻辑
3. 更新模板渲染过滤后的检查事项列表

### 4. UI/UX 考虑

- 搜索框位于检查事项列表顶部
- 搜索框宽度占满容器
- 支持实时搜索（输入即过滤）
- 保持与现有组件风格一致

- 检查事项列表实时显示匹配的项
