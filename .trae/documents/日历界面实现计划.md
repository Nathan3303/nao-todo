# 日历界面实现计划

## 1. 概述

实现一个月视图的日历界面，用于展示和管理任务。参考项目现有架构和提供的设计图。

## 2. 技术架构

### 2.1 文件结构

```
apps/web/src/views/index/calendar/
├── index.vue                 # 日历主页面
├── calendar-view.ts          # 日历视图的逻辑 hook
├── routes.ts                 # 路由配置（已有）
└── components/
    ├── calendar-header/      # 日历头部（月份导航、视图切换）
    │   ├── index.ts
    │   └── index.vue
    ├── calendar-grid/        # 日历网格（月视图）
    │   ├── index.ts
    │   ├── index.vue
    │   └── types.ts
    ├── calendar-day/         # 单天单元格
    │   ├── index.ts
    │   └── index.vue
    └── calendar-task/        # 日历任务卡片
        ├── index.ts
        └── index.vue
```

## 3. 核心功能实现

### 3.1 日历视图 Hook (calendar-view.ts)

- 提供日历视图的上下文（类似 tasks-view.ts）
- 集成 TaskUseCase、ProjectUseCase、TagUseCase
- 提供日期导航状态管理
- 按日期筛选和加载任务

### 3.2 日历头部组件 (calendar-header)

- 显示当前月份和年份
- 上一月/下一月导航按钮
- 今天按钮
- 视图切换（月视图，预留其他视图扩展）

### 3.3 日历网格组件 (calendar-grid)

- 生成月历的日期网格（6行×7列）
- 星期表头（周一至周日）
- 处理月份边界日期的显示（上月/下月日期）

### 3.4 日历天单元格 (calendar-day)

- 显示日期数字
- 突出显示今天
- 显示该日期的任务列表
- 支持点击创建新任务

### 3.5 日历任务卡片 (calendar-task)

- 显示任务名称
- 根据项目/标签显示颜色标识
- 显示任务时间（如有）
- 点击打开任务详情
