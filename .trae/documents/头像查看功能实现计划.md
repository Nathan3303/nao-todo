## 技术细节

### 头像 URL 处理

后端返回的头像 URL 可能是相对路径（如 `/uploads/avatar/xxx.jpg`），需要添加 `http://localhost:3302` 前缀才能正确访问。

处理逻辑：

```typescript
const getFullAvatarUrl = (url: string) => {
    if (!url) return ''
    if (url.startsWith('http://') || url.startsWith('https://')) {
        return url
    }
    return `http://localhost:3302${url}`
}
```
