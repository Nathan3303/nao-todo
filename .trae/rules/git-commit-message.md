在此处编写规则，自定义 AI 生成提交信息的风格。

## 格式

feat|fix|chore|change(功能点或变更点): 描述变更

变更点：
- 时间选择面板不会显示 NaN 字样
- 日期选择面板会显示当前选中的日期
- 日期时间选择面板会显示当前选中的日期时间

其他（可选）:
- 更新 xxx 包版本，从 x.x.x(需要提出旧版本号) 到 y.y.y
- 调整了 xxx 配置文件，以适应 xxx 功能

## 注意事项
- `feat` 表示新增功能点
- `fix` 表示修复 bug
- `chore` 表示构建/部署/配置/其他变更
- `change` 表示变更，除新增/修复/构建/部署/配置/其他以外的变更
- 若某个其他描述包含在变更点列表中某项中，比如变更点含有“修改了配置文件“，而描述出现修改了xxx配置文件，则不需要重复描述。
- 尽量将变更写在变更点列表中，而不是其他描述中。通常项目配置文件修改会写在其他描述中。
