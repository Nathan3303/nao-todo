# 优先级决策框架

顺序：**战略筛子 → MoSCoW → RICE → Kano**

## 战略筛子（任一否决即淘汰/推迟）

1. 是否直接贡献本季北极星/OKR？（否 → 淘汰）
2. 是否构建竞品难复制的壁垒？（1–5 分，<3 慎重）
3. 不做是否 3 个月内造成用户流失/营收下降？（是 → Must）

## MoSCoW

- **Must** 必须做 / **Should** 应该做 / **Could** 可以做 / **Won't** 不会做

## RICE

| 维度 | 说明 |
| :--- | :--- |
| Reach | 影响用户数/交易量 |
| Impact | 影响程度（3/2/1/0.5） |
| Confidence | 信心度（100%/80%/50%） |
| Effort | 总人月/人天 |

**公式**：RICE = (Reach × Impact × Confidence) / Effort

## Kano

体验类需求用 Kano 判断是否小成本加入。

## 输出要求

PRD 必带：战略筛子结论 + RICE 打分表（可追溯）。
