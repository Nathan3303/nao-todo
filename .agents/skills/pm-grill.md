# grill-me 澄清清单

需求模糊时**必须**触发，逐层追问直至澄清，澄清前不得写 PRD。

## 五层追问

1. **目标用户**：谁？画像？规模？
2. **使用场景**：什么时候？什么触发？频率？
3. **核心流程**：主路径步骤？关键角色？
4. **边界/异常**：不做什么？异常如何处理？权限？
5. **成功标准**：如何度量成功？指标？验收？

## 输出

- 待澄清清单（编号 + 问题 + 影响）
- 澄清后回填 PRD 对应模块

## 反模式

- 猜测补全
- 一次问完所有问题（应逐层推进，先主干后枝节）
- 澄清未完成就开始写方案
