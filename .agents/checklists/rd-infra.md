# 工程基座红线与交付检查清单

> 角色卡只常驻最硬红线；本文件在**交付前**读取并逐项核对。
> 汇报只报未过项：`未过：I-XX-03；其余 pass`（见 output-format）。

## 硬性红线（完整 8 项）

- [ ] 仓库内无密钥/机器特定值（token、私钥、绝对家目录路径）
- [ ] 脚本/迁移/安装器**幂等**（连跑 2 次 effect = 0 且 rc = 0）
- [ ] 新增 CI 权限/scope/Secret 逐项给出「为什么必需」，无 `*`/admin
- [ ] 守卫/校验带**失败演练**（破坏 ⇒ 报错 ⇒ 还原复绿）
- [ ] **不自验自己的守卫**（验收由 `qa`/`pm` 独立执行）
- [ ] 不写死仓库名/相对路径/包管理器（跨项目兼容）
- [ ] 未改项目 `AGENTS.md` 红线、业务源码/测试断言、他人未提交文件
- [ ] 全范围门禁 rc=0 且回执**精确数字**（命令 + exit code + 条数/文件数）

## 幂等 / 权限 / 自证 速查

- **幂等自证**：`cmd; cmd` ⇒ 第 2 次 effect = 0、rc = 0、无重复条目。
- **权限最小化**：每条权限/Secret 一句「为什么必需」；能只读就不写，能给单仓就不给组织级。
- **三段证据**：正常 rc=0 · 故意破坏 rc=1 并报出该项 · 还原后复绿。
- **对照数字**：每项给「改动前 → 改动后」（耗时/体积/条数/宽度…）；单跑不算。
- **敏感值**：日志/回执不输出 secret/token；错误体截断。

## 命名速查

`guard-<面>.mjs`（守卫脚本）/ `NAO_<域>_<项>`（环境变量）/ `check_<面>()`（校验函数）。

## 交付检查清单（完整 14 项）

- [ ] 边界已自评（工程基座类；业务语义部分已拆单回 `rd-fe`/`rd-be`）
- [ ] 幂等已验证（同命令连跑 2 次：effect = 0 且 rc = 0）
- [ ] 零密钥/零机器特定值入仓（grep 复核 token/私钥/家目录路径）
- [ ] 新增 CI 权限/Secret 已逐项给理由，最小化（无 `*`/admin）
- [ ] 改动/新增的守卫已带失败演练（三段证据齐）
- [ ] 跨项目兼容已在第二仓或临时目录验证（无单项目假设）
- [ ] 未触碰业务源码/测试断言/项目 `AGENTS.md` 红线/他人未提交文件
- [ ] 全范围门禁 rc=0；回执给精确数字（命令 + exit + 条数）
- [ ] 前后对照数字已给（对照类结论单跑不算）
- [ ] 已遵守项目 `AGENTS.md` 约束（命令纪律/仓库治理）
- [ ] 定位/变更代码已用 CodeGraph（回退 grep/read 有注明）
- [ ] 需求分支 `feat/<issue-id>-<slug>` 已 push，Draft PR 已开（填 PR 模板）
- [ ] 提交为 `wip()` 检查点 + 路径级暂存（禁 `-A`）；`--only <paths>` 且核过 index；无 WIP 提交落到 main
- [ ] PM 验收通过后才合并（`gh pr merge --squash --delete-branch` / 降级本地 squash）；未过验收未合并
