# 输出与沟通规范（通用）

## 语言与风格

- 中文回复。
- 先结论/方案，后细节；关键决策附理由。
- 不堆术语，不写空话。

## 长文落盘（强约束）

- 任意超过 300 字的结构化产出（PRD / 架构方案 / 评审报告 / ADR / 测试报告 / 用例集），**写文件**，不要贴在消息里。
- 消息只回：`路径 + ≤150字摘要 + 结论/阻塞`。

## 检查清单

- 交付前自查清单。
- 汇报时**只报未过项**：`未过：R-XX-03；其余 pass`。
- 禁止逐条复述全部通过项。

## 消息模板（通用）

```text
[编号/主题] | to=<会话> | role=<角色> | repo=<路径>
范围：做 X；不做 Y
引用：docs/...md#section（禁止贴全文）
交付：<产物类型>；长文落盘路径
摘要：≤150字
阻塞/决策点：<无 或 列出>
```

## 回执模板（通用）

```text
[编号] done | <role>
摘要：≤150字
变更：<文件/模块级>
测试：<命令/结果>
风险/阻塞：<无 或 列出>
详情：<路径>
```

## 反模式（禁止）

- 在消息里粘贴角色卡/PRD/输入信封全文。
- 复述需求原文而非结论与差异。
- 把长报告直接 `send` 污染线程历史。
- 汇报时逐条罗列全部通过项。
