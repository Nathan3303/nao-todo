# v1.20.3 —— 打扫屋子版：装得更轻，桌面版安装包不再夹带内部笔记

## 一句话

这次没有新功能，也没有改动任何操作方式：**依赖装得更轻了，桌面版安装包里以前能被翻出来的开发注释全部清掉了**，其余行为与 `v1.20.2` 一致。

## ✨ 更好用了

- **安装 / 更新更快**：依赖树少了一大截（详见下「📦 更小更快」），拉取和安装时间明显缩短。

## 🐛 修好了

- **桌面版安装包里能看到我们的开发注释**：解开安装包能看到中文说明、内部条目编号，甚至测试文件名。这些现在都清干净了——不会影响任何功能，只是把不该给用户看的东西收起来。
- **主界面侧栏的自动化检查一直在「考旧卷子」**：以前那些检查跑的是一个已经不再显示的旧侧栏，等于白考。现在改成检查你实际看到的那一个，如果以后有人改坏导航结构，会被立刻拦住。

## ⚠️ 请留意

- **没有任何操作方式变化**，不需要重新学习；本地已有的数据、登录状态、同步行为都不受影响。
- 如果你自己的脚本里 `import` 过下面这些第三方库里的小工具，会直接报「找不到模块」——不过本仓库里没有任何地方用它们（详见技术细节）。

## 📦 更小更快

- 依赖数量减少 **227 个包**（10 个库从依赖清单里移除，它们在全仓范围内一处都没被引用）。
- 桌面安装包体积基本不变（去掉的是没被任何代码引用的库）；主程序文件为了「崩溃时还能看到行号」多了约 4 KB，可以忽略。

## 技术细节（可略过）

- **版本**：root / `apps/web` / `apps/desktop` `1.20.2 → 1.20.3`（PATCH）。内部包无公共 API 变化（改动为注释与测试面），未 bump。
