# 简明版（面向用户）

**这一版：开着任务详情切视图不会再把它关掉了，账户相关按钮的配色统一到主题，清单「停用」与番茄钟「归档」两种状态终于能同步到云端。**

## ✨ 更好用了

- **开着任务详情切「表格 / 列表 / 看板」，详情面板不再消失**：以前切一下视图，详情会被关掉、得重新点开；现在会一直开着、内容不丢。
- **账户相关按钮的配色统一到主题**：设置页的「**注销账户**」改为**描边样式**（不再是一整块实心红）、「**恢复账户**」改为**主色**（恢复是正向操作，用红色语义不对）。
- **番茄页侧栏底部那两个按钮移除**：「新建常用番茄专注」与「查看历史专注记录」两个入口不再显示，后续会以更合适的方式回来。

## 🐛 修好了

- **清单「停用」状态、番茄钟「归档」状态以前同步不到云端**：客户端其实一直在发这两个状态，但服务端没有接收，于是被**悄悄丢掉**。现在能正常同步了 —— **需要服务端也更新到最新版才生效**。
- **「半写」不再无声**：当有改动没能完整同步（个别字段云端暂不支持）时，同步面板会**给出提示**；以前会当作「已同步」，悄悄丢掉。
- 修正了两处**只在特定日期/时刻才会出现**的测试误报（跨月、跨零点）：这不是功能故障，但会干扰我们判断「改动是否引入了问题」。

## ⚠️ 请留意（这些地方行为有变化）

- **「注销账户」按钮外观变成描边**（原来是实心红）：为了统一主题语义色并保证对比度，**不是故障**。
- **「恢复账户」按钮变为主色**（原来是红色）：恢复是正向操作，红色语义不对。
- **侧栏底部两个按钮不再显示**：如果你常用「查看历史专注记录」，跟我说一声，我优先安排替代入口。
- **服务端需要同步更新**：否则上面那条「停用态 / 归档态能同步」仍不会生效（客户端**不会报错**，只是不生效）。
- 同步面板新增的提示**只在真的发生「有改动没能完整同步」时出现**，日常使用不会看到。

## 📦 更小更快

- 本版以修正与一致性为主，体积无明显变化。

## 已知但本期未处理

- 极小概率出现「刚创建的任务显示 1 毫秒时间差」引起的提示，后续处理。
- 其它页面（常用专注 / 专注记录 / 搜索）的「今天 / 明天」等文案尚未本地化。
