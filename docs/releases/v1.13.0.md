# 本次更新

**关掉窗口，NaoTodo 也会继续在后台提醒你；重启电脑后它会自己回来 —— 桌面端「不漏提醒」这件事，到这一版才算真正补齐。**

## ✨ 更好用了

- **关窗口只是「收进托盘」**：任务、清单、专注都照常，到点照样弹通知。想回来点一下托盘图标，**回到的还是你关之前那个页面**，不是首页。
- **开机自动启动（默认开启，设置里能关）**：不用再记得「先打开 NaoTodo」，重启后它自己会回来。
- **第一次关窗口会告诉你发生了什么**：只提示这一次 ——「仍在后台运行，提醒照常；要彻底退出请用托盘菜单」。以后不会再打扰你。
- **长时间不关机也不会被踢回登录页**：登录会自动续期（以前只在启动时续一次，所以常驻两天就得重新登录）。
- **设置里多了一块「桌面常驻」**（设置 → 提醒）：能看到当前状态、开关开机自启、并在需要时退出应用。

## 🐛 修好了

- 桌面端「关掉窗口就退出，于是什么都提醒不到」—— 这是「不漏提醒」最后的缺口。
- 常驻超过两天被强制回登录页（登录续期只在启动时发生）。
- 服务端的历史登录档案只增不减（过期和早已登出的记录会一直堆着，现在每天自动打扫一次）。

## ⚠️ 请留意（行为有变化）

- **关窗口不再等于退出应用**（三个平台统一；macOS 以前关窗会销毁窗口）。**要彻底退出**：托盘菜单里的「退出」，或 设置 → 提醒 →「桌面常驻」→「退出 NaoTodo」。退出后就不会再提醒。
- **开机自启默认是开的**。Windows / macOS 可能需要在系统里批准一次（macOS 13 以上会显示「需系统批准」，设置里可以重试）；如果系统不允许，设置里会明确显示「未生效」，不会假装已开启。
- **电脑休眠或关机期间不会提醒**（系统限制）。唤醒后会在 10 秒内补一次。
- **GNOME 如果没装托盘图标扩展，图标可能看不见** —— 这时用设置页里的「退出 NaoTodo」也能退出，状态会显示「已开启（可能不显示托盘图标）」。
- **会话最长 7 天仍需重新登录**：这是安全边界，本期没有放宽（到期前会明确提示，不会静默不提醒）。
- **多设备仍然各自提醒一次**（账号级去重仍待后续批次）。
- **手机 / 网页版不受本次改动影响**。

## 📦 更小更快

- 没有新增任何运行时依赖；托盘图标资源合计约 **1.4 KB**。

## 技术细节（可略过）

- **桌面端**：单窗口 `hide()` 常驻 + `webPreferences.backgroundThrottling:false`（隐藏时 `visibilityState` 仍为 `visible` ⇒ 既有提醒引擎**零改动**继续轮询）；`close` → 隐藏、`before-quit` / `query-session-end` / `session-end` 置退出位（防拦住系统关机）；第二实例带 `--autostart` 静默忽略。
- **开机自启**：Windows / macOS 走 Electron 登录项并**回读**判三态；Linux 自写 `~/.config/autostart/nao-todo.desktop`（AppImage 用 `process.env.APPIMAGE` + `TryExec`）。
- **会话续期**：客户端 12h ±10% checkin（触发补集 = 启动 / 唤醒 / 联网 / ≥12h，去抖 5min，退避 1/2/5/15/30min 封顶），失败不清凭证；token 轮换加 10s 单次宽限，避免在途请求收到 `10041` 后自伤登出（Web 端从不触发 ⇒ 行为零变化）。
- **服务端**（`nao-todo-server#57` → squash `504b917`）：每日 03:10 批量硬删「过期 > 7 天」与「登出 > 24 小时」的会话（两谓词互斥，500 行/批 ≤20 批，**无 DDL**，`SESSION_CLEANUP_ENABLED=false` 可一键停）。
- **门禁**：`vp check` 0 error · 全仓 `vp test --run` **275 文件 / 2360 例 / 0 红** · 4 个 guard exit 0 · `desktop:build` / `webapp build` exit 0 · 移动端红线 0 行。
- **验收**：用户 2026-10-25 手工与视觉测试通过（关窗收托盘 / 首次提示 / 退出路径 / 隐藏态提醒 + 点通知回详情）。
- **未纳入本期断言**：`AC6`（连续常驻 ≥48h 不掉登录）为**观察项**；Windows / macOS 专属项（重启自启、macOS 13+ 批准、Windows 任务管理器禁用）**未在本机验证**；服务端清理任务的生产侧执行对账（`AC7`）待复核。
