# 本次更新

**设置页重排成四类、界面更开阔：左边一点就到，右边不再被框住；「登录设备」也重新设计过，一眼看清哪台是当前设备、多久没动过。**

## ✨ 更好用了

- **设置分成四类**：账户 · 外观与语言 · 提醒 · 数据与关于。左栏只有图标 + 名称，点一下就到；右侧不再用卡片框住，栏目之间用大留白和更大的标题分开。
- **每类说明挪到右侧标题下**：一句话告诉你这一类能做什么，不再挤在左栏。
- **危险操作集中**：账户类底部独立一块「危险区域」，退出登录与注销账户各带确认，不会再和普通设置混在一起。
- **数据与关于更清楚**：一行显示同步状态与上次同步时间（只读）；「本地数据与安全」说明默认收起、展开看全文；版本号旁边是「查看更新」（打开项目发布页，不会自动更新）。
- **「登录设备」重新设计**：设备名 + 「当前设备」标记 / 地区与 IP / 最近活跃（3 分钟前、昨天这种读法）+ 登录日期；当前设备自动置顶并轻微标出，非当前设备右边就是「下线」。
- **密码修改改为点行展开**：减少拥挤，点一下出现表单，校验与提交与以前完全一样。

## 🐛 修好了

- 以前「应用设置」里语言、外观、提醒、本地数据说明、版本号**堆成一列**，只靠一根分隔线硬分；现在各归其类、两次点击内可达。
- 「登录设备」以前把地区 · IP · 登录时间 · 最近活跃**挤在一行**，窄屏会乱折行；现在分三层显示，长设备名也不会挤坏按钮。
- 以前标题「加粗」其实没生效（主题里字重变量未定义，实际回落成常规）；现在标题真的更重、层级更清楚。

## ⚠️ 请留意

- **左栏不再有说明文字**（只留图标 + 名称），说明移到了右侧标题下 —— 信息没少，位置变了。
- **密码修改改成点行展开**（原来是一直展开的表单）。
- 「查看更新」只是打开项目发布页，**不是自动更新**；手机浏览器仍以应用内提醒为准。

## 📦 更小更快

- 没有新增依赖；删掉了旧的「应用设置」混装组件，设置相关的样式与逻辑更集中。
