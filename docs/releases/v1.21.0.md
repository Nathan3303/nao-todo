# v1.21.0 —— 桌面版可以自己更新了，设置页也重新收拾了一遍

## 一句话

桌面版新增**应用内检查更新并一键更新**（安装包在应用里下载、重启后生效）；设置对话框同步重做：左栏更像导航、账户信息归位、密码修改不再折叠、整体留白收紧。

## ✨ 更好用了

- **桌面版能在应用里更新了**：设置 →「数据与关于」→「关于与更新」，点「检查更新」就能看到有没有新版；点「立即更新」会在应用内下载，下载完提示「立即重启更新 / 稍后」，由你决定什么时候重启。
- **更新不会打扰你**：下载在后台进行，不影响记任务、开番茄；什么时候重启完全你说了算。
- **有没同步的改动会先提醒**：如果还有改动没同步完，点重启前会先问你（「先同步再更新 / 仍要更新 / 取消」），取消后已下载的更新还在，不用重新下。
- **设置左栏更像导航了**：去掉了激活项左侧那根竖线，改成整块高亮 + 文字加重，切换时一眼看清在哪一类。
- **账户页重新分区**：现在分成「用户信息 / 密码修改 / 登录设备 / 危险区域」四块，每块都有标题和一句说明；注册时间挪到了头像右侧，待注销时才会出现的「数据删除时间」放到危险区。
- **密码修改不再折叠**：进账户就能直接看到密码表单，不用先发现「可折叠的那一行」。
- **登录设备的刷新按钮挪到了分区标题旁边**；危险区的「退出登录 / 注销」两个按钮改成并排的一行。
- **设置页整体留白收紧**：块与块、行与行之间的空隙更紧凑，同一屏能看到更多内容。

## 🐛 修好了

- **检查更新失败时不再给你看技术报错**：以前偶尔会冒出「APPIMAGE env is not defined…」这类开发者才看得懂的字眼，现在只会显示「离线 / 超时 / 服务暂不可用」这类可读原因。
- **不能自动更新的安装方式不再假装能更新**：macOS 版和 deb 安装版点「检查更新」时会直接告诉你「当前安装方式不支持应用内更新」，并给出「打开下载页」，不会再走一遍失败流程。
- **检查失败后不再给「重试」按钮**：改为引导你去下载页；想再试就点上面那行「检查更新」，它永远可点。
- **密码表单原先比两侧内容右移了一点**（窄屏还会少用一截宽度），现已与其它行对齐。
- **登录设备里重复出现的标题**已去掉（分区标题承担说明，列表里不再重复一遍）。

## ⚠️ 请留意

- **只有两种安装方式能原地更新**：Linux 的 AppImage 与 Windows 安装版。macOS（未签名）与 Linux deb 安装版会显示「打开下载页」，需要你手动下载安装包。
- **下载的是完整安装包，不是增量补丁**，所以下载量等于一个安装包大小（约 100 MB 级），请留意流量。
- **更新在重启后生效**：点「稍后」不会立刻变版本，下次你重启应用时才是新版本。
- **第一版不会自己更新自己**：你现在装的这个版本是第一次带更新能力，所以它本身不会通过自动更新到你，下一个版本起才会。
- **设置页的改动对桌面端和网页版同时生效**，操作方式没有变化，不需要重新学习。

## 📦 更小更快

- 本次没有体积优化项；设置页间距收紧属于排版调整，不影响包体积。

## 技术细节（可略过）

- 更新通道：官方 `electron-updater` 6.x + GitHub Releases 作为唯一源；`autoDownload` / `autoInstallOnAppQuit` 均关闭，安装时机完全由用户触发；构建配置与 CI 形态本版未改动（现有 `app-update.yml` 与 `latest*.yml` 已够用）。
- 架构：主进程更新内核与 `electron-updater` 解耦（`checker` / `downloader` / `installer` / `env` / `syncGuard` 五端口注入，内核零 `electron` 依赖）；安装形态判定为纯函数 `resolveInstallMode({ platform, appimage, isPackaged })`；不可自动更新的形态**不发起任何检查请求**；失败原因只以原因码进入状态载荷与界面，`electron-updater` 原文与本机路径不进 UI、日志出口脱敏。
- 版本比较为三段数字比较（容忍 `v` 前缀、非法串按「不提示更新」保守处理）；24 小时静默检查缓存边界以 `23:59:59.999` / `24:00:00.000` 为判据。
- 设置面板：左栏复用 `nue-link--route` 四态（`tablist`/`aria-selected`/方向键与 Home/End 语义未变）；账户四分区、间距台阶 L0–L6 每层单处定义（删除 4 处双层内边距与多处字面值）；`DESIGN.md` 新增 §4.9「元素设计方式：以组件库主题为准」。
- 移除 `UserInfoViewer` 组件与 3 个相关文案键（全仓与移动端 0 引用）；`SessionManager` 的刷新按钮经 `defineExpose` 暴露**已节流**版本，侧栏面板不反向依赖组件。
- 版本号：root / `apps/web` / `apps/desktop` `1.20.3 → 1.21.0`；`packages/*` 有源码改动（`shared` 文案键、`presentation-identity` 组件），按近批惯例不单独 bump。
