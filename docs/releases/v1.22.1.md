# v1.22.1 —— 保养版：依赖安全、构建基座、两处小修

## 一句话

这次没有新功能，是一次**保养**：把生产依赖里的安全问题清干净、构建与发布工具链升到最新、修掉变更历史里一处「双层滚动」的别扭手感。操作方式没有任何变化。

## ✨ 更好用了

- **变更历史展开条目不再"套娃滚动"**：以前展开记录后，滚轮落在展开区里只会滚那一小块、外层不动；现在全篇只有一个滚动区，滚轮和键盘都能一路到底。

## 🐛 修好了

- **桌面运行时与界面框架的安全更新**：Electron、Vue 与多语言组件都升级到安全线以上（生产依赖的已知漏洞从 23 条降到 **0**）。
- **构建工具链的已知漏洞**：Vite 与几个底层库升级；开发期依赖的严重问题（3 条 critical）也清掉了。
- **桌面版与网页版构建工具**：GitHub Actions 升到最新主版本（顺带消掉 CI 里那条 Node 20 弃用警告）。
- **文档索引重复**：ADR 归档索引曾被整篇追加了第二份副本（两份内容还互有独有行），已合并成一份，并加了守卫防止再犯。

- **桌面端这次的 Electron 是一次小版本升级（43.4 → 43.8）**：打包与启动自检都通过，但**真实运行与自动更新链路的兼容性**建议你打开桌面版跑一遍日常操作确认。若发现异常，回退只需回退这一个版本。
- **没有任何界面或操作流程变化**，本地数据、登录状态、同步行为都不受影响。
