# 本次更新

**看板的「按状态 / 按优先级」切换换了个位置 —— 挪进右上角菜单、紧贴「看板视图」下面，看板顶上那一行空出来了。**

## ✨ 更好用了

- **入口和「切视图」在一处**：右上角菜单的「视图切换」里，紧贴「看板视图」下方就是「按状态 | 按优先级」，不用再跑到看板顶部去找。
- **看板多出一行空间**：内容区顶部那一行彻底移除，列头直接顶到上方，不留空白占位。
- **只在看板视图里出现**：切到表格 / 列表视图时，菜单里没有这一条（不是灰掉、不是占位，是干脆不显示）。
- **切分组不用反复开关菜单**：在菜单里点「按优先级」，看板立刻变四列，**菜单不关**，方便来回对比两档再关掉。
- **键盘也顺手**：`Esc` 关掉菜单后，焦点回到右上角那个按钮，直接回车就能再打开，不用再 `Tab` 一路找回来。

## 🐛 修好了

- **切换控件在菜单里「高一头」**：之前它是 40px 高，比菜单条目（32px）高一截，看着突兀；现在与菜单条目同高，一眼就明白是同一组东西。

## ⚠️ 请留意

- **仍然不记住分组选择**：刷新或重新进入会回到「按状态」（与上一版一致，是刻意如此）。
- **菜单不会自己关**：点分段切换后菜单保持展开 —— 这是有意的（方便对比两档），按 `Esc` 或点空白处关闭。
- 三处清单页（任务页 / 普通清单 / 标签页）都有这一项，位置与行为完全一致；桌面端与网页端是同一份实现。

## 📦 更小更快

- 没有新增运行时依赖。
- 分段切换组件多了一个「菜单内」尺寸档，仍是同一个共享组件，没有第二套样式。
