# 本次更新

**三个"一直以为是对的"的小地方修好了：优先级排序现在真的按高→中→低排；收藏/分享的链接打开就落在原处；设置和改密表单也能被读屏与键盘正常使用了。**

## ✨ 更好用了

- **优先级排序按语义排**：以前按字符串比较（high / low / medium），降序会变成"高 → 低 → 中"；现在是 **高 → 中 → 低**，升序反向。没设优先级的任务与「低」排在一起（因为界面上它们本来就显示为「低」），同一档内保持原顺序、不会乱跳。
- **收藏/分享的链接不再被"上次位置"顶掉**：带目标地址的链接（例如指向某个任务）打开后**直接落在那个位置**；只有地址没指定目标时，才回到上次浏览的地方。
- **设置左栏可以用键盘了**：`Tab` 进入后 `↑`/`↓` 切换分类、`Home`/`End` 跳到首/末，焦点会跟着走；读屏能正确播报"第几个分类、对应哪块内容"。
- **改密表单可被读屏识别**：三个输入框现在都有持久的可读名称（旧密码 / 新密码 / 确认新密码），不再只靠一输入就消失的占位文字。

## 🐛 修好了

- 日历里另有一份优先级排序映射，与列表口径不一致（无优先级被当成"最低"还是"低"说法不一）——现在两处共用同一份映射。
- 深链登录中转会丢掉目标地址的问题（以前点开链接、登录完就被送到上次位置）。

## ⚠️ 请留意

- **"没设优先级"与"低"在排序里是同一档** —— 界面本来就把未设置显示为「低」，所以它们排在一起；如果你希望未设置的单独排最后，请告诉我们。
- 深链行为变了：带目标的链接**优先**于上次浏览位置（这是本次的修复方向）。
- 手机窄屏用顶部 4 段切换（没有左栏），此前的键盘/读屏改进只作用于桌面左栏。

## 📦 更小更快

- 没有新增依赖、没有新增请求；排序与排序映射改为单一来源，代码更少一处重复。
