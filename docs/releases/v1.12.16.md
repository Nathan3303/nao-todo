# 本次更新

**提醒现在可以"管"了：能设免打扰时段、能一键完成、能看清是哪个清单和原本几点提醒你 —— 手机端也终于会告诉你"为什么收不到系统通知"。**

## ✨ 更好用了

- **免打扰时段**：在「设置 → 应用设置 → 提醒」里设一个时段（例如 22:00–08:00），这段时间到点的提醒**不弹窗、不出声、不打扰**；时段一结束（或你下次打开应用）会把错过的**逐条补上**，每条只补一次，并标出「原定 22:30」。
- **弹窗直接「完成」**：提醒里多了一个「完成」按钮 —— 点一下任务就完成、这条提醒出队，不用再点进详情改状态；「每天 / 每周」的提醒也不会再来烦你。
- **一眼看清是哪个任务**：弹窗现在会显示**清单名**和**原定提醒时间**，不用点进去判断。
- **通知与声音分开控制**：不想被系统通知打扰，关掉通知开关即可（应用内照常提醒、也不会漏）；声音开关单独控制系统通知是否响。
- **设置跟账号走**：换浏览器、换设备登录同一账号，三项设置一致。
- **首次不再自动索权**：系统通知改为你在设置里**手动开启**（浏览器对自动弹权限框本来就会忽略，现在更符合预期）。

## 🐛 修好了

- **「以为通知开着，其实收不到」**：某些浏览器（Android Chrome 页面通知被禁用）明明权限显示已开启、实际却发不出通知。现在会**真实试一次**，发不出就在设置区显示「当前浏览器不支持系统通知」并把声音开关置灰，不再给假状态；同时**提醒本身照常以应用内弹窗出现，不会丢**。
- 通知功能出错不再影响提醒：以前构造通知失败会让那条提醒彻底消失，现在会降级为应用内提醒。

## ⚠️ 请留意

- **手机浏览器发不了系统通知**（iPhone Safari 普通标签页没有这个能力；Android Chrome 需要额外的推送能力）⇒ **手机端以应用内提醒为准**。想要"锁屏也能收到"，需要另做 PWA/推送能力，另立项。
- **系统通知需要在设置里手动开启一次**（首次不再自动弹权限框）。
- **旧版本客户端可能覆盖云端提醒设置**：请**两端同批更新**到本版。
- 免打扰按**该设备本地时间**判断；多台设备各自提醒，不是全平台只响一次。
- 切到后台标签或最小化时"准时"不承诺（浏览器会限制定时器），回到页面会立刻补上。

## 📦 更小更快

- 无新增依赖、无新增常驻定时器；免打扰判定复用每轮扫描（每 10 秒一次，开销可忽略）。
