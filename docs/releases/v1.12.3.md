本版本为**组件库与主题升级 + 日历撤销入口重构 + 全仓测试布局规整 + 提示语义色 AA 达标**：统一两端组件库到 NueUI `1.13.0`（桌面端产物显著瘦身），把日历「撤销」入口改走组件库消息扩展插槽并完善成功/失败终态，修复提示/按钮/徽标/表单提示的语义色对比度（`DEF-58` / `DEF-61`），并全仓拉齐测试目录 + 加门禁。web 与 desktop 行为一致，**移动端零改动**。

## 行为变更（请留意）

1. **日历「撤销」入口改走组件库消息扩展插槽（`NueMessage`）**（`T362`）。不再使用自研顶部胶囊；**全节只保留一条**撤销入口（新动作出现时先关闭上一条）。**成功终态**：按钮**不可再点**并显示「已撤销」（`aria-disabled`）、主文案变「已撤销该调整」，保持约 **2s**；**失败态**：红底「撤销失败，可重试」+「重试」**仍可点**，保持约 **3s**。非终态仍为**约 5s** 自消息出现起算。
2. **提示（Toast）语义色更深**（`DEF-58` 修复，主题 `0.13.27`）。success 文字 `-70 → -100`、warning/error 文字 `-70 → -90`、三边框 `-60 → -80` ⇒ 浅/深均达「文本 ≥4.5 / 图形 ≥3」。**观感上提示文字与描边变深**。
3. **按钮 / 徽标 / 表单提示语义色更深**（`DEF-61` 修复，主题 `0.13.28`）。实心 success / warning / error 按钮填充 `-40 → -100`（白字对比度 **1.73 → 6.60**、**2.29 → 8.51**、**3.28 → 10.93**）、destructive 文字/描边 `error-40 → error-80`（hover 底 `error-10`）、Prompt `value-error` `error-30 → error-70`、Badge 底 `warning-50 → warning-80`。**观感上填充明显变深**。
4. **同步状态面板**（`T370` / `T385`）。分区之间纵向留白收紧；已无引用的 `.sync-panel__footer` 死 CSS 移除（「立即同步」按钮本就在**概览**分区内，功能与位置不变）。
5. **测试文件位置约束**（`T369`，**对开发者行为变化**）。`apps/**` 与 `packages/**` 的测试文件必须位于 `__tests__/` 目录内；新增守卫 `guard:test-location` 接入 CI `check`（不满足即 CI 红）。
6. **依赖版本变更**。NueUI `1.11.0`（web）/ `1.10.58`（desktop）→ **`1.13.0`**；主题 `nue-ui-theme-shadlike` `0.13.24 → 0.13.28`。

## 修复

### `DEF-58` 提示色对比度不达 AA（上游主题债）

- **现象**：浅色下 success 提示文字仅 **2.56:1**、warning **3.50:1**（error 4.55 临界）；success 边框 2.03、warning 边框 2.83（图形需 ≥3）。
- **根因**：上游 `message.css` 把提示文字映射到 `{type}-color-70`（浅色 l40）而底色为 `{type}-color-10`（l90）。
- **修复**：上游 `nue-ui-theme-shadlike@0.13.27` 改用更深色阶（success 文字 `-100`、warning/error 文字 `-90`、三边框 `-80`）⇒ 浅 5.67 / 5.49 / 6.76、深 8.27 / 7.42 / 6.51（均达 AA）。本仓升依赖后**关闭**。

### `DEF-61` 按钮 / 徽标 / 提示语义色配对 6 项不达标

- **现象**：destructive 文字/边框 `error-40`（3.28 ❌ / hover 2.47 ❌）、实心 success 白字 **1.73** ❌、warning **2.29** ❌、error **3.28** ❌、Prompt 错误值 **2.44** ❌、Badge 白字 **2.81** ❌。
- **修复**：上游 `nue-ui-theme-shadlike@0.13.28`（实心填充 `-100`、destructive `error-80`、Prompt `error-70`、Badge 底 `warning-80`）⇒ 6 项全部达标。本仓升依赖后**关闭**。

### 日历撤销入口可用性与文案（`T364` / `T366` / `T368`）

- **终态状态驱动**（非重建 DOM）：仅当写回**全部成功**才置「已撤销」（禁止乐观置位）；失败保持**可重试**且**不显示已撤销**。
- **终态重置消失计时**：成功约 **2s** / 失败约 **3s**，保证终态**可被感知**（原「自 5s 起算」会在接近超时时只余极短可见窗口）。
- **禁用语义**用 `aria-disabled`（原生 `disabled` 会把持有焦点的按钮抛回 `<body>`）；点击由扩展区 + 数据层双重守卫 ⇒ 连点/键盘连击最多生效一次。
- **替换期旧条置 `retired`**：库移除旧节点有 ~0.5–2s 淡出，期间旧按钮**不可点**（避免点到淡出旧条却撤销了最新动作）。
- **失败态语义配色**：pill 仍以 success/warning 创建（库 `type` 创建时固定），失败时经 CSS 改指 `error -90/-10/-80` ⇒ 颜色与「撤销失败」文案一致。
