# 本次更新

**修了三个「以前悄悄坏掉」的问题：本地不再保存你的登录密码、「退出登录」真的会退出、登录校验异常时不会再永久卡住。**

## 🐛 修好了

- **你的密码不再被写进本地日志（安全问题）**：以前每次登录/改密，请求内容（含密码明文）会被记进本机的「操作日志」数据库，请求失败或超时时还会长期留着。现在**登录类请求一律不记**，并且会把历史残留**一次性清掉**。
- **「退出登录」以前其实没退出**：客户端把请求参数名写错了，还把服务端的「参数错误」当成成功 —— 你以为退出了，服务端那边会话还活着。现在会**真的撤销会话**；撤销失败会明确提示（断网时仍可以本地退出）。
- **登录校验异常时会永久卡在「正在验证用户凭据」**：现在要么正常进入应用，要么给你「重试 / 重新登录」两个明确出口。
- **启动瞬间被误判为「已下线」**：以前应用刚启动、后台同步与登录校验同时跑时，旧凭证的 401 会把登录态误清掉。现在这类在途请求只记录、不登出，等校验结果再决定。

## ⚠️ 请留意

- **这一版需要配套的服务端更新**（`nao-todo-server` #60，`c834404`）。**如果服务端没更新，"退出登录"仍可能显示成功但会话没撤销。**
- 之前那个「登录后卡在登录页」的**真正修复在服务端**（#58，`511e635`，你已经部署了）；这一版客户端**不包含**它。
- 手机 App 与桌面端其它行为没有变化。

## 📦 更小更快

- 没有新增任何运行时依赖。

## 技术细节（可略过）

- **凭据不入日志**：`operation-log.ts` 按「凭据字段（含 `_`/`-`/大小写变体，任意深度）+ `/auth/*` 路径」跳过落库；`purgeLegacyCredentialLogs()` 幂等清理；`replayFailedOperations` 取数面排除凭据记录（不重放登录/检入/登出/改密）。
- **登出契约**：请求体 `{ jwt }`（原 `{ token }`）、成功码 `10030`（原误判 `10031`）；失败经 `isNetworkError` 区分网络类（静默，保证离线可退出）与业务类（可见反馈）。
- **检入冲突终态**：`settleCheckInConflict`（有会话 ⇒ `null` 进应用；无会话 ⇒ 回 `10022` + 页面显式终态）；`recordShellError('auth:checkin-conflict', …)`，token 只记 8 字符前缀。
- **检入在途窗口**：`shared/requester/checkin-window`，窗口内 `10041` 只记 `auth.credential.deferred-checkin`，窗口关闭后照旧登出。
