# 本次更新

**上一版桌面端「登录成功却停在登录页」的问题已修好 —— 装上这一版，登录后就能正常进入 NaoTodo。**

## 🐛 修好了

- **桌面端登录后停在登录页**：登录其实已经成功（提示也弹出来了），但界面没走进应用。原因是我们自己上一版新加的「自动续期」在登录瞬间抢先用旧凭证去续期，结果把自己挤下线了 —— 属于「不漏提醒」这批新功能的连带问题。
- **万一跳转失败，现在会告诉你**：以前这类失败完全静默（界面不动、也不说原因），现在会明确提示一句，并自动再试一次。

## ✨ 更好用了

- 登录成功后**直接进入应用**，回到你上次停留的页面。
- 打开客户端后如果还没完成登录，不会再出现「后台悄悄续期一次、前台又检入一次」的重复动作。

## ⚠️ 请留意

- **只影响桌面端**：手机浏览器 / 网页版本次没有任何行为变化（网页版本来就没有这条自动续期路径）。
- **装上即生效，不需要重新登录**。如果你之前被卡在登录页，装这一版后用同一账号登录一次即可。
- 这一版是**给上一版打的热修补丁**；原计划的「手机看专注记录」顺延到下一版（`v1.13.2`），不跟这次抢发布。

## 📦 更小更快

- 没有新增任何运行时依赖。
