# v1.18.1 —— 列表不再闪加载，正在打字的字不会再丢

## 一句话

自动刷新现在是**真正的静默**：列表不会闪、不会跳；你在编辑框里打的字**不会再被另一端的改动冲掉**。

## ✨ 更好用了

- **看板也原地刷新了**：上一版只修好了列表和表格，看板每 30 秒还会在每个列底闪一下加载条、空列会从「无待办任务」变成「正在加载任务」。现在四个视图（列表 / 表格 / 看板 / 日历）都一致：刷新时**内容不动、不闪、不跳**。
- **刷新失败不再把内容清空**：以前一次失败（比如网络抖了一下）会把列表整块换成错误提示，下一轮成功再换回来 —— 看起来像内容在"闪断"。现在**内容留着**，只在旁边给一条提示：「刷新失败（正在显示上次加载的内容，稍后会自动重试）」。
- **提示条不再显示内部错误码**：以前偶尔会看到「刷新失败：10051」这种看不懂的东西，现在统一说人话。

## 🐛 修好了

- **正在输入的内容被冲掉**（你报的第 4 项）：编辑框里打着字、还没保存时，另一端改了同一条，本端会自动刷新并把你打的字替换掉。这个问题上一版只挡得住第一轮刷新，30 秒后的第二轮仍会丢字。现在：**你正在编辑的字段保值不动**，该条其它字段（优先级、状态等）和别的任务照常更新；保存后仍按原有冲突规则处理。
- **自动刷新时列表闪加载态**（你报的第 1 项）：四个视图全部改为**原地刷新** —— 不出现加载态、列表条数不变、行元素不被重建（所以不会有高度跳动）。
- **「刷新失败」但界面上什么都没变时，其实是静默失败**：极端情况下（失败原因不可读）提示条会不显示。现在一定显示，且句子告诉你**它会自己重试**。
- **整页出错后点「重试」没反应**：看板在多列同时出错后，重试按钮点了不会重新加载。已修（这是既有的问题，不是这次改出来的）。
- **提示条里的超长内容会把布局撑破**：提示条现在允许任意断行，极长的连续字符（错误文本、URL）不会溢出。

## ⚠️ 请留意

- **自动刷新失败时会出现一条提示条**：这是有意行为 —— 内容保留 + 明确告诉你"刚才没刷新成功，会自动重试"。如果你觉得提示条位置/配色不顺眼，告我。
- **提示条只写人能看懂的原因**：服务器返回的是内部错误码时会省略原因段（只保留"稍后自动重试"），这不是"它没告诉你"。
- **初次进入页面仍然会显示加载态**：我们只对「自动刷新」做静默，正常打开/翻页/点重试还是会有加载提示（否则本地库大时你会看到长时间空白）。
