# 本次更新

**手机侧栏底部现在一行就说清同步状态；清单标题和清单名字也不会再被莫名其妙切掉。**

## ✨ 更好用了

- **同步状态看得懂了**：以前手机侧栏底部的同步只有一个图标，得点开才知道"到底同步没同步"。现在它直接写出状态 —— 上次同步时间、待推送几条、失败几条、或正在同步中；看一眼就知道。
- **省下一行高度**：同步状态与设置按钮原来是上下两个图标、占两行，现在并成一行（状态在左、设置在右），抽屉里能多放一点内容。
- **清单标题用满了宽度**：以前清单区的标题明明旁边还有空地方，名字稍长就被切掉；现在标题会吃满可用宽度，只有真的放不下时才在**末尾**出现「…」，长按能看到全名。
- **清单名字也一起修好了**：清单下面每一条清单的名字，以前长一点会折成两行、第二行还被切掉，现在单行显示、放不下就末尾省略。

## 🐛 修好了

- 手机上暂停同步但队列里其实没有待推送任务时，状态会显示「待推送 0」—— 这个语义错误已修正，现在会正常显示上次同步时间。

## ⚠️ 请留意

- **清单名字的换行行为变了**：名字过长的清单，以前会折成两行（第二行其实被切掉、看不见），现在**单行显示 + 末尾省略**。这是有意的变化 —— 之前那种"折行"本身就是显示不全。
- **电脑版同样受益**：标题吃满宽度、长名末尾省略，其它布局与高度不变。
- 手机侧栏宽度仍是 256px，本次没有改变侧栏形态。

## 技术细节（可略过）

- 版本：root / `apps/web` / `apps/desktop` `1.12.13 → 1.12.14`；`packages/*` 本批零改动不 bump。
- 需求：`T522`（Issue #225 · PR #228 · PRD `docs/prds/2026-10-22-drawer-tools-row.md`）· `T523`（Issue #226 · PR #229 · PRD `docs/prds/2026-10-22-smart-list-title-width.md`）。
- T522：抽屉工具带由 `flex-direction: column`（同步 40×40 上 / 齿轮 40×40 下，实测 256×93）改为 `row` + `space-between`（实测 256×57）；状态触发器 `flex: 1 1 auto; min-width: 0` 可收缩，文案只在 `pendingCount > 0` 时显示「待推送 N」；文案与 `aria-label` 共用同一 computed（单一来源）；三通道 = 颜色（`is-pending`/`is-failed`）+ 符号（失败 `ntd-disconnect`、同步中旋转）+ 文字；异常态文本用 `warning/error` **90 档**（≥4.5:1）；数据可信度角标改贴图标右上角（`calc` 由 `--nue-text-2xl` 与 `--nue-box-size-md` 推导，无写死像素）；rail 变体由 `isDrawerHost` 门控 ⇒ 图标/`aria-label`/文案逐字不变。
- T523：`.nue-collapse-item__header` 两个子项原为 `flex: none`（内容定宽）⇒ 溢出被祖先 `overflow-x: hidden` **硬切边**（实测 `scrollW 273 > clientW 221`，**无省略号**、计数被裁）。改为标题 `flex: 1 1 auto; min-width: 0`、名称 `nowrap + text-overflow: ellipsis`、计数 `flex: none`、动作区 `flex: none`；`:title` 用原生属性（零 JS）。**范围扩展 R1**：`.nue-link__content` 补 `nowrap + min-width: 0`（原缺 `nowrap` ⇒ 折行后被 40px 行高垂直硬切，实测 `sH 36 > cH 18`），可单独回退、表头部分独立成立。
- 两处技术陷阱（已加守卫）：① `:deep()` **必须写在顶层**，写进 scoped 嵌套块会被展开成「父选择器 + `[data-v-xxx]` 目标」而**静默失效**；② 断言「框架透传 / 内部类名存在」时必须用真实组件 + 打印实测值（`nue-button__text` 类名本次已逐个核实在主题与组件源码中均存在）。
