# 本次更新

**看板现在能「按优先级」分组了 —— 拖一下就是把任务改成那个优先级，不再只是换个看法的壳子。**

## ✨ 更好用了

- **看板顶部多了「按状态 / 按优先级」切换**：切到「按优先级」，任务按 紧急 / 高 / 中 / 低 四列排开，列头写的就是优先级。
- **拖动 = 改优先级**：在「按优先级」下把任务从中拖到紧急，**它的状态不会跟着变**，优先级立刻生效（刷新、同步后仍是紧急）。
- **空或未知的优先级落「低」列**：不会凭空消失，也不会把库里原来的值偷偷改掉（只有你真的拖动，才会写入新值）。
- **切回「按状态」照旧**：状态列、拖拽改状态的行为与以前一模一样。
- **「已归档」入口能用键盘了**：Tab 能选中、回车能打开（鼠标点击行为与以前完全一致）。

## 🐛 修好了

- **「按优先级分组」以前是个假选项**：列头显示的是状态名、列内容按状态过滤、往里拖还会把任务状态写成非法值。这一版把它真正接线，三处（列头 / 过滤 / 拖拽）都按当前分组走。
- **两段优先级判据的死代码**：清掉了一对「只为彼此存在」的死人函数，优先级只剩一份权威定义。

## ⚠️ 请留意

- **分组选择不会被记住**：刷新后回到「按状态」（这是刻意的，本版范围只做切换本身）。需要记住的话我再单独做一版。
- **日历视图切换、设置里的窄屏分类控件换了位置**（代码上迁到共享层，四个地方共用同一个组件）—— 外观、尺寸、动效**逐字未改**，如果看到任何差异请告诉我。
- 移动端的「紧急」优先级仍未识别（需单独授权）。
