# v1.16.5

**这一版修了三处小毛病，其中两处是你自己用出来的。** 最要紧的是番茄专注页那个「选任务」的列表 —— 它以前几乎总是空的。

## 🐛 修好了

### 「任务专注」列表不再总是空的

番茄专注页点上方 `< 专注 >` → 切到「任务专注」，以前几乎**任何时候都显示「暂无待办任务」**，明明手上一堆活。

原因不是没数据：这个列表只查「**还没到期**」的任务，而判定用的是**精确到此刻**的时间 —— 所以

- 已经过期的任务 → 被当成"过期"藏起来
- **今天到期、但只填了日期**的任务 → 存进去是今天 00:00，比"现在"早，于是也被藏起来

结果就是：只要你给任务都填了截止日期，这个列表就永远是空的。

现在它会列出**所有还没完成的任务**：逾期的、今天到期的、没设截止时间的都会出现。已完成的、已删除的、已归档的、已放弃的仍然不出现；搜索、点选关联、滚到底加载更多都照旧。

**顺带一提**：逾期没做的任务其实最需要专注，藏起来本来就不合理。

### 番茄专注页的 `< 专注 >` 可以用键盘了

那两个入口以前是没有地址的链接，鼠标能点，但 `Tab` 停不到、`Enter` 按不动。现在是正经按钮：能 `Tab` 聚焦、有焦点框、`Enter` 能打开；外观和以前一样。

> 修的时候还出过一次"看起来修好了其实没修好"：组件的默认写法改了，但页面里实际用的是另一处覆盖写法 —— 是复验时才发现。现在按"真实页面"验证，并补了页面级用例，同类问题下次能被挡住。

### 专注记录的「专注模板」有了清除键

筛选面板里「专注模板」选过值后，右端从来不出现 ✕（一个字母拼错导致这个开关一直没生效）。现在能一键清空了。

## ⚠️ 请留意

- 修好「任务专注」后，**这个列表会比你印象中多**（因为逾期任务回来了）。如果你本来想"只看没到期的"，那需要一个单独筛选，可以再提需求。
- 本次**没有**改动任何服务端行为，也不需要重新登录。
