# 本次更新

**被踢下线时终于会告诉你为什么；在别的设备改完密码后，这边刷新也不会再冒出看不懂的「验证未完成」。**

## ✨ 更好用了

- **登录失效会有明确说明**：回到登录页时，顶部会有一条提示 —— 「登录已过期，请重新登录」或「你的账号**可能**已在其他设备登录，请重新登录」。可以点「关闭提示」收掉，不用管它也不会挡住输入框。
- **改密后其它设备的提示说得清楚了**：如果你在网页端改了密码，桌面端刷新时会看到「密码可能已在其他设备修改，当前登录已失效，请重新登录」，并且**主按钮是「重新登录」**（以前是让你「重试」，而重试根本没用）。
- **多个标签页会一起收口**：一个标签页登出或失效，其它标签页也会回到登录页并显示同一条提示，不会各跳各的。
- **登录页 / 注册页的互相跳转可以用键盘了**：Tab 键能选中，中键也能开新标签（这条以前点了没反应）。

## 🐛 修好了

- **已经登录成功、却还显示「登录已过期」**：提示状态没被清掉造成的误报，现在登录成功就会清空。
- **「验证未完成，请重试」这句看不懂**：现在会说明可能的原因（密码在别处改过 / 登录已过期 / 短时间内重复验证），并且主按钮始终是「重新登录」。
- **后台请求会带着空凭证反复撞接口**：61 处拼接统一收到一处实现，登出后不再发无效请求。

## ⚠️ 请留意
