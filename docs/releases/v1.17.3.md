# v1.17.3

**这一版把「同步状态」这块收拾干净了：更好看、不抖了，个别按钮也终于能用。**

## ✨ 更好用了

### 同步面板更清爽

- 分区之间不再是"设置表"似的横线，改成留白分层；上次同步时间更醒目，「立即同步」挪到右侧带图标；
- 一切正常时只留一句**「数据已是最新」**，不再铺一堆空标题；
- 待推送 / 失败的数量改成淡底胶囊 + 对应颜色，一眼能分辨；「冲突 N」整行都能点，不用瞄准小按钮；
- 错误信息很长时面板内部滚动，不会把窗口撑破。

### 「待推送 N」这个数字会即时更新了

以前它要等一整轮同步跑完才变，离线时你改了几个任务它还显示旧数字。现在编辑后**很快**（约半秒）就会更新；同步跑完归零。

### 「保留我的修改」能用了

在「我的修改已覆盖云端」这类记录上，以前点它会提示"该类型不支持"。现在点一下就能**确认保留**（本地本来就是你的版本），记录消失、计数减少，**不会触发额外的同步**。
另外，对于确实**无法自动恢复**的类型（例如两边各自新建了同一个对象），面板不再显示这个按钮 —— 改成明确写"需手动处理"并给你复制内容，省得点了才发现不行。

## 🐛 修好了

- **点「立即同步」时面板会抖一下**：根因是内容在同步瞬间被清空又回来（错误区消失、提示语消失、按钮变宽）。现在同步过程中**内容保持常显**：上一轮的错误摘要会带「上次同步」小字继续显示，提示语不再闪，按钮宽度固定。同步成功后才会平滑收起（这一次收敛是正常的）。
- 桌面端自动化冒烟里「离线进入」的判断仍在找密码框（那是早就退役的解锁门）—— 已改成判断真实证据，避免误报"已就绪"。

## ⚠️ 请留意

- **普通同步不再显示「正在加载更多…」这行提示**：只有镜像**确实触顶且还有更多**要拉时才出现。这是为了消除抖动有意收窄的（不是故障）。
- 无数据迁移、**无需重新登录**、**服务端无改动**（本次无需部署服务端）。
