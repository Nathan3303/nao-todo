# v1.20.1 —— 变更记录收进「更多」，看完就关

## 一句话

上一版把「变更历史」放在任务详情正文里，会一直占着位置、让详情页越堆越长。这一版把它收进底部「**更多**」菜单，点开是一个**对话框**，看完关掉就走。

## ✨ 更好用了

- **详情页更清爽**：正文里不再有变更区块，名称 / 描述 / 子任务等正常内容不再被挤下去。
- **要看时才打开**：底部「更多」→「变更历史」→ 对话框；底部按钮、右上 × 、Esc **三种方式都能关**，关掉后焦点回到「更多」按钮（键盘用户 Tab 不会丢位置）。
- **看着的时候不会自己闪**：对话框打开期间，后台自动刷新不会把内容清空或重挂，条目还在原处、不会跳动。
- **空态与老数据**：没有记录时显示「暂无变更记录」，不报错。

## ⚠️ 请留意

- **入口变了**：如果你在找上一版的「变更历史」区块，现在它在底部「更多」菜单里。
- **只改了入口和呈现形式**：记录内容、来源标记、上限（1000 条 / 90 天）、不上报服务器 —— 全部与上一版一致。
- **桌面端与网页端一致**：同一个入口位置。

## 📦 更小更快

- 无网络与体积变化；**打开详情不再为历史取数**（未打开对话框时零查询）。

## 技术细节（可略过）

- `main/history.vue` 迁为 `task-history-dialog.vue`（对话框壳 + 时间线），旧内联文件删除、无隐藏占位；`main/index.vue` 去掉挂载。
- Footer `nue-dropdown`「更多操作」组新增 `inner-dropdown-option`（`execute-id="history"`、`icon=time`），文案**复用 `history.title`** —— **i18n 零新增键**（仍精确 13 个）。
- 三路关闭：底部按钮 / × / `NueDialog` 的 Escape；关闭后 `nextTick` 把焦点归还**常驻的「更多」按钮**（菜单项随下拉卸载，符合 WAI-ARIA menu button 行为）。
- 打开期间 `vo` 整对象替换 ⇒ 对话框**同一 DOM 节点**、条目数不变、`load` 仍只 1 次（`T713` 独立探针验证，非自证）。
- 无 provider 的宿主不出死入口（`v-if` 守卫，与旧内联同口径）。
