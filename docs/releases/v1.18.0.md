# v1.18.0 —— 窗口放着不动，也会自己更新

## 一句话

另一台设备上改了任务，这边**最多 30 秒就自己出现**，不用再手动点同步、也不用切走再切回来。

## ✨ 更好用了

- **自动刷新**：窗口开着的时候，另一端（另一台电脑 / 另一个浏览器）的改动会自己出现。以前只有「重新打开页面 / 切到别的窗口再回来 / 手动点立即同步」才会更新 —— 窗口一直停着就**永远**停在旧数据上。
- **切回来立刻就是新的**：从别的标签、别的窗口、或从托盘唤回来时，**马上刷新一次**，不用等下一轮。
- **多个标签不再「各看各的」**：同一个浏览器开几个标签，其中一个同步完成后，其余标签**立刻**跟着更新。以前只有其中一个标签会真正去拉数据，其他标签会一直停在旧数据上。
- **后台不再白跑**：窗口/标签隐藏起来（含应用最小化到托盘）时**完全不刷新**，不占网络、不耗电；切回来立刻补一次。

## 🐛 修好了

- **「数据已是最新」有时是假的**：请求太频繁被服务器拦下时，以前会把它当成「拉取成功但没数据」，界面显示「已是最新」其实什么都没拉到；更糟的是**首次打开时撞上这种拦截，你会看到一片空白且没有任何提示**。现在会明确告诉你「请求过于频繁，请稍后再试」，并自动稍后重试。
- **两个标签显示的「上次同步」时间不一致**：某个标签的数据已经更新了，同步面板却还显示更早的时间。现在时间会跟数据一起更新。

## ⚠️ 请留意

- **隐藏时不刷新 + 显示时立刻刷新**：这是有意的 —— 后台不白白占用网络，切回来那一下就是最新的。
- **冲突记录可能会变多**：因为检查变勤了，以前「悄悄被别人的版本盖掉」的修改，现在更容易被记成一条记录让你看到。**这不是新增了你原本没有的冲突，而是把本来就发生的改动显出来了。**如果你觉得记记录太吵，告我一声，我做一个合并降噪。
- **同一网络下多台设备更不容易互相挤占**：以前同步请求的额度是按「网络」算的，同一个 Wi-Fi 下开几台设备会互相占对方的额度；现在按**账号**算。这项是服务端的改动，**需要部署由你那边完成**后才生效。
