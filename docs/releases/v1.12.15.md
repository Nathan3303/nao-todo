# 本次更新

**提醒不再靠"能连上服务器"：断网、关掉网页、切到后台，到点照样提醒；同一条只响一次，多开标签或刷新也不会重复。**

## ✨ 更好用了

- **关掉网页期间的提醒不会再丢**：以前关着网页时到点的提醒，等你回来已经不认得了；现在下次打开会把错过的补上（只补一次）。
- **断网也能提醒**：到没到点由你自己这台设备判断，不需要联网。
- **同一条只提醒一次**：多开几个标签页、刷新页面、关掉再打开，都不会重复弹同一条。
- **点通知就能到任务**：点屏幕角落的系统通知会直接打开那条任务的详情；在提醒弹窗里点任务名也一样 —— 以前点了没反应。
- **「每天 / 每周」会自己排下一次**：到点提醒后自动安排下一次，不用重新设置。

## 🐛 修好了

- **网页开久了就再也收不到提醒**：以前靠一条长连接，连接断了提醒就静默消失；现在不依赖它。
- **已完成 / 已归档的任务还会弹提醒**：现在不会了；同时**子任务的提醒不会再被漏掉**。
- **关掉网页后到点的提醒会被服务器"抹掉"时间**：现在会保留，并在你回来时补弹。

## ⚠️ 请留意

- **切到后台标签或最小化时，"准时"不承诺**：浏览器会限制定时器；回到页面后会立刻补上。
- **只提醒"已经同步到这台设备"的任务**：另一台设备上刚建、还没同步过来的任务，这台设备不会提醒。
- **多台设备各自提醒**：不是全平台只响一次。
- **桌面端需要先解锁**，解锁后会把错过的提醒补上。
- **旧版本客户端**：服务端不再替它续期提醒，「每天 / 每周」会退化成只响一次 —— 更新到本版即可恢复。

## 📦 更小更快

- 少了一条常驻的长连接；提醒弹窗的加载方式做了合并，首次打开少一个网络请求，整体脚本体积略减（约 −0.5 KB）。
