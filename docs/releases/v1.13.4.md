# 本次更新

**番茄钟这一版更安静也更清楚了：夜里不再被声音吵到、抬眼就知道还剩多久、还能看出自己在第几轮。**

## ✨ 更好用了

- **页签标题会显示进度**：计时中浏览器标签页上直接写着「还剩多久 + 现在在做什么」，例如 `24:59 · 专注`、`04:30 · 休息`；暂停时前面会多一个 `⏸`。切到别的标签页也能一眼看到，结束或取消后标题自动复原。
- **桌面端收进托盘也看得到**：把窗口收进托盘后，鼠标悬停托盘图标就能看到同样的「阶段 + 剩余时间」。
- **新增轮次指示**：计时器下方多了圆点 + 一行小字，例如「第 2/4 轮」「本轮结束后长休」「休息中 · 已完成 2/4」。看一眼就知道自己在第几轮、这轮做完会不会进长休。

## 🐛 修好了

- **「4 轮后长休」以前要多等一轮**：设置 4 轮长休时，实际是做完第 5 轮才进长休。现在**做完第 4 轮就进入长休**，与设置一致。
- **关掉通知声音后番茄提醒照样响**：以前番茄的完成提醒不看「设置 → 提醒」里的声音开关。现在关掉就真的安静。
- **深夜也会被番茄提醒吵醒**：以前番茄提醒完全无视「免打扰」时段，照样弹系统通知、照样响。现在免打扰时段内改为**屏内提示**，不再发系统通知、不再有声音。

## ⚠️ 请留意

- **长休会来得早一轮**：如果你习惯旧节奏，这一版会让你感觉「怎么这么快就长休了」—— 这是把少算的一轮改回来了，不是新加的规则。想恢复旧体验，把「长休触发轮数」调大 1 即可。
- **「跳过」「结束专注」不再算一轮**：只有完整做完一轮专注才推进轮次进度；中途跳过或结束不会计入「第 N 轮」，也不会因为它提前进长休。
- **免打扰时段内只有屏内提示**：如果你把桌面窗口收进了托盘，这条屏内提示是看不到的 —— 免打扰本来就意味着「不打扰」，所以不会为此破例发系统通知。若你在提醒设置里**关闭了通知**，则任何提示都不会出现（界面上计时器仍在运行）。
- **番茄的时长设置仍是各设备独立保存**：换设备或重新登录不会带回你的 25/5/15 等设置（这一版没有改动这一点）。

## 📦 更小更快

- 没有新增任何运行时依赖。
- 标题与托盘的刷新复用了计时器原有的刷新节奏，**没有新增定时器**。

## 技术细节（可略过）

- **通知判定顺序**：① 读设置失败 ⇒ 照发且不静音（fail-open）② 命中免打扰 ⇒ 应用内提示后结束（**优先于通知开关**：该开关只管辖系统通知）③ `notify === false` ⇒ 全静默 ④ 其余发系统通知且 `silent = !sound`。派发层永不抛，不影响阶段流转与记录落库。
- **标题/托盘单源**：`formatPomodoroTitle` 一处产出，按值去重（秒级 ⇒ ≤1 次/秒）。复位值恒为 `NaoTodo`（Electron `setToolTip('')` 等于移除 tooltip）。
- **桌面通道**：`ipcRenderer.send` / `ipcMain.on` 单向、独立常量 `DESKTOP_ONEWAY_CHANNELS`（不并入 `DESKTOP_IPC_CHANNELS`，其 4 通道断言未动）、载荷 1..64 字符、六支降级全静默且无 `console.error`。`AppRoot` 走相对路径引入（避开 `@/hooks` 桶在测试环境解析到 webapp 的坑）。
- **计数点迁移（`DEF-111`）**：仅在「专注自然完成」时 `+1`；跳过/结束/取消/跳过休息均不计数；长休后周期归零。store 暴露 `completedRounds`（qa 契约名）。**观察项**：`idle` / `longBreak` 阶段圆点实心固定为 0（「本周期视图未开始 / 新周期」语义），因此 idle 时不显示本周期已完成的轮数，进入 focus 即恢复。
