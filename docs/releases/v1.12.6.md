# 本次更新

**这一版：搜索页的搜索框左边多了一个「收起 / 展开侧边栏」按钮，和任务、番茄、日历、设置页的操作完全一致。**

## ✨ 更好用了

- **搜索页也能一键收起左侧栏**：搜索框左边新增按钮，点一下就把左侧栏收成窄窄的图标条（快捷搜索 / 常用搜索 / 最近搜索随之收起），搜索结果区一下子变宽；再点一下原样回来。以前只能切到别的页面收起侧栏、再切回搜索页。
- **按钮会跟着状态说话**：鼠标悬停会显示「收起侧边栏 / 展开侧边栏」，收起与展开两态都能一眼看出来；用键盘 Tab 选中后按 Enter 或空格同样生效。

## ⚠️ 请留意（这一版行为有变化）

- **搜索框左边多了一个按钮**，输入框因此右侧了一点、宽度略微收窄。如果你更在意输入区宽度，收起左侧栏后会明显变宽。

## 📦 更小更快

- 本版只新增一个入口按钮与两处提示文案，体积无可见变化。
