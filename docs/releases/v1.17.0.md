# v1.17.0

**这一版专门处理「数据悄悄被覆盖」：以后冲突不会再静默发生，你能看到谁赢了、自己改了哪一项，也能把自己的版本找回来。**

## ✨ 更好用了

### 冲突面板说人话，不再只有一句提示

以前部分情况（比如两台设备同时改同一个任务的不同字段）某个修改会直接消失，面板里什么都看不到。现在每次「有一方的修改没进最终结果」都会留下记录，并带上**被丢掉的具体内容** —— 你能看出自己改的是哪一项、云端最新是什么。

- 冲突类型、发生时间、你的版本时间都在详情里；
- 类型标签统一为可读文案（「云端已有更新」「我的修改已覆盖云端」等）；
- 无法自动恢复的类型（例如两边各自新建了同一个任务）会明确写「这类冲突无法自动恢复」，并提供**复制内容**按钮，方便你手动重建。

### 「用云端的」现在真的会生效

以前在面板点「用云端的」，只是删掉那条记录，云端内容其实没有写回本地 —— 你接着编辑一次，又把它覆盖回去了。现在点完会**先把云端内容完整写回本地**、保留云端版本号，再清掉记录，后续编辑基于云端版本进行。

如果用的是旧版服务端（还拿不到云端那份内容），会明确提示「将在下次同步后生效」，不会假装已经生效。

### 删除和编辑打架时也会告诉你

手机离线删了一个任务、电脑又在改它 —— 以前谁赢都不吭声。现在会按版本判定，并在面板里说清「这次删除没有生效」或「这次编辑被删除覆盖」，且保留可恢复的内容。

## 🐛 修好了

- 拉取到的云端版本覆盖本地时，不再只悄悄更新「同步基线」而不留任何记录。
- 冲突记录多了之后，最重要的「标识冲突」不会被次要记录挤掉；同类重复事件会合并计数（`重复 N 次`）而不是塞满列表。
- 冲突内容过长时按 512 字符截断并明确标记，避免记录无限膨胀。
- **「用云端的」遇到真实服务端返回的空值会直接报错**（第一版实现缺陷，走查当天发现并修复）—— 现在标签、清单、提醒等字段为 `null`/空串时也能正常写回。
- **详情里会列出根本没改过的字段**（比如版本号、检查项数量）—— 已改为只展示**真正改动的字段**。
- **字段值不好读**：标签显示成 ID、状态显示成 `in-progress`、空值显示成空白 —— 现在统一显示为**标签名 / 中文状态 / 「未设置」**。
- **详情对比看不清**：左右两列的值带框带底色、字段名和值不在一条线上 —— 已改成**左右对照表格**（字段 / 我的修改 / 云端最新），值一律纯文本、无框，靠 `−/+/~` 与文字说明区分三态。
- **两侧都「未设置」却被标成有差异**（空值与空字符串被判为不同）—— 已统一空值口径，不再出现这种「看不出差别的差异」。
- **左栏长标题居中、非任务冲突只显示一串 ID**（如评论）—— 已改为左对齐、并显示「父任务名 · 内容摘要」。

## ⚠️ 请留意

- **清单 / 标签的图标为本地默认样式**：服务端从未承载图标字段，本版把这一点明确下来 —— 图标不再随同步发送，也不会在拉取时被重置为默认值（你本机设置过的图标会保留）。**图标跨端显示**属于后续新功能，不在本版范围。
- 冲突面板可能出现**比以前多**的记录 —— 这正是本版目的（以前是静默丢失）。处理完徽标会递减。
- 旧版服务端的「用云端的」会显示「将在下次同步后生效」，需要服务端升级后才会真正落本地。
