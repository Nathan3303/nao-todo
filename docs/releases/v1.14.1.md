# 本次更新

**任务优先级多了一档「紧急」，而且别处设好的紧急任务，在这里不会再被显示成「低」。**

## ✨ 更好用了

- **优先级现在有四档**：**紧急 → 高 → 中 → 低**（紧急是新增的最高档）。在任务详情里可以直接选「紧急」；列表、表格、看板、详情里都会用「警报图标 + 文字 + 颜色」三重标记它，不只靠颜色区分。
- **紧急任务排最前**：按优先级排序时，紧急永远在「高」之前。
- **导出也对了**：导出任务说明时，紧急任务写成「紧急优先级」，不再是「低优先级」。
- **别的地方也认得它**：日历任务条左缘的颜色、搜索结果里的优先级圆点与悬浮提示、搜索筛选栏的短名，都能正确显示「紧急」。

## 🐛 修好了

- **紧急任务被显示成「低」**：如果你的任务在其它端（或服务端接口）被设成紧急，本端以前会把它当成「不认识的值」直接归到「低」—— 现在正确显示。
- **个别情况下优先级标签会报错空白**：遇到不认识的值时不再抛错，安全回落到默认档。
- **搜索里的「紧急」筛选**：以前在地址栏里写「紧急」会被当成无效值忽略，现在能正确过滤。

## ⚠️ 请留意

- **看板的「按优先级分组」目前还用不了**（这是**之前就存在**的问题，不是本版引入）：切过去会看到几列空着，往里拖任务还可能把任务状态写坏。**建议继续用「按状态分组」**，紧急任务在那里照常出现在待办/进行中/已完成列，并带「紧急」标记。已登记为待修项。
- **移动端暂时还不显示「紧急」**：移动端属于另一套代码，改动需要单独授权，本次没有碰。
- **「紧急」和「高」颜色相近**：两者是同一套红色系，靠图标（警报 vs 三柱）和文字区分 —— 暗色下如果觉得难分，请反馈，我们换图标。

## 📦 更小更快

- 没有新增依赖，也没有新增设计色值（沿用既有语义色）。
- 优先级排序与显示仍然只有一个「权威定义」，新档位不会在哪个页面漏掉。
