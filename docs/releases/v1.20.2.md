# v1.20.2 —— 变更历史换成"活动流"，一眼看清改了什么

## 一句话

变更历史不再是"左侧一条彩色竖线 + 一段文字"，改成常见的时间线样式：**每条一行** —— 左边一个来源圆标（本机 / 云端 / 合并 / 恢复）、中间一句「来源 · 字段名：旧值 → 新值」、右边时间；**按今天 / 昨天 / 更早分组**。

## ✨ 更好用了

- **更好扫读**：一行一件事，来源、字段名、新旧值都在一行里；长内容折叠成一行省略，悬停可看全文，点一下在条目内展开完整差异。
- **按天分组**：今天 / 昨天 / 更早；空的分组不占位。
- **整行都能点、键盘也能用**：每一行就是按钮，Tab 能到、Enter 展开/收起。
- **点击区达标**：底部「更早的记录」按钮原来是 17px 高（低于 40px 的可点下限），现在 **40px**。
- **展开不再顶满屏幕**：单条展开最高占可视区 **32.5%**（以前一条长描述展开能占 **108%**，把列表上下文全顶掉），其余内容在条目内的滚动区查看。

## 🐛 修好了

- **"展开"点了没反应**：归档 / 删除 / 恢复这类没有字段差异的记录，以前也显示「展开」，点开是空白。现在这类条目不显示展开。
- **颜色之外分不清来源**：来源用符号（✎ 本机 / ☁ 云端 / ⇄ 合并 / ↺ 恢复）+ 文字 + 颜色三重区分 —— 去色或红绿色盲下仍能分辨（实测灰度下有两色亮度仅差 5.2，靠符号和文字区分）。

## ⚠️ 请留意

- **入口位置没变**：还是底部「更多」→「变更历史」，打开是对话框。
- **折叠时看到的是省略号**：长内容要展开才看全（悬停也有全文提示），这是为了让列表不被一条撑满。
- **已知边界**：记录多到接近满屏时，展开某一条会出现两层滚动区域（滚轮落在展开区会被内层接走）。已登记，后续再优化。

## 📦 更小更快

- 无网络与体积变化；对话框行为不变（三路关闭、焦点归还、打开期间自动刷新不打断）。
