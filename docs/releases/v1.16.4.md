# v1.16.4

**这一版把界面组件库升到 1.15.3，顺手把当年为绕过组件库 bug 写的那层「临时壳」删掉了。** 对用鼠标的人几乎看不出变化；对**只用键盘**或**用读屏软件**的人，导航从此真正可用。

## ✨ 更好用了

### 侧栏导航现在是「真正的链接」

以前鼠标点能跳，但键盘 `Tab` 走不到、`Enter` 按不动、右键没有「在新标签页打开」、读屏软件也不说它是链接 —— 看起来正常，其实只有一半功能。现在它是一条完整的链接：能 Tab 聚焦、回车跳转、右键新标签打开，读屏会念出「链接」。

### 头像加载失败后能自己恢复

网络断了、登录过期、地址 404 —— 头像一旦挂掉，以前**再也回不来**，只能刷新页面。现在只要地址换成可用的（重新登录、重新上传），头像**无需刷新**就会恢复；同一个坏地址不会反复重试（不会闪）。

### 下拉与日期选择器的「清除」成了一个正经按钮

清除图标以前躲在按钮内部，读屏念不出、键盘停不住。现在是独立按钮：能 Tab 停在上面、读屏念「清除选择 / 清除日期」、点一下清空且图标随即消失。

### 开关：一次按键只切换一次

升级前，我们给几个开关自己补了一套键盘处理；组件库新版自带这套能力后，两套会**同时**响应 ⇒ 一次按键跳两次。这一版把自建那套全部拆掉，改由组件统一提供，行为回到「按一下、变一次」。

## 🐛 修好了

### 日期选择器的清除键压住了日历图标

给任务设置开始 / 截止时间时，右端的清除 ✕ 会和日历图标**叠在一起**。原因是我们自己的一段样式把「给清除键预留的空位」一并抹掉了。已修：清除 ✕ 与日历图标分开，点击、键盘都正常。

## ⚠️ 请留意

- **只选日期时，时刻显示为 `00:00`** —— 给任务选时间时，如果你**只点了某一天、没有调整时和分**，显示的时刻是 `00:00`（以前会带上「当前那一刻」）。已有完整时间的任务改日期后，时刻**保持不变**，不会被挪走。
- **侧栏 4 个图标入口的外观应当与升级前完全一致**。万一个别图标项的方块尺寸或颜色看着不对，请反馈 —— 这类问题不会报错，只能靠眼睛发现。
- **面板里日期选择器的触发条应当撑满整行**。若变窄或错位请反馈。

## 📦 更小更快

体积基本不变：六项产物指标均 `<1%`，最紧的一项是 CSS 原始体积 **+0.96%**（来源 = 组件库新版为「清除键独立」补的样式）。
