# v1.22.0 —— 键盘党版：命令面板、任务归档、搜索大提速

## 一句话

这次带来了 `⌘/Ctrl + K` 命令面板与 `?` 快捷键一览、单个任务的归档入口，以及搜索的整体翻新 —— 大量数据下**打开搜索从 36 秒降到 1 秒内**，还能按截止日筛选、按五种方式排序。

## ✨ 更好用了

- **命令面板**：按 `⌘K`（Windows 是 `Ctrl+K`）打开，输入即筛，`↑↓` 选、`Enter` 执行、`Esc` 关闭。面板里的内容**就是当前页面真正能用的命令**，不会列出"按了没反应"的项。
- **快捷键一览**：按 `?` 打开，按分组列出所有生效的快捷键（Mac 上显示 `⌘`，其它平台显示 `Ctrl`）。
- **任务可以单独归档了**：任务详情底部「更多 → 归档此任务」。归档后它从列表/日历里消失，想找回就到搜索页打开「包含已归档」。
- **搜索重做**：
    - 结果默认先给 50 条，底部「显示更多」每次加 50，不再一次性把页面撑爆；
    - 可以按**更新时间 / 截止日 / 优先级 / 名称**排序，各自支持升降序；
    - 新增**截止日区间**筛选（可只填一头），并可选「包含无截止日」。
- **搜索变得很快**：5 万条任务的本机数据，打开搜索从 **35.8 秒降到约 0.9 秒**。

## 🐛 修好了

- **大库搜索卡到不可用**：以前搜索要分 50 页、每页都重读整库 ⇒ 5 万条要 36 秒；现在一次读取即可，首屏不到 1 秒。
- **命令面板 / 快捷键帮助原来按了只打日志**：现在两项都真的能用了。
- **「归档任务」这个预期落空**：以前只能归档整个清单，单个任务没有归档入口，现在有了。

## ⚠️ 请留意

- **搜索结果默认只显示 50 条**，是刻意设计（先快后按需展开）；底部有「显示更多」，不会丢结果。
- **归档后的任务只从搜索页找回**：搜索页打开「包含已归档」即可看到，列表和日历默认看不到它们。
- **清单本身处于归档状态时，里面的任务为只读**：详情里不会显示「归档」也不会显示「取消归档」，而是给一句说明。想单独救回某条任务，仍需先取消归档整个清单（这是既有约定，本次没有改变）。
- **命令面板内容随页面变化**：在日历页会看到日历的快捷键，在任务页看到任务相关的 —— 这是刻意设计，只列当下真正生效的键。
- **桌面端的应用内更新从上一版（v1.21.0）开始生效**：本次发布后，装 v1.21.0 的用户会在下一版开始收到自动更新提示。

## 📦 更小更快

- **搜索**：5 万条本机数据下，打开搜索页 **35.8s → 约 0.9s**（数据就绪口径，不含首帧渲染）。
- **内存**：一次性装入 5 万条任务的增量约 **+26 MB**（约 541 字节/条）。
- 清理了一批再也用不到的历史组件与文案键（对功能无影响）。

## 技术细节（可略过）

- **搜索管线**：从「100 条/页 × 最多 50 页」的多页 sweep 改为「单次大页扫描 + 触顶探测」，并只在搜索上下文触发（任务列表/日历/后台刷新不受影响）；计数改为轻量谓词一遍扫描（5 万条中位 13.4ms），只对展示窗口做完整排序与高亮。子任务补拉加 10s/轮预算，避免大库无界补拉。
- **仓储根因未修（已挂 Issue #376）**：`persistence-local` 的 `list()` 与 `limit` 无关地整表解密（5 万条单次 ~768ms）；本次是绕开而非治本。
- **命令系统**：命令面板与快捷键帮助**全部由命令注册表派生**（无第二份清单）；日历/日视图的键本就通过 `useShortcut` 注册进同一注册中心（挂载注册、卸载注销），因此帮助页天然「只列当前页面生效」的键。新增可选字段 `i18n` / `hidden` / `gesture`；删除死命令 `app.modal.close`（`scope: 'modal'` 无进入点）。
- **任务归档**：仓储新增可选 `archive(id)`（同事务写 `archivedAt`、`projectId` 不变、入同步队列、记审计）；usecase 带三条守卫（清单归档硬拒 / 已归档幂等 / 子任务拒绝）；`unarchive` 语义零改动（保留 ADR §15.1 的「移入收集箱」逃生口）。
- **审计裁切根治**：`pruneAuditLog` 加 in-flight 单飞 + 跑完补排，`evicted` 计数改为物理删除数；导出 `flushAuditPrune()` 供测试排空，根治了「单文件连跑 20 次出现 3 红」的跨用例残留 flake。
- **发版硬校验进 CI**：`release.yaml` 的 release job 在创建 Release 前跑 `scripts/verify-release-versions.mjs`，校验 **tag = 三处 `package.json` 顶层 version = 三份 `latest*.yml`**；不一致则 Release 建不出来。脚本用 JSON 解析（不用 `grep '"version"'`，那会误抓 `devEngines.packageManager.version`）。
- **提交前预检**：新增 `pnpm run guard:commit-scope`，阻断「不属于本次提交范围的 tracked 未暂存改动」（防 lint-staged 整树 stash 卷走他人改动，`DEF-160`）。
- **设计基座**：`DESIGN.md` 由 272 行瘦身为 56 行，只保留组件库主题表达不了的约束；视觉值一律取自 `nue-ui` + `nue-ui-theme-shadlike`；对比度阈值由 `scripts/contrast-audit.mjs` 实测（17 组 pair），CI 由 vitest 用例复用同一阈值表执行。
- **门禁**：`vp test --run` 491 文件 / 3985 例 / 0 红 · `vp check` 0 error（1649 文件）· **七**守卫 rc=0 · 双端构建 rc=0 · 移动端红线 0 行。
- **版本号**：root / `apps/web` / `apps/desktop` `1.21.0 → 1.22.0`；`packages/*` 有源码改动按近批惯例不单独 bump。
