# 本次更新

**这一版专修桌面端（macOS）：装上是 NaoTodo 自己的图标，打开不再提示「已损坏」。**

## 🐛 修好了

- **Mac 版图标**：Dock、访达、应用切换器里现在显示 NaoTodo 自己的图标了（之前一直是 Electron 的默认图标）。
- **Mac 版打不开**：之前装好后打开会提示「已损坏，无法打开。您应该将它移到废纸篓」，现在会正常启动。

## ⚠️ 请留意

- **Mac 版第一次打开仍需放行一次**：我们没有向 Apple 购买开发者签名认证，系统还会拦一道。你会看到「无法验证此 App 是否包含恶意软件」之类的提示 —— 二选一放行：
    - 打开「系统设置 → 隐私与安全性」，页面下方会出现这个应用的提示，点「仍要打开」；
    - 或在「终端」里执行一次下面这行，再双击打开：

    ```bash
    xattr -dr com.apple.quarantine /Applications/nao-todo.app
    ```

    **只需一次**，之后正常双击即可。上面这行命令的意思是：去掉系统给这个应用打的「从网上下载、尚未获得信任」标记。

- **Mac 用户请下载文件名里带 `arm64` 的 dmg**（Apple 芯片机型）。Intel 芯片的 Mac 目前还没有安装包。
- **Windows / Linux 用户**：安装包会重新出，功能与上一版一致，无行为变化。
