# v1.12.2（2026-09-28）

本版本为**冲突 UX 收口**：修复「处理冲突后计数不消失」，统一「冲突 N」计数口径，并把冲突界面按 **C 端消费级** 定位做了一轮**对话框化 + 可读性**重构。web 与 desktop 行为一致，**移动端零改动**。

- **Tag**：`v1.12.2`
- **版本**：root `1.12.1 → 1.12.2` · `apps/web` `1.12.1 → 1.12.2` · `apps/desktop` `1.12.1 → 1.12.2` · `packages/shared` `1.4.0 → 1.4.1` · `packages/infrastructure` `0.8.1 → 0.8.2`（`apps/mobile` / `packages/presentation-react` 零改动）
- **协同**：仍建议与服务端 `nao-todo-server` `5cb30c5`+ 配套（OCC + 派生行回传）

## 行为变更（请留意）

1. **「冲突 N」计数口径：由「journal 条目数」改为「待处理对象数」**（`T346`）。同一对象（`表:实体`）的多条冲突记录只算 **1 项** ⇒ **徽标数字 = 冲突面板左栏行数**；处理完一个对象后计数 **−1**（不是 −N），全部处理 ⇒ **0**（徽标隐藏）。计数仍只由 journal 派生（**单一真源**，未引入第二计数源），重启后按同一口径恢复。
2. **冲突面板形态：内嵌列表 → 模态对话框**（`T338`）。入口为状态栏「冲突 N」；打开后为 `role="dialog"` / `aria-modal` 的模态框（左右分栏，窄窗堆叠）。**`×` / Esc / 底部「关闭」三条路径均关闭对话框并把焦点归还入口按钮**（`T347`）。
3. **技术字段不再可隐藏（常显、次要样式）**（`T339`）。原「显示技术字段」开关移除；`updatedAt` / `revision` / `id` 等排在普通字段之后、加轻分隔，以次要色 + 更小字号呈现。
4. **偏好同步失败语义本版无变化**：沿用 `v1.12.1` 已登记行为（偏好入队失败 ⇒ 报错并回滚，非静默）。

## 修复

### 处理冲突后「冲突 N」计数不递减 / 不归零（`T331`）

- **现象**：在冲突面板点「保留我的修改」或「用云端的」后，左下角仍显示原「冲突 N」；**重启应用才消失**。
- **根因**：计数与列表**不同源** —— 列表读 journal（实时），计数读状态面快照；两条恢复动作只删 journal 条目、刷新列表，**未把 journal 的剩余数量写回状态面**。
- **修复**：恢复动作完成后用**同源剩余对象数**写回计数 ⇒ 处理 1 个对象计数 −1、全部处理 ⇒ 0（徽标隐藏）。计数与列表始终一致（详见行为变更 1）。

### 冲突界面可读性与对比度（`T347`，qa 视觉走查五项）

- **① 浅色三态标签 / 符号按**卡片真实底色**重算达标**：失败项全部是绿色系，且底色是卡片 `--nue-primary-color-100`（`#e6e6e6`）而非白底 —— 原注释按白底估算（「4.95 / 6.67 / 8.97」）不成立。修法 = 绿色系小文本 / 符号由 `-90` / `-80` 提级至 `--nue-success-color-100`（**5.29:1**）、橙色符号由 `-80` 提级至 `--nue-warning-color-90`（**5.34:1**）；红系沿用（`-90` = 7.19、`-80` = 6.07）。
- **② 深色技术卡片改主题 token**：背景由写死 `#efefef`（深色下突兀亮块、且内文仅 2.48:1）改为 `var(--nue-primary-color-100)`（深色 = `#262626`）⇒ 卡片内次要文本深色 **5.31:1** / 浅色 **4.60:1**，两套均达标。
- **③ `×` / Esc / 底部按钮三条关闭路径一致归还焦点**：根因 = 对话框 `Teleport` 到 body，点击冒泡到 `window` 被下拉面板（`transparent`）误判「点外部」而**关掉父面板**，`@close` 随即把焦点移到轨道按钮（Esc 是 keydown、不触发 click ⇒ 本就正常）。修法 = 在对话框 overlay 截断点击冒泡 ⇒ 面板保持打开、焦点回到入口按钮。
- **④ 空态图路径改 `assetUrl('/images/...')`**：原 `/public/images/...` 在生产无 `dist/public/` 目录 ⇒ **404**（dev 能 200 是 Vite 按项目根解析的巧合）；改为 `assetUrl('/images/notaskhere.webp')` / `assetUrl('/images/todo.webp')`，与仓内既有 6 处调用方一致。**已核生产产物无 `/public/images` 引用**。
- **⑤ 底部「关闭」语义修正**：由「只清空右栏对比」改为**关闭对话框**（与按钮文案一致；原行为会让用户以为点了就关，实际对话框仍在）。

> 对比度为**按主题 token 计算值**（sRGB 线性化，与 qa 走查同口径）—— 浅色：added 5.29 / changed 5.34 / removed 7.19（标签）· 6.07（符号）· 技术文本 4.60；深色：added 10.18 / changed 8.05 / removed 6.24（标签）· 5.36（符号）· 技术文本 5.31。qa 在最终构建上二次实测复核。

### 同毫秒时间戳 test flake 加固（`T333`）

pull 侧 LWW 用严格 `>`，用例若与本地 create 落同毫秒会被判「本地胜」跳过而偶发红；统一让远端时间戳严格更晚。**仅测试改动，无运行时影响**。

## 改进（冲突 UX C 端化重构 · `T332` / `T338`–`T346`）

- **对话框 + 左右布局**（`T338`）：状态栏「冲突 N」⇒ 打开模态对话框；**左栏 = 待处理对象（一行一对象）**、**右栏 = 选中对象的差异详情 + 动作区**（sticky 底部）；≥900px 左右分栏，**<900px 自动堆叠**。
- **左栏一行一对象 + 标题按对象数**（`T346`）：同一实体多条记录只占 **1 行**；对话框标题计数 = 对象数（与徽标 / 行数一致）；右栏「对象信息」仍展示该对象的**记录条数 + 全部冲突类型（去重）**，信息不丢失。
- **横向差异卡片 + 三态三重冗余**（`T332` / `T338`）：字段差异改为**逐字段卡片横向流式**（非表头 + 行 + 网格）；增 / 删 / 改以**颜色 + 符号（`+ − ~`）+ 文字标签**三重承载（灰阶 / 色盲下仍可辨）。
- **文案去术语、字段名说人话**（`T340`）：`我的修改` / `云端最新` / `用云端的` / `保留我的修改`；冲突类型改说人话；字段名映射为可读标签（`name`→名称、`updatedAt`→更新时间…），未映射字段走可读回退，**不裸露技术键名**。
- **技术字段常显 + 次要样式**（`T339`）：移除开关；技术字段排在普通字段之后、轻分隔、次要色更小字号。
- **三态统一 `LoadingError`**（`T342`）：加载 / 空 / 错误 / 无字段差异统一用 `LoadingError` 承载（四态齐备）；错误态附「重试」。
- **状态栏面板按类别分区**（`T343`）：概览 / 数据 / 待处理 chips / 冲突 / 错误 / footer，不再全部竖排。
- **密度与层级**：字段行高 18 → 24px、行距 4 → 8px；组头 / 条目 / 字段三层用色重与留白分层（败方 = secondary、服务端 = primary + medium）；条目点击区 ≥40px；覆盖类动作给安全提示，主按钮突出、次按钮弱化。
- ⛔ 仅展示层：**不改**恢复动作 / 合并语义 / 计数真源。
