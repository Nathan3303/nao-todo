## 修复

### 处理冲突后「冲突 N」计数不递减 / 不归零（`T331`）

- **现象**：在冲突面板点「保留服务端版本」或「以我的版本重试」后，左下角仍显示原「冲突 N」；**重启应用才消失**。
- **根因**：计数与列表**不同源** —— 列表读 journal（实时），计数读状态面快照；两条恢复动作只删 journal 条目、刷新列表，**未把 journal 的剩余条数写回状态面**。
- **修复**：恢复动作完成后用**同源剩余条数**写回计数 ⇒ 处理 1 条计数 −1、全部处理 ⇒ 0（徽标隐藏）。计数与列表始终一致。

## 改进（冲突记录 UI/UX · `T332`）

- **按对象分组**：同一实体（`表:实体`）的多条冲突归为一组，组头显示「表名 · 标题 · N 条冲突」，默认展开、可折叠；标题取不到时**优雅降级**（名称/标题 → ID → 本地化类型 → 「未知对象」），**不出现空白或 `undefined`**。
- **增/删/改三态高亮**：以**颜色 + 符号**（`+ − ~`）**双承载**（叠加左侧强调条），不单靠颜色区分（可访问性）。
- **技术字段默认隐藏、可展开**：`updatedAt` / `revision` / `id` 等默认不展示，点「显示技术字段」后再显示。
- **长值截断可展开**；**双方来源标注清晰**（「我的版本（败方）」/「服务端版本（当前）」）；仍**只显示有差异的字段**。
- ⛔ 仅展示层改动：**不改**恢复动作、合并语义与计数逻辑。

## 改进（冲突面板重构 · `T338`）

- **入口改为对话框 + 左右布局**：状态栏「冲突 N」⇒ 打开模态对话框；**左栏 = 冲突记录**（按对象分组、可滚动、选中高亮、组头「表名 · 标题 · N 条」）；**右栏 = 选中条目 diff**（沿用 T332 渲染）+ 动作区（sticky 底部）。
- **响应式**：≥900px 左右分栏（左栏 `clamp(240px,30%,360px)`、右栏 `flex:1`）；**<900px 自动堆叠**（列表 30vh + diff），对话框 `94vw × 90vh`。
- **可访问性**：`role="dialog"` + `aria-modal="true"`；Esc 关闭（NueDialog 原生）；打开后焦点入框、关闭后归还触发按钮；左栏条目键盘可遍历、选中高亮。
- **对比度修复**：三态色由 `-60` → `-80`（色条 + 符号，图形 ≥3:1，实测 3.78 / 5.31 / 7.35）与 `-90`（文字标签，实测 4.95 / 6.67 / 8.97，均 ≥4.5:1）；原 `--nue-success-color-60`（`#22c322`）仅 **2.36:1** 不达标，已修。
- **三重冗余（必需）**：颜色 + 符号（`+ − ~`）+ **文字标签**（新增/删除/修改）—— 实测**去色（灰阶）三态对比度均 <3:1**、**protanopia/deuteranopia 下 warning↔error ΔE 仅 7.4 / 9.1**（橙/红几乎重合）⇒ 仅颜色不可辨，尤其影响色觉差异用户。
- **密度与层级**：字段行高 **18 → 24px**、行距 **4 → 8px**；组头 / 条目 / 字段三层用色重与留白分层（败方 = secondary `#666`、服务端 = primary `#333` + medium）。
- **新增 i18n 键**：`fieldAdded` / `fieldRemoved` / `fieldChanged` / `selectHint`；并启用 `sync.conflict.title`（对话框标题）。
- **第二轮反馈（T339）**：
    - **两栏分隔线**：左 / 右栏之间竖向 **1px**（既有 `--nue-border-color`）；**<900px 堆叠时改为横向分隔**（复用左栏下边框，不新增控件）。
    - **左栏精简**：**只保留**「对象名称（组头）+ 冲突类型（条目）」；被移出的元信息（类型 / 实体 ID / 冲突 ID / 发生时间 / 版本时间）在**右栏「对象信息」**小节可见（**不丢信息**）。
    - **技术字段始终显示**：移除「显示技术字段」开关；技术字段排在普通字段之后、加轻分隔，并以**次要样式**（次要色 / 更小字号）呈现，避免抵消降密度效果；连带删除 `showTechnical` i18n 键与 `visibleDiffs` 死代码。
- **C 端化（T340）**（用户定位纠正：本应用是 **C 端消费级应用**，对话框不得按「后台/管理台」做）：
    - **去工具感**：逐字段**卡片**（无「表头 + 行 + 网格」）+ 圆角 / 分区留白 / 舒展字号；列表与组头**点击区 ≥40px**；主按钮突出、次按钮弱化。
    - **左栏进一步精简**：**只显示对象名称**；冲突类型/状态/时间/ID/字段差异**全部进右栏详情**（硬约束：信息只迁移、不丢失）。左栏宽度 `clamp(200px,26%,320px)`（把空间让给详情）。
    - **文案去术语**（C 端说人话）：`我的修改` / `云端最新` / `用云端的` / `保留我的修改`；冲突类型全部改说人话（如「云端已有更新」「云端没收到你的修改」）。
    - **字段名说人话**：新增「字段 → 可读标签」映射（`name`→名称、`archivedAt`→归档状态、`updatedAt`→更新时间…），未映射字段走**可读回退**（拆词 + 首字母大写）；⛔ 不裸露技术键名。
    - **安全感**：覆盖类动作给一句话**安全提示**（「选择后以你选定的版本为准」）；「保留我的修改」为主按钮、「用云端的」为次按钮。
    - ⛔ 未引入新色板/新组件体系（沿用既有 `nue-*` token 与组件）。
- ⛔ 仅展示层：**不改**恢复动作 / 合并语义 / 计数（`T331` 同源归零在对话框容器下仍生效，含回归测试）。
