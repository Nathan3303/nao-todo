# 本次更新

**这一版：搜索筛选栏更好懂了 —— 少了一个没有文字的开关，「包含已归档」开关有了文字、也能用键盘操作，下拉菜单更紧凑，筛选按钮会直接告诉你「选了哪些」。**

## ✨ 更好用了

- **筛选按钮会显示你选了什么**：以前按钮上只有一个数字（如「优先级 2」），现在直接写出名称（如「优先级：高、中」）；勾了三项以上时显示前两项 + 剩余数量（如「状态：待办、正在进行 +2」），标签还会带上自己的颜色小圆点。维度名比已选名称淡一档（灰色）、已选名称更实一些，**一眼就能看出这一栏有没有在筛选**。
- **「包含已归档」开关有了文字，也能用键盘**：开关右边现在写着「包含已归档」，点这行文字就能开关；用 Tab 可以选中它，按空格或回车也能切换（以前只有鼠标能用，读屏软件也读不出它是开还是关）。
- **下拉菜单更紧凑**：菜单里每一项之间的距离收紧一档，任务、日历、搜索三处的下拉看起来一致，一屏能看到更多选项。

## ⚠️ 请留意（这些地方行为有变化）

- **搜索里不再有「纳入已删除 / 已放弃」开关**：从这一版起，**已删除、已放弃的任务不会再出现在搜索结果里**。如果你以前靠这个开关去翻已放弃的任务，跟我说一声，我另开一个更合适的入口。
- **以前保存过的「常用搜索」或旧链接里如果带了这个条件**：打开时该条件会被**自动忽略**（不会报错，只是不再生效），其它条件照常。
- 筛选栏左侧少了一个开关，位置由「包含已归档」补上，「清空筛选 / 保存为常用搜索」的位置与样式不变。
