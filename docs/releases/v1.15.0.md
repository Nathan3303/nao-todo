# 本次更新

**登录相关的几个坑一次收口：改过密码后桌面端不再被「密码错」卡死，登录过期后也不再留一堆无效请求。**

## ✨ 更好用了

- **桌面端在别处改过密码，也能自己救回来**：以前会遇到「网页能登、桌面端说密码错、进不去」的死局。现在：数据本来就不需要再解锁的，直接进；需要解锁的，可以用**旧密码**解开（解开后会顺手换成新密码的包裹），实在不行可以选「重建本地数据」。
- **注册后回到原页面**：从分享链接点进注册，注册完成会落到你本来要去的页面，不再被送回首页。
- **隐私模式也能登录**：浏览器不给存设备标识或主题偏好时，会降级继续跑，不再直接失败。

## 🐛 修好了

- **「本地数据解锁失败，请检查密码」这句误导**：现在会说明真实原因（密码可能已在其它设备改过）并给出下一步，而不是让你怀疑输错了。
- **登录过期后还在一直发请求**：会话结束后后台同步立即停手，不再带着空凭证反复撞接口（日志里那串 401 会消失）。
- **会话失效的清理「一半一半」**：以前不同入口清的东西不一样（有的清了、有的留着、保险库还开着）。现在统一成一套固定动作。
- **桌面端初始化被执行两次**：两套「已处理过期」的记账互相不知道，现在收敛成一套，一次只处理一次。

## ⚠️ 请留意

- **会话失效时，本地保险库会被锁定**（以前不锁）。下次登录时用账号密码自动解开，**不需要单独再输一次**。
- **「重建本地数据」会丢尚未同步到服务器的本地改动** —— 点它之前会二次确认，请看清提示。
- **到期 / 被顶号时暂时还没有提示文字**（下一版补「登录已过期」「已在其它设备登录」的横幅）；本版只保证行为一致地回到登录页。
- 移动端本次没有任何改动。

## 📦 更小更快

- 没有新增运行时依赖。
- 认证相关的判断与请求头拼接都收成了单点实现，后续不会再出现「这个入口清了、那个没清」。
