# 本次更新

**看板现在能翻页了：每列滚到底会继续加载，加载完显示「没有更多了」。**

> 之前看板其实只显示「全部列加起来的前 20 条」—— 任务一多，大部分卡片根本看不到（188 条任务时约 **89% 看不到**）。这一版修好了。

## ✨ 更好用了

- **每列各自翻页**：滚到某一列的底部，就加载该列的下一批（每页 20 条），其它列不动；到底是「没有更多了」。
- **列头数字变成「这一列共有多少条」**：以前显示的是"已经画出来的条数"，现在能直接看出"这列一共多少、还有多少没看到"。
- **刷新 / 改排序 / 改筛选 / 切分组，都会回到第一页**：换了条件就从第一屏重新开始，不会出现「筛完只剩 3 条却停在第 5 页」。
- **拖拽和新建不会打乱你已经翻到的位置**：拖走一条只减 1，新建的任务直接出现在目标列最上面，不会把你打回第一页。
- **断网也能翻页**：分页查的是本机数据，不额外请求服务器。

## 🐛 修好了

- **看板只显示前 20 条**：这个毛病从 2026-04 就有（历史上所有版本都带着），看板的"加载更多"其实是个空函数，触底永远不触发。
- **「按优先级」里「低」列漏任务**：优先级为空或存了非法值的任务，以前在「低」列查不到；现在会归到「低」列显示（不会改动库里原来的值）。

## ⚠️ 请留意

- **列表 / 表格按「低」筛选，现在也会带出「优先级为空或非法」的任务** —— 与看板「低」列口径统一，是刻意的（更正确），但确实是行为变化。
- **看板列头的数字含义变了**：从「已加载条数」变成「该列总数」。
- 每一列底部现在会显示「没有更多了」（英文界面是 `No more tasks`）。
- **「没有更多了」的前提是本机数据已同步完整**：如果同步还没跑完，可能先看到「没有更多了」，等同步完再翻就有 —— 这一点与列表视图一致。

## 📦 更小更快

- 没有新增运行时依赖。
- 每一列各自查询本机数据，不会因为翻页而多打服务器；三处清单页（任务页 / 普通清单 / 标签页）共用同一份实现。
