# 本次更新

**侧栏、清单和标签这些导航项，现在能用键盘走了，也能中键/按住 Ctrl 点开新标签。**

## ✨ 更好用了

- **键盘导航通了**：左侧导航（任务 / 日历 / 番茄钟 / 搜索）、番茄钟侧栏、任务侧栏里的内建清单、以及你自己建的清单和标签，都能用 **Tab** 逐个选中、回车进入。
- **能开新标签了**：中键点击或按住 Ctrl 点击导航项，会在新标签页打开（以前点了没反应）。
- **读屏软件会念出名字**：图标型的导航项补上了可访问名称，不再只念「链接」。
- **键盘聚焦时看得见**：用 Tab 走的时候会显示一圈明显的焦点框（鼠标操作不会出现，不影响观感）。

## 🐛 修好了

- **已经登录成功、却还显示「登录已过期」**：上一次的提示状态没被清干净，现在从登录、设置页登出、桌面端解锁门登出、其它标签页登出，都走同一个清理入口，不会再残留。
- **未来新增登出入口容易漏清**：清理逻辑收敛成唯一入口，漏清会被测试直接抓到（已有对应用例兜住）。

## ⚠️ 请留意

- **任务侧栏最下方的「已归档」入口仍不能用 Tab 选中**（鼠标可点）。它和这次修的那批不是同一类：它是「点击触发」而不是「跳转链接」，改法会动到交互语义，所以留到单独一版处理。
- **焦点框是这一版新出现的视觉**：只在键盘操作时显示，颜色与站点主色一致。
- 上游组件库的这个缺陷仍然存在（`nue-link` 的 `route` 用法不产出 `href`），我们这一版是在本仓绕开；等上游修好后可以回退本仓的绕法。

## 📦 更小更快

- 没有新增运行时依赖；导航项的样式类名与上一版**逐字一致**，外观零变化。
