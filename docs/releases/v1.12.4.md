# 简明版（面向用户）

**这一版：日历和番茄专注都更好用了 —— 视图切换搬进了侧栏、任务条一眼看清起止、番茄「结束专注」现在会保存记录了。**

## ✨ 更好用了

- **日历的子视图切换搬到了左侧栏**：月 / 周 / 日 现在在侧栏顶部，当前视图一眼可见。如果你把侧栏收起来了，内容区头部还留着同一个切换入口，不用再展开侧栏。
- **日视图右上角改成「现在」**：点一下回到今天，并把**当前时间刻度线居中**（原来叫「今天」、只跳日期）。月 / 周视图仍是「今天」，点了跳转到今天并**高亮**。
- **任务条一眼看清范围**：任务的**开始端和结束端是圆角**，中间跨天 / 跨周的接续处是**直角** —— 一眼就能看出哪一段是任务的头、哪一段是尾。
- **接续的那一段不再显示「改期」按钮**：避免在中间段误改结束日期（两端的正常改期不受影响）。
- **番茄「今日专注」搬进了左侧栏**：进入番茄页就能看到今天的专注记录，**常展开**，标题行上带**今日总时长**。记录多了**列表自己滚动，「专注概览」固定不动**。侧栏比较窄，所以记录条目改成**两行展示、字号小一档**，更好读。
- **番茄页头部改成悬浮式**：「番茄专注 / 正计时」两页的头部去掉了底边、不再占用高度，计时器位置更靠上（「常用专注 / 专注记录」两页保持原样）。
- **切换番茄子页面不再把任务详情关掉**：开着某个任务的详情，切到「常用专注」或「专注记录」，详情**仍然开着、内容不丢**；再切回来也还在。

## 🐛 修好了

- **评论不显示作者**：新增评论后**立即显示你的昵称和头像**，关掉面板再打开也保持一致。
- **「今日专注」显示成别人的数据**：之前去「专注记录 / 常用专注」查过其它记录后，回到计时页，侧栏会变成显示刚才查的那批记录。现在**始终只显示今天自己的记录**。
- **番茄「结束专注」不保存记录**：以前用这个按钮结束的专注**不会被记录下来**。现在会正常保存，并**立即出现在侧栏「今日专注」**。

## ⚠️ 请留意（这些地方的行为有变化）

- **「结束专注」现在会保存本次专注记录**（此前不保存）。很抱歉：**以前用这个按钮结束的专注没有留下记录，无法找回**。
- **「今日专注」的形态和加载时机变了**：侧栏里改为**常展开**（不再折叠），标题行显示**今日总时长**；进入番茄页就会加载（以前是进计时页才加载）。切到「常用专注 / 专注记录」时侧栏不显示这个区块，但数据一直在，切回即时可见。
- **「番茄专注 / 正计时」的头部样式变了**（悬浮、无底边、不占高度），这是有意调整，**不是故障**。
- 侧栏里那两个按钮（「新建常用番茄专注」「查看历史专注记录」）**暂时不展示**，后续会以别的方式回来。
- 日历里任务条的**圆角 / 直角**是新增的视觉语言（圆角 = 真实首尾，直角 = 跨天接续处），**不是显示异常**。

## 📦 更小更快

- 本版以界面与交互调整为主，桌面端体积无明显变化。

## 技术细节（可略过）

- 版本：root `1.12.4` · `apps/web` / `apps/desktop` `1.12.4` · `packages/presentation` `0.8.0 → 0.8.1` · `packages/shared` `1.4.2 → 1.4.3`（日历 / 番茄 i18n 键）· `packages/domain-task` `1.4.0 → 1.4.1` · `packages/infrastructure` `0.8.2 → 0.8.3`（评论作者）（`apps/mobile` / `packages/presentation-react` 零改动）
- 日历：子视图切换器抽为纯展示件（`segmented` 滑块 Tab 用于侧栏 · `compact` 用于侧栏隐藏时的兜底）；侧栏经 teleport 落在应用级侧栏 ⇒ 原先 `--cal-*` 令牌作用域外，改用 `nue-*` 令牌
- 日历任务条：`is-start` / `is-end` 绑定圆角（4px = `--nue-radius-sm`）；真实首尾端内缩 2px、接续端贴格线；跨月行边界守卫保留（用于判定「是否被截断」）
- 番茄：`getRecords → addRecords` 读路径不再触发 `onRecordCreated`（原会把其它页面查询结果误当新记录 `prepend`，即串数据根因）；计时器新增 `end()`（落库 + 通知 + 回 idle），`reset()` 仍为真取消
- 番茄详情面板：`pomodoros/:taskId?`、`records/:taskId?` 补齐可选参数 ⇒ 子视图切换时 `route.params.taskId` 稳定，`TaskDetailsAdapter` 不卸载、同 `taskId` 不重复 `initialize`
- 侧栏滚动：概览 `flex: none` + 列表 `flex: 1 / min-height: 0 / overflow-y: auto`（滚动条用库自带样式）；记录条目 `compact` 变体（两行 + `--nue-text-xs`）
- 清理：两处 SFC 的 `</script>` 与 `<template>` 之间的游离字符（零行为变化）
- 遗留（已登记）：`aside.vue` 中因移除折叠而未被引用的变量 / 死样式，待用户确认底部按钮去留后再清理
