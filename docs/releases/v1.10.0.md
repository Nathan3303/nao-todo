# v1.10.0（2026-09-24）

> **一句话**：**web 端现在也能离线看、离线改** —— 业务数据与桌面端统一为「本地优先 + 同步回传」，并修掉本轮用户报障的两个**登录阻塞缺陷**（登录成功却被弹回登录页、刷新提示「检入失败」）。

**Tag**：`v1.10.0`（指向 `main` 的合并提交）· 合并 PR：**#89**（`Closes #88`）· 移动端与 `packages/presentation-react` **零改动**。

## 亮点

### 1. web 离线可用（阶段一）

- **离线进入与离线可读**：本地镜像 + 「数据截至 X」新鲜度提示；冷启动离线也能看到数据。
- **安全姿态与迁移**：两端一致的明文本地存储、启动解包/迁移路径、**登出/切换账号按白名单清库**（不再整库 `clear()`）。
- **禁写护栏**：离线写被拦截时给出**可见提示**（不再静默失败）。

### 2. 业务 7 域两端同构「本地优先」（阶段二 2A）

- **写路径统一为「本地优先」**：任务 / 检查项 / 评论 / 清单 / 标签 / 番茄 / 番茄记录 —— 写入**先落本地 → 入同步队列 → 回传**，**离线写不再被拦**。
- **身份域保持例外**（昵称 / 密码 / 头像 / 会话）：仍是远端直连 + 离线明确拦截 —— 因为身份域不在同步表内，离线写只会假成功。
- **冲突可观测**：服务端胜出时**保留本地败方快照**（有界 50 条，存于本地元数据），同步面板新增「**冲突 N**」行。
- **首拉门**：本地无镜像时先等首拉（或超时放行），避免"本地空 = 首屏空"。
- **时间校准**：本地写入时间改用**服务端时间偏移**校正，避免 LWW 误判覆盖。

### 3. 本轮 P0 修复（用户报障）

| 症状                                                                 | 根因（简）                                           | 现在                                                                                                            |
| :------------------------------------------------------------------- | :--------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------- |
| **登录成功后仍被弹回登录页**                                         | 守卫内的"补清上次登出"把**刚拿到的登录凭据一并删掉** | 补清**只清数据、不删当前会话凭据**（按调用语境区分）；以后**无需手动清数据**                                    |
| **刷新提示「检入失败」**（且无法自愈）                               | 检入失败被判为"网络问题"⇒ 不清认证 ⇒ 卡重试页        | **只有明确的网络类**才保留登录态；**其余按凭证失效处理**并跳登录页（未知错误走安全默认）                        |
| **控制台 `EventSource … application/json is not text/event-stream`** | 令牌失效后仍发起 SSE（该报错是下游症状）             | **无令牌不建连**；会话失效由请求层单一出口处理                                                                  |
| （顺带纠正）网关 **502/504**、服务端 **5xx** 时读路径不回退          | 认证分类判据被反向套用到读路径                       | **读路径：只有明确凭证失效（HTTP 401/403 或 10041/10021/10022）才上抛，其余一律回退本地镜像** —— 保住"离线能用" |

### 4. 同步面板与状态展示

- 两端一致的同步状态展示（轨道角标 + 面板）；新增**冲突计数**行与**偏好同步失败**行，且**互不污染**业务计数。

## 兼容与数据

- **升级无需手动清数据**：旧令牌失效会**自动清理并引导重新登录**；此前"登录后不跳转"的残留态本版本会**自愈**。
- 本地库结构与既有版本兼容（**索引库版本未 bump**）；web 与桌面端各自沿用原存储位置。
- 服务端**仅新增字段**（`SyncResult.Outcome`，additive）⇒ 旧服务端不受影响；**服务端契约无破坏性变更**。

## 已知限制（不阻塞发布，均已登记）

- 窄屏（≤445px）web 的抽屉分支**没有同步状态面板**（登记在案）。
- **冲突对比/恢复的可视化界面**留待后续（本版只提供计数 + 败方快照）。
- 同步响应中的 `conflict` / `error` / `skipped` 尚未被客户端消费（其中 `error` 未消费意味着"服务端失败但本地已出队"可能发生，为**既有行为**，已登记）。
- 标签偏好尚未纳入本地优先 ⇒ **不得据此认为「偏好面完全一致」**。
