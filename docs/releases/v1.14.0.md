# 本次更新

**番茄钟这一版修掉一个「看着吓人」的显示错误，并补上「重新开始本周期」。**

## ✨ 更好用了

- **新增「重新开始本周期」**：当你停着、而且本周期已经做完几轮时，圆点旁边会出现这个入口。点它会先问你一次，说明「清空的是本周期进度，**今天的专注记录不受影响**」；确认后本周期从第 1 轮重新开始。

## 🐛 修好了

- **点「结束专注」后圆点会变成四个空圈，看着像进度被清零**：其实你的进度一直在，只是界面显示错了 —— 更别扭的是再点「开始」，它又跳回「第 3/4 轮」。现在停下时也会显示真实进度，文案还会写清楚（例：`本周期已完成 3 轮 · 再 1 轮长休`），**结束专注前后不再跳变**。

## ⚠️ 请留意

- **未开始时的圆点会显示本周期已完成的轮数**（以前一律是空圈）。这不是新规则，只是把真实状态显示出来。
- **「结束专注」仍然不会清空本周期进度** —— 结束的是「这一次专注」，不是「这一组」。想清空整组，请用新增的「重新开始本周期」（会二次确认）。
- 长休息期间圆点仍显示为空（「新周期」），与之前一致。

## 📦 更小更快

- 没有新增任何运行时依赖。
- 轮次那一行的高度被固定住了：入口出现或消失**不会推动**上面的计时器与下面的笔记框，不会出现「界面跳一下」。

## 技术细节（可略过）

- **`DEF-112` 根因与修复**：引擎 `resetToIdle()` 有意不清零 `completedRounds`，而 `resolveRoundIndicator()` 的 `idle` 分支无条件返回 `filled: 0` ⇒ 同一状态两处矛盾（该 `filled: 0` 来自上一批 PM 的验收补正，**是口径判错、非实现问题**，已在 PRD 与缺陷池写明）。修复：`filled = completed >= total ? 0 : completed`（满周期兜住残留），`idle` 文案分两档（`pomodoro.rounds.idle` / `idleProgress`）。
- **业界形态对齐**：中止本次（`结束专注` / `跳过`，不计数）与清空整组（新入口，独立 + 二次确认）分离；依据为方法论原文「Once a Pomodoro is set, it must ring… indivisible unit」「In the event of an unavoidable disruption, take your five-minute break and start again」「After four pomodoros, take a longer break」（Todoist 的 Pomodoro 指南）。
- **新增 `resetCycle()`**：只有一行 `completedRounds.value = 0`，不动阶段 / 任务与模板选择 / 笔记 / 任何已保存记录。入口 `canResetCycle = phase === 'idle' && completedRounds > 0`，用 `v-if` **不渲染**而非 disabled。
- **无障碍**：`role="img"` 只包「圆点 + 文案」（辅助技术会把 `role="img"` 的后代当表现性元素），重置入口是其**兄弟节点**的原生 `button`；`aria-label` 与可见文案同源。
- **`NueConfirm` destructive**：库内确认按钮硬编码 `primary`，故在 `apps/web/src/themes/confirm.css` 以 `.nue-confirm--destructive` 映射到**库自带 error 语义色**（仅换引用、不自造色值；类名由库的 `theme → ${namespace}--${token}` 动态生成，已核非死代码）。
- **不跳动验证**：`min-height: var(--nue-box-size-xs)` 与 `.nue-button--small` 的 `height` 同 token ⇒ 960/720 两档 × M∈{4,10} 四组合下行高 28px、计时器与笔记框位置全一致。
