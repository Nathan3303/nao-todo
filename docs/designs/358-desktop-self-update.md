## 1 信息架构

- 3 层封顶：`设置 › 数据与关于 › 关于与更新`；**不新增第 5 分类**（4 类 IA 与窄屏 4 段是既有契约，`settings-ia` 用例即契约）。
- 落点：`data-panel.vue` 的 `data-setting-id="version"` 行在桌面端**升级为卡片分组**（锚点保留）；**Web 端该行逐字不变**（AC10：无空容器、无占位、无新增请求）。组内两行：**R1 版本行**（永不被状态替换：`当前版本 1.20.3` + `检查更新`）+ **R2 状态行**（状态机渲染，46/58px 定高）；R1 答「我在用哪版 / 能不能查」，R2 答「有没有新版 / 在做什么 / 我要做什么」。

## 2 流程

- **P1 主路径**（AppImage / Windows）：①`检查更新` → ②检查中（按钮 loading+disabled，≤10s）→ ③有新版本（带体积）→ ④`立即更新` → ⑤下载中（进度，**不阻塞**任务/番茄/同步）→ ⑥已就绪 `立即重启更新`/`稍后` → ⑦重启 → 本次启动已完成更新。
- **P2 平台降级**（macOS / deb）：③ 之后动作**替换**为 `打开下载页` + 一行原因，⛔ 无`立即更新`（AC7）。
- **P3 失败**：任一阶段失败 ⇒ `×` + 可读原因 + `重试`/`打开下载页`；按钮**永久可再点**（AC4/5/11）。
- **P4 数据护栏**：仅「已就绪 → 立即重启更新」且**未同步计数 > 0** ⇒ 卡 A（§7）；`取消` 回已就绪并**保留已下载**（AC9）。**P5 已就绪期检查按钮**：disabled + 可见理由（tooltip「重启应用后即可再次检查」），防检查结果覆盖已下载成果。

## 3 视觉规范（Shadcn 尺度 · 桌面密度）

- **度量**：控件高 **30px**（主/次/幽灵同高，文本 12px）· 图标 14 · 圆角 卡片 8 / 按钮 6 / 图标槽 3 · 行内边距 14；**字号**：组标题 15/600 · 行标签 13 · 辅助 12 · 页面级 18/700（层级差 ≥1.25 倍）。
- **更新块 = 边框卡**（`1px --nue-border-color` + radius 8）：R1 / R2 之间 1px 分隔线；⛔ 不加底色、不加阴影（shadcn 的 card + row-divider，替代 v1 纯平面）。
- **R1**：左 `当前版本 1.20.3` 13px + 右 `检查更新`（outline：白底 + 1px 边 + 文本 `-800`）；hint 12px 次要色放上次检查时间。
- **R2**：左 `[符号 18px 槽] 状态文字 13/600` + 第二行 `补充说明 12px 次要色`；动作区右对齐，主按钮 `primary`（近黑底白字）、次按钮 `ghost`/`outline`。
- **进度条**：高 **3px**、宽 240、圆角 2；轨 `--nue-primary-color-100`、完成 `-900`；右侧跟百分比 12/600；**不带语义色**（绿/红会被读成成败）。
- **符号**：只用字符 `– … ↑ ↓ ✓ ×`（定宽 18px + `tabular-nums`）；⛔ emoji / 自绘图标。**状态色**（三重冗余之一）：有新版本 `warning-90`｜已就绪·已是最新 `success-90`｜失败 `error-90`｜中性·进行中 `--nue-secondary-text-color`。
- **侧栏弱提示**：齿轮右上 **6px 空心环 / 1.5px 描边**，外扩 1px 并垫 1px 底色遮罩（不与图标线粘连；`--nue-secondary-text-color`，无填充、无动效），rail 与抽屉两变体同时具备（DESIGN §4.6）；显示 = 有可用更新 **且** 该版本未在设置看过（设备级 `lastSeenUpdateVersion`）；⛔ 红点/脉冲/toast/改齿轮色/扩命中区；Web 与移动端不渲染。

## 5 状态

| `data-update-state`           | 符号·色            | 文字                                         | 补充说明                                                                       | 动作                                |
| :---------------------------- | :----------------- | :------------------------------------------- | :----------------------------------------------------------------------------- | :---------------------------------- |
| `idle`                        | `–` 次要           | 还没检查过更新                               | 上次检查：…（无则省略）                                                        | 无（① 在 R1）                       |
| `checking`                    | `…` 次要 + spinner | 正在检查更新…                                | —                                                                              | ① loading+disabled                  |
| `available`                   | `↑` warning        | 有新版本 1.21.0                              | 下载约 108 MB，装好后重启生效（体积未知 ⇒ 省前半句）                           | ②`立即更新` primary                 |
| `downloading`                 | `…` 次要           | 正在下载更新…                                | 已下载 46 MB / 108 MB（总量未知 ⇒ 只给百分比）+ 3px 条 + `42%`                 | 无；① disabled                      |
| `ready`                       | `↓` success        | 更新已就绪                                   | 重启应用后生效；点`稍后`⇒ 文案不变、去掉`稍后`                                 | ②`立即重启更新` + `稍后`            |
| `up-to-date` / `just-updated` | `✓` success        | 已是最新 1.20.3 / 已更新到 1.21.0            | 上次检查：刚刚 / 这是本次启动装好的新版本                                      | 无（无主按钮，AC6；不落盘）         |
| `failed`                      | `×` error          | 没能检查更新 / 下载没完成 / 更新包校验没通过 | 可读原因（离线 / 超时 / 服务不可用 / 校验未过），⛔ 不含路径、主机名、内部编号 | `重试` outline + `打开下载页` ghost |

- **优先级**：`ready` > `downloading` > `just-updated` > `checking` > `failed` > `available` > `up-to-date` > `idle`；`ready` 期不得被检查结果覆盖（P5）。
- **平台降级 = 动作替换，不是新状态**（防组合爆炸 / 测试面 ×2；`data-update-platform-degraded` 布尔）：macOS「macOS 版需要从下载页安装新版本」；deb「deb 版由系统包管理，新版本要从下载页取」。**体积与进度（PRD §六 留白，本稿定稿）**：**显示**；下载前必给体积（已知时），下载中给 `已下载 X% · a / b`，**总量未知不得写 MB**（⛔ 不显示 0 MB、不编数字）。
- **`LoadingError` 落点（AC12）**：本块无区域级三态替换 ⇒ 仅 `checking` 用 `<loading-error :loading="true">`（`height:auto`）；`idle`/`failed` 属**动作级**内联（DESIGN §4.1 例外；`nue-empty` 带 6rem 插画破坏卡片版式）—— 登记为 AC12 第三句**受控偏离**；若须字面齐用，唯一切换点 = `failed` 改 `:error` + `#error` 插槽。

## 7 可用性

- **点击数**：齿轮 → 检查 → 立即更新 → 立即重启 = 4 击（与 PRD 关键路径同源）；`已是最新` 不出现`立即更新`。**反馈时限**：按下 ≤100ms 出 loading；≤1s spinner；>1s 给进度；进度刷新 ≤2 次/秒。**防误操作**：`仍要更新` 用危险样式、默认焦点在`先同步再更新`；`取消` 保留已下载（AC9）。
- **卡 A（`nue-dialog` 400×210）**：标题「有改动还没同步」→ 正文「还有 N 项改动等待同步。」「更新会重启应用，建议先同步完成。」→ `先同步再更新`（primary）｜`仍要更新`（danger）｜`取消`（ghost）。**断言依赖**：文案 A 前提 = 本地未同步队列**跨重启保留**；若实现结论为「重启丢弃队列」⇒ 换文案 B「这 N 项改动会在重启时丢失且无法恢复」+ 按钮「仍然更新（会丢失改动）」。以事实为准，⛔ 不用含糊措辞掩盖。

## 8 无障碍

- **对比度**：文本 `-90` 档 ≥4.5（4.95 / 6.73 / 8.97）；图形 `-80` 档 3.78 / 5.39 / 7.35 ≥3；⛔ 不用 §4 禁用项（含「次要文字落灰底 4.40」）。
- **键盘 · live 区 · 命中区**：①→②→次按钮 顺序可达，焦点环 2px + 2px offset；卡 A 焦点陷阱 + Esc 与焦点归还；读屏首帧（`loaded=false`）不得播报「已是最新」；状态行 `role="status"` + `aria-live="polite"` **只挂阶段文案节点**，百分比走 `progressbar` 的 `aria-valuenow/valuemin/valuemax/valuetext`（无总量 ⇒ `aria-valuetext="正在下载，进度未知"`）；命中区**桌面指针口径 ≥30px**（原 DESIGN §3「≥40px」为触屏口径，本稿**显式登记偏离**，键盘可达与 focus 可见不降级）。

## 9 实现契约 · 坑 · AC

- **测试钩子**：R2 根挂 `data-setting-id="update-status"` + `data-update-state="<枚举>"` + `data-update-platform-degraded="true|false"`；R1 保留 `data-setting-id="version"` / `data-setting-action="check-update"`。
- **坑**：① 主题**无强调色**（brand hue 0 + s0 ⇒ 纯灰阶），「有新版本」只能 warning；② 语义文字叠任何 tint 底掉到 4 以下（success-90 on 灰 100 = **3.97**，次要文字 on 灰 100 = **4.40**）⇒ 要么无底、要么升 `-100`；③ `--nue-link-color` 浅色 **1.50** 不能当链接色；④ `LoadingError` 的 empty/error = `nue-empty` + 6rem 插画，塞进卡片会破版；⑤ 已就绪期检查按钮只 disabled 无理由 ⇒ 被读成卡死（AC11）；⑥ 状态行高度不恒定 ⇒ 下载完成时按钮跳位（动作区预留 `min-width`）；⑦ 百分比进 `aria-live` 会刷屏；⑧ 平台降级别新增状态；⑨ 体积未知不得编 MB；⑩ 边框 1.61:1 只可装饰，承载语义要另给 ≥3 的描边；⑪ ⛔ 图标位不得用「方块描边」占位 —— 14px 圆角灰描边方块与**未勾选复选框中**同形，会被读成表单控件（本稿 v2 内部评审实际踩到，改为 `nue-icon` 同名线稿图标：账户 / 外观 / 提醒 / 数据 / 齿轮 / 同步 / chevron）。
- **AC 对照**：AC1 →`available`｜AC2 →`ready`+§7｜AC3 →P1｜AC4 →`failed`｜AC5 →`failed`（校验未过单列）｜AC6 →`up-to-date` 无主按钮｜AC7 →§5 平台降级｜AC8 →R1 hint 复用缓存时间、不新增请求｜AC9 →§7｜AC10 →整块 `v-if="isDesktop"`、Web 行不变｜AC11 →P3｜AC12 →§8 + `LoadingError` 落点（含受控偏离）｜AC13 → 双语键值见 copy 文件。
