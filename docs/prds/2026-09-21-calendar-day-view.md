## 4. 用户场景

- **画像**：需要按时刻安排/检查一天任务的用户（时间块规划）。
- **场景卡**：进日历 → 切「日」→ 看到 0–23 时间轴与当天任务条 → 拖动任务条改到别的时段 → 在空白处点一下新建 30 分钟任务 → 拖右边缘拉长到 1 小时 → 看错可撤销。
- **关键路径**：三态切换 → `viewMode='day'` → `buildDayGrid(anchorKey, tasks, …)`（分钟级 span → 列/轨道）→ 渲染时间轴 + 任务条 → 交互（新建/拖拽/拉伸）→ `taskUseCase.update({startAt,endAt})` → 快照联动重渲染。
- **页面状态清单**：加载中 / 加载失败（含重试）/ 空态（当日无任务）/ 有任务 / 锚点日=今天（时间线可见）/ 非今天（时间线隐藏）/ `+N` 折叠态 / 拖拽进行中 / 撤销条可见。
- **边界数据**：时长为 0；时长为 1 分钟；时长 ≥ 1 天（跨日）；仅 `startAt`；仅 `endAt`；无任何时间；开始/结束跨午夜；同一时段 ≥ 5 个任务（`+N`）；`14:37` 这类非 30 分钟整数分钟。

## 5. 业务规则

### 5.1 列模型与头部

- **48 列**，每列 30 分钟（`00:00`–`23:30`）。
- 列头：列索引为**偶数**（对应整点 `HH:00`）显示文本 `HH`；列索引为**奇数**（`HH:30`）**不显示文本**（仅刻度视觉）。首列起于 `00:00`。
- 周起始口径 `weekStart` 对日视图**不适用**。

### 5.2 任务条定位（分钟级，连续）

- 仅当 `startAt` 与 `endAt` **均有效**时进入时间轴：
    - `startMin` = 当日内的分钟偏移（钳制到 `[0, 1440]`）；`endMin` 同理；**跨日 = 裁剪到当日**。
    - `left = startMin / 1440`，`width = max(endMin - startMin, MIN_SPAN_MIN) / 1440`，其中 `MIN_SPAN_MIN = 30`（A4：时长为 0 时最小 1 列宽）。
    - **不吸附**：`14:37` 起 → 条从 14:37 处起（位于 `14:30` 与 `15:00` 两列之间）。
- 续接标记：任务起始早于当日 → 左端续接；结束晚于当日 → 右端续接（与周视图 `cont-start`/`cont-end` 同款语义）。

### 5.3 全天行与归属

- 顶部**「全天」行**（独占一条，不参与时间轴与 `+N`）：收录满足任一者——`endAt` 有效但 `startAt` 无效（R1：归属截止日当日）；仅 `startAt` 有效（A4）；两者皆无（不占任何日期，不入日视图）。
- 跨日任务的**当日裁剪**：若裁剪后覆盖 `00:00–24:00` 整天，则**进入全天行**而非时间轴（避免出现占满整行的长条）。

### 5.4 纵向与溢出

- 纵向沿用**轨道（lane）** 模型：同一时段的多个任务纵向堆叠；超出可视轨道数的部分折叠为 `+N`（触发点与既有 `+N` 一致的交互：点开查看）。
- 轨道分配沿用既有贪婪首次适配；主键为**开始分钟升序**（对应既有的"起始列升序"），同起点内按**用户排序**（TASK-15 口径）。
- 可视轨道数由行高实测（复用 `useCalendarGrid` 的 DEF-2 逻辑）。
- **`+N` 粒度 = 日级单一指示器**（探针 `[0,47]`），点击打开既有当日面板（A6 / D3）。

### 5.5 交互

| 交互       | 触发            | 规则                                                                                                                                                             |
| :--------- | :-------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 快速新建   | 点时间轴空白处  | `startAt` = 点击时刻 **floor 到 30 分钟**；`endAt` = startAt + 30 分钟；复用既有 quick-create 流程与 i18n                                                        |

**`buildDayGrid` 返回契约（冻结）**

```ts
{
  anchorKey: string
  columns: { index: number; label: string }[]        // 48 项；整点 label = 两位小时 '09'，半点 label = ''
  timed: { task: TaskViewObject; colStart: number; colEnd: number; lane: number; isStart: boolean; isEnd: boolean }[]
  allDay: TaskViewObject[]                           // 仅 endAt（无 startAt）∪ 当日裁剪后覆盖整天（§5.3）
  overflow: { key: string; count: number }[]          // 日级单探针：长度 0 或 1，key = anchorKey
  isToday: boolean                                    // = anchorKey === todayKey（注入，便于测试，不依赖真实时钟）
}
```

- 字段名用 **`isStart` / `isEnd`**（与月/周 `CalendarSegment` 同名语义：该跨度真实起/止于本视图内；`!isStart` → 左端续接），**不用**组件 prop 侧的 `contStart/contEnd`。
- `colStart/colEnd` 为**闭区间且允许小数**（ADR C2）：`colStart = startMin/30`、`colEnd = endMin/30 − 1`。
- **DOM 契约（供 C6/C12 断言）**：列头容器 `data-testid="day-columns"`（子节点 48、其中有文本者 24）；时间轴背景 `data-testid="day-axis-bg"`（其内 `[data-col]` 数量必须为 0，即禁 48×N DOM）；未安排入口 `data-testid="day-unscheduled-entry"`。
- **挂载契约（冻结）**：`daily/index.vue` **复用 `CALENDAR_VIEW_CONTEXT_KEY` + Pinia**（与 `monthly/`、`weekly/` 一致），**不得改为 props 直传**。组装点可在既有 `useCalendarMonthly` 内扩 `viewMode = 'day'`（ADR C14）或抽子组合式，但**注入契约不变**。
- **列头结构口径（冻结）**：`data-testid="day-columns"` 的**直接子元素恰 48 个**（奇数位文本为空字符串）；如需改为「24 整点 + 24 刻度」等结构，**须先报 PM**（否则测试漂移）。
- **交互 DOM 契约（冻结，供 T55/T51）**：任务条 `data-testid="day-task"` + `data-task-id="<id>"`；右侧拉伸把手 `data-testid="day-task-resize"`；**交互层 `data-testid="day-axis-track"`**（覆盖在纯视觉的 `day-axis-bg` 之上，承载点击新建与坐标换算；`day-axis-bg` 仍禁子节点，C6）。
- **撤销契约（冻结）**：日视图**复用**共享 `monthly/undo-toast.vue` + `useCalendarSchedule.undoLast`（C9）；在该共享组件**根元素**加 `data-testid="schedule-undo"`（additive，月/周同受益）。
- **坐标基准（冻结）**：分钟映射取 **`day-axis-track` 的 `getBoundingClientRect()`**，用**指针绝对位置** `clientX - rect.left` 换算（**不用 `offsetX`**，因拖拽会跨元素）；`1px = 1440/rect.width` 分钟。
- **写回通道（冻结）**：快速新建 → `taskUseCase.create`（复用既有 quick-create 流程）；拖拽/拉伸 → 既有 `useCalendarSchedule` 内核 + `taskUseCase.update`。拖动期**不得**触发数据刷新（C7），松手才提交；失败 toast + 位置回退（无乐观脏状态）。
- 整点文本格式暂定两位小时（`09`）；若实测偏窄可改 `09:00`，属渲染细节、不影响契约形状。
