# 2026-10-24 设置对话框内容重分类与布局优化 PRD

> **状态**：待开工确认（v1.0，2026-10-24）· **Issue**：[#243](https://github.com/Nathan3303/nao-todo/issues/243) · **批次**：`v1.12.17`（PATCH）
> **来源（成熟度）**：grill 一轮结论（2026-10-24，4 项全选推荐项）+ 落点读码（`apps/web/src/components/settings/**`）。
> **指针**：界面原则 `AGENTS.md`「产品定位与界面原则」· 视觉与 token `DESIGN.md` · 设计方法 `frontend-design` skill（本单指定使用）。
> **硬约束**：移动端红线目录零改动 · 不改任何业务逻辑（提醒/同步/主题行为不变）· 不新增 `nue-*` token（确需新增先报 PM）· 视觉 C 端（禁管理台气质）。

## TL;DR

- **做什么**：把设置对话框从「3 段 + 应用设置里一列混装」重排为**4 类**（账户 / 外观与语言 / 提醒 / 数据与关于），并用「左栏分类 + 右侧分组卡片」的布局重做版式。
- **给谁**：想改主题、改提醒设置、看版本或退出的普通用户（现在得在一列混装里翻找）。
- **成功标准**：任何一项设置**在 2 次点击内可达**；每类只出现同类项；窄屏 320px 下 4 段标签不裁字、不横向滚动。
- **不做什么**：不改任何设置的实际行为（提醒/主题/语言口径零变化）· 不做自动更新（无更新基建）· 不动移动端 App · 不新增设置项以外的功能。
- **为什么做**：`应用设置` 里混着语言、外观、提醒、本地数据长文、版本号五类东西，靠分隔线硬拼；用户找「免打扰」要在一列里扫。

## 一、问题证据

- **内容混装（读码）**：`app-setter/index.vue` 在单个 `nue-div` 内顺序堆放：语言 / 外观（主题）/ 提醒（含通知·声音·免打扰·权限）/ `local-data-notice` 长文 / 版本号，**仅以 `nue-divider` 分隔**，无分组标题。
- **导航粒度不足**：`dialog/index.vue` 只有 3 段（账户与个人信息 / 密码与安全 / 应用设置），「应用设置」承担了 5 类内容。
- **退出登录藏得深**：`profile-updater/index.vue` 里「退出登录」与用户资料混排，且与「注销账户」相邻 ⇒ **危险操作与常规操作同层**。
- **无同步状态入口**：侧栏有同步状态，但设置里看不到「上次同步时间」，排障时要回主界面找。
- **5 Whys**：找不到设置项 ← 一列混装无层级；无层级 ← 当初每加一项就接在列表末尾（提醒在 `T524/T529` 是后加的）；为何一直加在末尾 ← 没有分类契约，只有"再加一根分隔线"；根因 ← **设置对话框缺「信息架构」，而不是缺控件**。

## 二、目标指标

- **指标 1（可达性）**：任一设置项**从打开设置起 ≤2 次点击**可达（分类或段 → 项）。
- **指标 2（唯一归类）**：每个元素只出现在一类里（结构断言：4 类元素清单互不重叠）。
- **指标 3（窄屏）**：320px 宽下 4 段标签**单行不裁字**、无横向滚动；桌面左栏固定宽不挤压右侧（≥ 1024px 时右栏内容不被压到 <320px）。
- **指标 4（零行为回归）**：所有设置项的实际行为与 `v1.12.16` 完全一致（提醒/主题/语言/同步语义零改动）。
- **口径缺口**：无埋点；靠结构测试 + 用户真机视觉勾选。

## 三、范围 / 非范围

**范围（4 类 + 元素归位 + 3 处补齐）**

1. **分类（4 类）**：账户 / 外观与语言 / 提醒 / 数据与关于。
2. **账户**：用户信息（头像/昵称/邮箱，展示 + 编辑入口）/ 密码修改 / **退出登录（独立危险行）**。
3. **外观与语言**：主题（浅色 / 深色 / 跟随系统）/ 语言（中文 / English）。
4. **提醒**：系统通知开关 / 声音开关 / 免打扰时段 / 权限状态与一次性说明（**内容与行为完全沿用 `T529`**，仅换位置）。
5. **数据与关于**：**同步状态一行**（当前状态 + 上次同步时间，只读）/ 本地数据与安全说明（长文，**折叠为一个可展开说明**）/ 版本号 + **「查看更新」外链**（打开项目 Releases 页；无自动更新，文案要诚实）。
6. **布局**：桌面 = 左栏 4 类（图标 + 名称 + 一行副标题） + 右侧分组卡片（组标题 + 组说明 + 子项行）；窄屏（≤445px）= 顶部 4 段分段切换（复用 `segmented-switch`，2 字标签）+ 单列卡片。
7. **视觉方向 = 工作台/工具感**（细则见 §六，按 `frontend-design` 取舍：结构承担信息、不用装饰性渐变/阴影堆叠、强调色只用于选中与开关）。

**非范围**

- **任何设置的实际行为** —— 理由：本单只做信息架构与版式，行为改动会牵连 `T524/T529` 已验收的提醒语义。
- **自动更新 / 下载进度 / 版本检查接口** —— 理由：桌面端无 `electron-updater` 基建，做"检查更新"按钮而不下载会误导；本批只给诚实的「查看更新」外链。
- **移动端 App**（`packages/presentation-react` / `apps/mobile`）—— 理由：红线，不随 Web/桌面需求改动。
- **设置项的新增功能**（如快捷键说明、数据导出、清除缓存）—— 理由：本次未提出，避免范围膨胀。
- **同步面板内容改造** —— 理由：`T115b/r7` 已定稿，本单只显示一行只读状态。
- **主题/提醒设置的存储与同步契约** —— 理由：`T529` 刚验收，不动。

## 四、用户场景

- **画像**：想关掉夜间提醒、或想换深色主题、或想知道"我这台同步到哪了"的普通用户。
- **关键路径**：打开设置 → 左栏点「提醒」（或窄屏点第 3 段）→ 直接看到通知/声音/免打扰 → 改完关闭（立即生效，无"保存"按钮）。
- **页面状态清单**：四类各有内容 / 某类为空（不出现空类，如未登录时的账户组）/ 加载（同步状态行 loading）/ 失败（同步状态行显示失败与重试入口）/ 危险操作确认（退出登录二次确认）。

## 五、业务规则

- **R1 唯一归类**：每个元素只属于一类；跨类内容（如「本地数据与安全」）放「数据与关于」，不复制第二份。
- **R2 无保存按钮**：所有开关/选择**即时生效**（沿用现状），离开即完成。
- **R3 危险操作隔离**：退出登录独立成行、视觉与其它行可区分、必须二次确认（沿用现有确认对话框）；**不得**与常规设置相邻无间隔。
- **R4 诚实文案**：「查看更新」打开**项目发布页**，文案不得暗示"自动更新"；版本号显示当前版本。
- **R5 权限状态单源**：提醒类里的权限状态与一次性说明**沿用 `T529` 的判定与设备级 ack**，本单不改判定逻辑。
- **R6 折叠不失信息**：本地数据说明折叠后标题与一句话摘要可见，展开后全文不删减（信息只迁移、不丢失）。
- **R7 只读不得可编辑**：同步状态行只读（不可在设置里暂停/恢复同步，那是侧栏的职责）。

## 六、NFRs 与视觉约定（工作台/工具感）

- **层级**：左栏 = 导航（icon + 名称 + 一行说明，选中态最明显）；右侧 = 组（标题 + 一句说明）+ 子项行（左标签 / 右控件 / 下方说明文字）。
- **不用装饰**：卡片用 1px 边框 + 表面色区分，**不用阴影堆叠、不用渐变强调**；分隔用留白与细线，不画表格网格。
- **强调色**：只用于「选中分类」「开关 on」「危险操作」，其余一律中性；三态可辨按颜色 + 符号 + 文字三重冗余（`AGENTS.md`）。
- **字体**：沿用既有 `nue-*` 字号阶梯（`--nue-text-xs/sm`、标题用既有 heading 级），**不新增字族**；行高与点击区：子项行 ≥44px、可点控件 ≥40px（`DESIGN.md` §3）。
- **动效**：仅响应式（切换分类的淡入、开关状态变化），**无入场序列动画**。
- **窄屏**：≤445px 用 4 段分段切换（2 字标签：账户 / 外观 / 提醒 / 数据）；320px 不裁字；≤400px 保持贴底形态（沿用 `T521` 窄屏口径）。
- **可访问性**：左栏为 `tablist`、分段为 `group` + `aria-pressed`（沿用 `T521`）；所有控件键盘可达、`aria-label` 完整。
- **性能**：不新增数据请求；同步状态行复用既有 store/状态，不做额外轮询。

## 七、AC

- **验证接缝**：设置对话框结构测试 `apps/web/src/components/settings/dialog/__tests__/`（分类与元素清单、窄屏 4 段、点击切换）+ 复用既有 `segmented-switch` / 提醒设置 composable 的既有用例；视觉与手感由用户真机勾选（QA 出清单）。
- **AC1（主路径·分类）**：Given 打开设置，Then 左栏恰有 **4 类**（账户 / 外观与语言 / 提醒 / 数据与关于），每类带图标与一行说明；点任一类右侧切换到该类内容。
- **AC2（主路径·元素归位）**：Given 逐类查看，Then 元素**只出现在所属类**：账户 = 用户信息 / 密码修改 / 退出登录；外观与语言 = 主题 / 语言；提醒 = 通知 / 声音 / 免打扰 / 权限状态；数据与关于 = 同步状态 / 本地数据说明 / 版本与更新。
- **AC3（可达性）**：Given 任意设置项，Then 从打开设置起 **≤2 次点击**可达。
- **AC4（边界·窄屏）**：Given 320px 宽，Then 4 段标签**单行不裁字**、无横向滚动；≤445px 走分段切换、>445px 走左栏（同一时刻只渲染一套，不得两套并存）。
- **AC5（负向闭环·零行为回归）**：Given 在设置里改主题 / 语言 / 通知 / 声音 / 免打扰，Then 行为与 `v1.12.16` **完全一致**（既有提醒与主题用例全绿、无需改动断言）。
- **AC6（危险操作）**：Given 点「退出登录」，Then 二次确认；确认后按既有登出路径执行；该行视觉与常规设置可区分且与其上下项有明确间隔。
- **AC7（诚实外链与版本）**：Given 点「查看更新」，Then 打开项目 Releases 页（新窗口/外部浏览器）；版本号显示当前版本；文案不含"自动更新"暗示。
- **AC8（折叠不失信息）**：Given 本地数据说明，Then 默认折叠显示标题 + 一句摘要，展开后全文与 `v1.12.16` 文案逐字一致（不删减）。
- **AC9（只读同步状态）**：Given 打开「数据与关于」，Then 同步状态行显示当前状态与上次同步时间，**无**暂停/恢复控件；状态取自既有数据源（不新增请求）。
- **AC10（设计一致性）**：Given 全仓，Then 只用既有 `nue-*` token 与既有组件（不新增 token；新增 i18n 键需 zh/en 齐备 + 类型同步）；三态可辨三重冗余；点击区达标；移动端红线 0。
