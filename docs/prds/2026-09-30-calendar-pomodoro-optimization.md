## 1. 需求原话（用户逐条给出，按时间顺序）

**日历**

1. 「子视图切换组件移动至界面侧边栏」
2. 「日子视图右上角的『今天』改为『现在』」
3. 「月/周子视图重新引入任务末尾的连续标记」

追加（推翻第 3 项形态）：「这样吧，**前后连续的标记还是撤掉**，然后**任务条的开始和结尾改成圆角，大概 4px（0.25rem）**，整个任务条看起来就是**开始圆角，接续直角，最后圆角**，这样比较能让用户一眼看出来这个任务的范围。另外**接续的地方（末尾）就不要显示『改结束日期』的按钮了**。」

**番茄专注**

1. 「将『今日专注』移动至侧边栏显示（NueCollapse）」
2. 「路由优化：各子视图切换不应导致任务详情面板重置（`:taskId?`）」

## 2. 日历页面优化（实现口径与验收标准）

### 2.1 子视图切换移入侧边栏

- 落点：日历页**自带侧栏** `apps/web/src/components/calendar/aside/aside.vue`（经 teleport 落进应用级左栏）**顶部**，其下接分隔线
- 实现：抽出**纯展示件** `components/calendar/view-switch.vue` —— `segmented`（滑块 Tab，用于侧栏）· `compact`（当前视图名 + 下拉，用于兜底）
- **侧栏隐藏兜底（硬要求）**：内容区头部保留 `compact` 入口 ⇒ **不得出现「无切换入口」**
- 视图名 i18n：`calendar.view.month` / `week` / `day` / `viewSwitch`（中英齐备）
- 路由与快捷键**不改**（`view-routes.ts` 映射、`m` / `w` / `←→` 保持）
- 验收：侧栏显示 / 隐藏两态均可切换 · 窄屏抽屉可用 · 「月/周/日」中英正确
- 附带修复：侧栏组件因 teleport 落在**应用级作用域**，原先 `--cal-*` 令牌未定义（规则在、变量无值）⇒ 容器无边框、滑块指示器透明（**无激活色**）⇒ 改用既有 `nue-*` 令牌（⛔ 未新增 token）

### 2.2 「今天 / 现在」

- 月视图 / 周视图：文案「**今天**」· 行为 = 跳转到今天所在周期 + **高亮今天**
- 日视图：文案「**现在**」· 行为 = 回到今天 + **当前时间刻度线在视口居中**（已是今天再点仍重新居中）
- 两处文案走 i18n：复用死键 `calendar.today`（全仓零引用）· 新增 `calendar.now`
- 验收：点击行为（含置中）· 中英文案

### 2.3 任务条「圆角区分首尾」（**推翻**原「连续标记」方案）

- **被推翻的方案**：短横线连续标记（`.cal-cont`）—— 曾按「月/周跨周、日跨本日显示」实现，并按 PM 裁定放开跨月行守卫
- **最终方案**：**真实首端圆角 + 真实末端圆角**（4px = `--nue-radius-sm`）· **接续端直角** 且紧贴格线 · 真实首尾端内缩 2px
- **接续末端不再渲染「改期」触发器**（月 / 周 / 日共用；日视图续接段的右缘**拖拽手柄**按用户早前裁定保持恒显）
- 边界口径：月 = 网格行边界（**跨月行守卫保留**，第二用途 = 判定「该段是否被截断」）· 周 = `weekStart` 偏好的自然周 · 日 = 当日 24h
- 验收：单段两端圆角 / 首段左圆右直 / 中间段两端直角 / 末段左直右圆 · 接续末端无改期入口 · 跨月末行直角

## 3. 番茄专注页面优化

### 3.1 「今日专注」入侧边栏

- 落点：`PomodoroAside` **导航之下**；**仅「番茄专注 / 正计时」两页显示**（其余子页面隐藏）
- 数据：**entry 级唯一 loader**（经 `POMODORO_VIEW_CONTEXT_KEY` 提供）—— 因 loader 含 `AddNewRecordId` 订阅 + `setOnRecordCreated` **单例语义**，不能并存两个实例
- 形态（经用户 2026-09-30 手改后定稿）：**常展开**（不再折叠）· 标题行含**今日总时长** · 底部「新建常用番茄专注 / 查看历史专注记录」两按钮**暂不展示**
- 条目展示：可选 `compact` 变体（**两行** + 字号 `--nue-text-xs`），仅侧栏用法开启；「常用专注」页不传 ⇒ 观感不变
- 滚动：**概览 `flex: none`（固定）** + 列表 `flex: 1 / min-height: 0 / overflow-y: auto`（滚动条用库自带样式）
- 空态 / 加载：统一 `LoadingError`（原自绘空态下线）· 标题去重（`hideHeader` 可选，默认关）
- 验收：结束专注后**即时出现** · 串数据修复 · 两行条目 · 记录多时列表滚动且概览不动 · 侧栏与抽屉两态

### 3.2 子视图切换不重置详情面板

- `pomodoros/:taskId?`、`records/:taskId?` 补齐**可选参数**；侧栏导航改**对象路由**并透传当前 `taskId`
- 详情面板挂在**页面级**（`entry.vue`，`router-view` **之外**）⇒ 切换子视图不卸载；同 `taskId` 不重复 `initialize`
- 范围：**只修番茄页**（用户裁定：search 无此问题）；`calendar` / `search` / `tasks` 仅**回归**
- 决策与影响面详见 ADR `docs/adr/2026-09-30-subview-route-taskid-convention.md`

### 3.3 头部悬浮

- **仅**「番茄专注 / 正计时」：去底边 + `position: absolute`（**不占高度**）+ 点击穿透（`pointer-events: none`，内容 `auto`）
- 「常用专注 / 专注记录」**保持原样**（有意区分：列表页需要标题分隔感）

- 「常用专注 / 专注记录」头部悬浮化（保持原样）
- 改期菜单等其它「今天 / 明天」文案本地化（登记为观察项）
- `setOnRecordCreated` 改多订阅者 / 按 key 注册（观察项，**未立项**）
- `aside.vue` 因移除折叠产生的**死代码 / 死样式**清理（用户注释掉底部按钮而非删除 ⇒ **意图未定，暂不清理**）

## 7. 决策与裁定（含被推翻项与校准）

- 连续标记（短横线）→ **圆角区分首尾**（**推翻**，含「跨月也显示」的守卫放开一并回退）
- 月视图行边界守卫 **保留**（第二用途：判定「是否被截断」）
- 允许对 `PomodoroRecordList` 做**最小 additive 改造**（`hideHeader` 默认关；自绘空态改 `LoadingError`）
- 「今日专注」数据源 = **entry 级唯一 loader**（单例订阅约束）
- 串数据修法 = **C1 修根因（读路径不再触发回调）+ B 仅计时页显示**；**不做**多实例 store / 订阅总线
- 详情面板范围 = **只修番茄页**（其余仅回归）
- 响应式口径 = **固定变体**（不引入容器查询 / JS 测量体系）
- 「结束专注」语义 = **落库**（`end()`）· `reset()` = 真取消
- 两处 SFC **游离字符**顺手清理（零行为变化）

## 8. 遗留与观察项
