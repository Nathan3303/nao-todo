## 3. 决策与口径

- **主题包与组件库各自独立分发**（用户裁定）：⛔ 不为主题修复 bump / 发布 `nue-ui` 组件库
- **撤销入口 = 库扩展插槽**（不自研胶囊）；只保留**一条**活动提示（新条替换旧条）
- **成功的判据必须是业务结果**（`firstErr === null`），不只看 UI 反馈
- **测试布局**：`apps/**` + `packages/**` 下测试文件必须在 `__tests__/`（移动端两处豁免 = 红线）
- **对比度按真实底色实测**（不按注释/白底估算）
