## 1. 主题与背景（5 Whys 摘要）

① 用户改个偏好（昵称/密码/徽标开关）需整页跳转 `/settings` + 二级侧栏 → ② 设置属"偶发低频操作"，不值得占一等路由页与主侧栏上部导航位 → ③ 高频主路径（任务/日历/番茄/搜索）与低频设置混排、挤在侧栏上部 → ④ 深层需求：侧栏只承载高频主路径，低频工具收进就近浮层；设置入口与高频导航在空间上分治 → ⑤ 命题：**设置对话框化 + 入口沉底后，设置打开成本↓、导航区更聚焦**（埋点 P1 遗留验证）。
