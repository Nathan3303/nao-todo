## 1. 主题与背景（5 Whys 摘要）

效率型桌面用户高频翻月/切视图/回今天/快建，日历此前**零键盘支持**（鼠标链路长）；长跨度翻月（如 9 月→次年 3 月）需连点十数次。深层需求：日历应成为**可全键盘操作的排期驾驶舱**，并支持"一击定位任意年月"。

## 2. 目标指标与埋点口径

- 中间指标（P1 遗留）：`calendar.nav_shortcut`、`calendar.title_jump`、`calendar.keyboard_active_users`。
- 口径：快捷键触发以命令 handler 执行计；标题跳转按面板 select 计。
