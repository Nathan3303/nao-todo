> **状态**：**v1.0 已确认开工**（2026-10-26）—— 用户 4 项澄清（§五 D0）+ `R2`–`R4`（断点 720 / 卡片字段 / 首屏上限）**均确认**；Issue [#258](https://github.com/Nathan3303/nao-todo/issues/258) 已立项；**待 qa 用例先行**。
> **任务号**：`T548` 本需求（PM）· `T549` qa（用例先行 + 窄屏断言）· `T550` rd-fe（实现）。
> **来源**：用户 2026-10-26 需求「优化番茄专注记录页面在手机浏览器下的适配性」+ 首轮澄清（痛点 = 整体无法下移 / 首屏被数据卡片占满 / 看不到记录表格）。
> **指针**：落点读码 `apps/web/src/components/pomodoro/records/{index.vue,table-main.vue,stats-cards.vue,filter-panel.vue}`；相关缺陷 `docs/reports/defect-pool.md` 的 `DEF-31`（「内容区头部多兄弟块 ⇒ 内容底部被遮住」布局根因，P3 待复现）；设计基线 `DESIGN.md`（安全区 §9 / 断点与布局）。
> **硬约束**：仅改 `apps/web` 的记录页（含其子组件）· **桌面（>720px）零变化** · 移动端红线零改动（`packages/presentation-react` / `apps/mobile`）· 不改数据/查询/分页口径（无后端改动）· 不新增交互（筛选仍展开、详情仍用既有面板）· 只用既有 `nue-*` token。

## TL;DR

- **做什么**：让「专注记录」页在手机上**能往下滚、看得见记录**：窄屏改卡片列表、压缩首屏统计区、修掉「页面被锁死无法下移」的布局。
- **给谁**：用手机浏览器看专注记录的用户（iPhone Safari / Android Chrome，360px 起保底）。
- **成功标准**：360px 宽下页面可滚到底、首屏能看到记录区、每条记录卡片信息齐（类型/任务/时长/开始时间）且点开详情不丢字段；桌面观感与现在**一模一样**。
- **不做什么**：不动「专注」计时页与侧栏 · 不做筛选折叠/抽屉化 · 不改桌面表格 · 不碰移动端 App · 不引入新依赖与新 token。
- **为什么现在做**：手机上「整体无法下移」= 功能不可用级问题（记录根本看不到），不是观感微调。

## 一、问题证据

- **用户实测（2026-10-26）**：「整体无法下移，首屏被数据卡片占满，而且无法查看到重要的记录表格」——即**页面不能纵向滚动**，且记录列表被挤出可视区。
- **布局结构（读码定位，非最终方案）**：
    - 页面容器 `.pomodoro-records-page` 为 `flex: 1; min-height: 0; overflow: hidden`；
    - 表格容器 `.pomodoro-records-page__table` 为 `flex: 1; height: 100%; overflow: hidden`，内部 `nue-scroll-bar` 再 `flex: 1`；
    - 表格主体 `table-main` 有 `min-width: 760px` + `overflow: hidden` + `text-overflow: ellipsis` + `white-space: nowrap`，且**无任何 `@media`**。
    - ⇒ 窄屏下「统计卡堆叠 + 筛选 + 表格」争抢固定高度，表格被压到近似零高，而外层 `overflow: hidden` 让整页**既不可见也不可滚**。
- **已知同类家族**：`DEF-31`（「内容区头部多兄弟块 ⇒ 内容底部被遮住」的布局根因，P3 待复现）——本轮即该症状在「专注记录」页的再现，PRD 需给出可验口径（§七 AC1）。
- **已有部分响应式**：`stats-cards` 已 4 → 2 → 1 列（断点 720px / 480px）⇒ 断点体系**可复用**，无需新增魔法数。

## 二、目标指标

- **可滚动（核心）**：360px 宽、记录 ≥10 条时，页面可滚到列表末尾与分页（滚动可达率 **100%**，不是「看起来能滚」）。
- **首屏可见性**：360px 首屏（未滚动）**至少可见记录区入口 + 1 条记录**（当前为 0 条）。
- **零横向溢出**：320px / 360px / 390px 三档 `scrollWidth ≤ clientWidth`（当前表格 760px 必溢出）。
- **点击区**：卡片、分页控件点击区 **≥40px**。
- **桌面零回归**：>720px 下布局、列、字号、分页位置与当前**逐项一致**。

## 三、范围 / 非范围

**范围内**

- 记录页窄屏（≤720px）：整页可纵向滚动；列表改**卡片列表**；统计卡窄屏紧凑化（2×2 + 收窄内距/字号）；筛选保持展开但紧凑；分页窄屏可用；空/错/载三态不撑破布局。
- 桌面（>720px）：**零变化**（表格保持）。

**非范围**

- 「专注」计时页、侧栏/抽屉、任务页与其它列表页。
- 筛选折叠成按钮/抽屉、详情改底部抽屉（均属交互变更，用户已选「只改样式」）。
- 桌面表格列增减、排序/筛选逻辑、数据口径、后端接口。
- 移动端 App（`packages/presentation-react` / `apps/mobile`，红线）。
- `DEF-31` 的**共享布局基座**根因修复（本轮只在记录页层面解决；根因另议）。

## 四、用户场景

- **主场景**：用户在手机浏览器打开「专注记录」⇒ 首屏看到今日/累计统计的紧凑卡 + 记录列表卡片 ⇒ 逐条向下滚动浏览 ⇒ 点某条卡片看详情（时间、模板、备注等全字段）⇒ 返回列表继续滚。
- **主场景（翻页）**：滚到底部分页 ⇒ 点下一页 ⇒ 列表换页且**仍停在列表位置**（不弹回页面顶端）。
- **边界（长内容）**：任务名很长 ⇒ 卡片内末尾省略，不撑宽、不出现横向滚动条。
- **边界（空/错）**：没有记录或加载失败 ⇒ 三态居中提示，不出现横向滚动条、不把分页顶出屏幕。
- **异常（极窄）**：320px 小屏 ⇒ 无横向溢出，统计卡仍可读（2×2 或 1 列但不占满首屏）。

## 五、业务规则

- **D0 用户已拍板（2026-10-26）**：① 痛点 = 整体无法下移 + 首屏被数据卡占满 + 看不到表格 ② 设备 = **iPhone Safari + Android Chrome 两端**（360px 最低宽保底）③ 形态 = **窄屏改卡片列表**（与桌面表格**同一数据源**）④ 范围 = **只改记录页，桌面零变化**，不改交互。
- **R1 单一数据源**：卡片列表与桌面表格消费同一 `records` 数据，**不新增查询、不改分页参数**；字段缺失时展示 `-`（与表格既有口径一致）。
- **R2 断点复用（已确认 2026-10-26）**：窄屏判定沿用既有 `720px`（`stats-cards` 已用），**不新增第三套断点**；≤480px 允许进一步压缩内距/字号。
- **R3 卡片字段（已确认 2026-10-26）**：`类型（图标 + 番茄钟/正计时）· 任务名 · 时长 · 开始时间`；`专注模板 / 结束时间 / 备注` 进详情（不丢字段，只迁移）。
- **R4 首屏压缩上限（已确认 2026-10-26）**：统计区窄屏高度不超过视口约 1/3，保证首屏见记录（具体数值由实现按实测调，AC 以「可见 1 条」判）。
- **R5 详情沿用**：点卡片打开**既有**详情面板（窄屏表现若已有适配则沿用），不新增交互形态。
- **R6 桌面不动**：>720px 的 DOM/样式行为保持当前实现；若必须调整选择器，须证明渲染结果一致（以实测断言为准，禁静态推断）。
- **R7 三态统一**：加载/错误/空一律走 `LoadingError`，不得自绘。
- **R9 卡片单行（已确认 2026-10-26，用户真机走查后）**：卡片改为**单行** `类型图标 · 任务名（过长省略）· 时长 · 开始时间`；`padding` 与行间/卡片间距收紧（现为三行 + `padding: sm/md` + `gap-xs`），**目标卡片高 ≈56px、一屏可见 6–8 条**。
- **R10 分页尺寸（已确认）**：分页按钮改 `NueButton` **small 视觉尺寸**；**实际可点区仍 ≥40px**（用不可见扩展区/内联补偿实现，视觉不变小到不可点）。⇒ `AC5` 的「≥40px」判据由**按钮高度**改为**可点区（命中区）**。
- **R11 分页箭头居中（已确认）**：左右箭头图标在按钮内**水平 + 垂直居中**（现偏移）。
- **R12 信息不丢**：单行化只迁移不删除 —— 模板/结束时间仍在详情；卡片必留四字段。
- **R14 笔记展示（已确认 2026-10-26，用户真机走查）**：详情抽屉内笔记区 ① **补可见标签「笔记」**（与其它字段同 `field-label` 样式，不得只靠裸文本）② **字号降到 `--nue-text-sm`（14px，与其它字段值同号）**，行高 ≥1.6 —— **更正（2026-10-26）**：原写「16px」有误；实测 `.pomodoro-records-detail__note` **无 `font-size`**（`nue-text` 默认 `inherit`），实际继承 **16px**，而其它字段值是 **14px** ⇒ 用户观感「太大」= 相对其它字段偏大；若改成 16px 等于**不变**，故目标应为 **14px** ③ 长笔记**保留换行**（`white-space: pre-wrap`）、不撑破抽屉（换行或纵向滚动，无横向溢出）④ 无笔记时该区**不显示**（沿用现状 `v-if`）⑤ **去掉装饰容器**（已确认 2026-10-26）：笔记外层容器的 `padding` / `background-color` / `border-radius` **全部移除**，笔记与其它字段同样式（「标签 + 正文」纵向排列，正文左对齐、可换行）—— 保留灰底只删 padding 会让文字贴边，**不允许**。
- **R13 详情抽屉手机全宽（已确认 2026-10-26，用户视觉验收后追加）**：详情抽屉（`nue-drawer theme="right"`，主题默认 `span 32%` / `min-span 18rem`，但组件内联默认 `span 36%` / `min-span 240px` **盖住主题** ⇒ 390px 屏上实际约 **240px**、右侧留约 150px 列表残影、内容被挤压）在 **≤480px 时宽度 = 100% 视口**（含安全区内缩）；**>480px 保持现状（288px 语义不变）**。全宽后**必须保留 ≥2 条关闭路径**（`✕` + `Esc`；遮罩被覆盖不可点时不得只依赖遮罩），关闭控件可点区 **≥40px**。

## 六、NFRs

- **性能**：不新增运行时依赖；列表 100 条内滚动无卡顿（体感 + 抽样，具体阈值由 rd-fe/qa 定）。
- **安全区**：遵守 `DESIGN.md` §9（安全区内缩、动态视口基），不得引入 `100vh` / 含滚动条宽度的视口单位。
- **可访问性**：卡片可键盘聚焦、回车打开详情；可访问名含类型 + 任务 + 时间；读屏顺序 = 视觉顺序。
- **响应式边界**：320 / 360 / 390 / 768 / 1280 五档均无横向溢出。
- **可维护性**：窄屏规则集中（优先 `@media` + 既有 token），不散落魔法数；`760px` 硬宽仅保留在桌面分支。
- **NFR 归口**：以上为业务基线；实现取舍（是否拆子组件、滚动容器归属）由 rd-fe 定并回执说明。

## 七、AC（Given–When–Then，五覆盖）

**主路径**

- **AC1（核心·可滚动）**：Given 360px 宽、记录 ≥10 条，When 用户在页面上向下滑动，Then 页面可滚到**列表末尾与分页**且能继续操作（记录区不再被压缩到零高、外层容器不再锁死滚动）。
    - **自动化判据（`R8`，2026-10-26 与 qa 对齐）**：jsdom **无布局引擎**（`scrollHeight/clientHeight/getBoundingClientRect` 恒 0、`@media` 不参与层叠）⇒ 禁止用几何值直接断言（正确实现也会 0≤0 假绿）。改判「**CSS 生效值推演 + 结构**」：容器链上**无 `overflow-y: hidden` 锁死组合**、存在**纵向滚动通道**、记录区高度不被 `height:100% + hidden` 锁死；几何与体感由**真机走查**判（PRD §八）。
- **AC2（卡片形态·单行）**：Given 窄屏（≤720px），When 查看记录列表，Then 每条记录以**单行**卡片呈现 `类型（图标+文字）· 任务名（过长末尾省略）· 时长 · 开始时间`，**卡片高 ≈56px 且 360px 视口一屏可见 6–8 条**；点击卡片打开既有详情，**详情字段与桌面表格一致，无丢失**（`R9`/`R12`）。
- **AC3（首屏）**：Given 360px、有 ≥3 条记录，When 首次打开（不滚动），Then 首屏**至少可见记录区与 1 条记录**；统计卡窄屏为紧凑形态（≤2×2 排布）。

**边界**

- **AC4（320px）**：Given 320px 宽与超长任务名，When 浏览列表，Then 无横向溢出（`scrollWidth ≤ clientWidth`）、任务名末尾省略。
- **AC5（分页）**：Given 窄屏多于一页，When 使用分页，Then 按钮为 **small 视觉尺寸**但**可点区（命中区）≥40px**、**左右箭头图标在按钮内水平垂直居中**、无横向溢出、且**仍停在列表区**（不弹回页面顶端）（`R10`/`R11`）。

**异常 / 三态**

- **AC6**：Given 无记录 / 加载中 / 加载失败，When 窄屏查看，Then 三态由 `LoadingError` 呈现、居中不撑破布局、不出现横向滚动条、分页不越出屏幕。

**负向闭环**

- **AC7（桌面零变化）**：Given 视口 >720px，Then 表格列/字号/分页位置与改动前**逐项一致**（真实组件挂载 + 打印实测值对比，禁 stub 推断）；移动端 `packages/presentation-react` / `apps/mobile` 改动 **0 行**；无新增请求、分页参数不变。

**设计一致性 / a11y**

- **AC8**：卡片视觉沿用既有 `nue-*` token 与记录页语言（圆角/间距/字号），不新造组件体系；若含状态标签，颜色 + 符号 + 文字三重可辨。
- **AC9**：卡片可键盘聚焦并回车打开详情；可访问名含类型 + 任务名 + 时间；读屏顺序与视觉一致。
- **AC11（笔记展示，`R14`）**：Given 打开含笔记的记录详情，Then 笔记区有可见标签「笔记」、正文**字号 = `--nue-text-sm`（14px，与其它字段值一致）**且行高 ≥1.6、长文本按原文换行且**无横向溢出**（≤480 全宽下同）；Given 记录无笔记，Then **不渲染**笔记区（不出现空标签）；且笔记容器**无 `padding` / `background-color` / `border-radius`**（与其它字段同样式）。
- **AC10（详情抽屉·手机全宽，`R13`）**：Given 视口 ≤480px 且点开某条记录详情，Then 抽屉宽度 = **视口宽（100%，含安全区内缩）**、内容区无横向滚动/无被挤压（字段与数值同屏可读）、关闭控件可点区 ≥40px，且 `✕` 与 `Esc` **两条路径都能关闭**并回到列表原位置；Given 视口 >480px，Then 抽屉宽度与现状一致（288px 语义不变），桌面/平板零变化。
