## 1. 问题证据与 5 Whys

**来源**：用户提问「优化日视图主体 UI，并提供放大和缩小功能，允许溢出滚动，但不能影响其他元素。另外全天的任务也显示在里面，而不是单独一行在上面。」

| 层  | 追问                                                                                                                                                                       |
| :-- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ①   | 日视图主体在「看不清」与「看不到」两端同时受限                                                                                                                             |
| ②   | 48 列用 `1fr` 铺满宽度 ⇒ 30 分钟列宽 = 容器宽 ÷ 48（1200px 容器 ≈ 25px），标题常被省略，重叠任务挤在一起                                                                   |
| ③   | 垂直轨道放不下时折叠为**日级 `+N` 单探针**，用户无法滚到看到                                                                                                               |
| ④   | 横向既无缩放也无滚动：既不能把读不清的条放大，也没有「溢出滚动」这条通路                                                                                                   |
| ⑤   | **命题**：引入档位化**时间轴缩放（×1–×4）+ 横向溢出滚动 + 刻度密度随档位细化**，并把**全天任务从「时间轴上方独立一行」移入网格内独立泳道**；全部作用域限于日视图时间轴主体 |

**现状实测（读码）**：`.day-cols-head` = `grid-template-columns: repeat(48, 1fr)`；`.day-grid` = `flex:1; min-height:0`（放不下只折叠 `+N`）；`.day-allday` 为时间轴上方独立 flex 行；`build-day-grid.ts` 中 `DAY_COLUMNS = 48`、`COLUMN_MINUTES = 30`、`MIN_SPAN_MIN = 30` 为模块常量；`snapMinutes(value, 30, mode)` 的 `step=30` 在 3 处硬编码。

## 5. 业务规则

### 5.1 档位与几何（**建议矩阵，待架构确认**）

| 档位 | k   | 时间轴总宽 | 建议刻度粒度 | 列数 | 列宽（1200px 容器） |
| :--- | :-- | :--------- | :----------- | :--- | :------------------ |
| ×1   | 1   | 1.0 × 容器 | 30 分钟      | 48   | 25px                |
| ×1.5 | 1.5 | 1.5 × 容器 | 30 分钟      | 48   | 37.5px              |
| ×2   | 2   | 2.0 × 容器 | 15 分钟      | 96   | 25px                |
| ×3   | 3   | 3.0 × 容器 | 15 分钟      | 96   | 37.5px              |
| ×4   | 4   | 4.0 × 容器 | 10 分钟      | 144  | 33.3px              |

- **时间放大语义**：每分钟像素 = k × (容器宽 ÷ 1440)；**时间轴总宽 = `max(k × 容器宽, 列数 × 20px)`**（列宽下限公式，见 ADR TASK-19 §3-D3）。
- **列宽 = k × 容器宽 ÷ 列数**（与上式数学等价 ⇒ 实现只需 `repeat(列数, 1fr)` + 容器总宽，**列宽无需单独设置**）。
- **k = 1 时无横向滚动**（总宽 = 容器宽，容差 ≤ 1px）——与现状视觉等价。
- **刻度粒度随档位细化**：列数 = 1440 ÷ 粒度（48 / 96 / 144）；粒度按 ADR TASK-19 §3-D1 矩阵（×1/×1.5 = 30min、×2/×3 = 15min、×4 = 10min，为不变量 I1–I4 下的唯一解）。
- **列头标签规则（两型）**：① 标签仅落在**对齐 ≥30 分钟刻度的列边界**上；② **30 分钟粒度档仅整点标注**（24 个 `HH`，**与现状逐字节一致**），**15/10 分钟粒度档整点 + 半点标注**（48 个 `HH:MM`）。
- **格线三级**：60min（实线）> 30min（当前混色）> sub-30（更低混色，仅 10 分钟档启用），三档**全部**由 CSS 渐变绘制（禁 `列数×N` 背景 DOM）。
- **列宽下限保护**：下限 **20px**（= 现状在 960px 容器下实际可达的最低列宽），由**容器总宽**的 `max()` 公式统一承接（见上），**禁** per-column `min-width`（会破坏 `1fr` 等分、列头与网格错位）。触发条件：×1/×2 容器 <960px；×1.5/×3 <640px；×4 <720px。

### 5.2 列头与滚动行为（Q8=A / Q12=A）

- 列头**垂直固定**（不随纵向滚动离开视野）；**水平方向与列对齐一起滚动** ⇒ 整点标签始终对齐其所在列。
- **缩放锚点 = 视口中心**：缩放后保持「原先位于视口中心的时间点」仍在视口中心。
- **进入日视图时的横向定位**：定位到**当前时间**（非今天 → `00:00`）。

### 5.3 全天任务内嵌泳道（Q3=C / Q9=A）

- 全天任务（仅 `endAt`；或跨日裁剪后覆盖整天）由「时间轴上方独立一行」**移入网格内独立泳道**：
    - 位于时间轴区**顶部**；
    - 与 0–24 刻度**同一横向坐标系**（跟随横向滚动）；
    - 标签保留「全天」标识。
- 泳道任务过多 → 泳道**纵向生长**；纵向溢出由**整个主体纵向滚动**承接。
- 时间轴内轨道溢出的日级 `+N`（TASK-16 D3/A6 单探针）**机制保留**（`packLanes` 调用路径照旧），但**日视图不再折叠**：日视图传 `maxLanes = Infinity` ⇒ `overflow` 恒空、全部轨道渲染，纵向溢出由主体纵向滚动 100% 可达（ADR TASK-19 §3-D4 **V1**）。

### 5.4 操作入口（Q6=C）

| 入口     | 行为                                                                                                                                                                                                            |
| :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 头部按钮 | 控制条内新增 `−` / `+` 两个图标按钮（`theme="icon,ghost"` 同规格，到端 `disabled`）；**契约**：`data-testid="day-zoom-out"` / `"day-zoom-in"`，`aria-label="缩小时间轴"` / `"放大时间轴"`；**不设**独立复位按钮 |
| 键盘     | `Ctrl/⌘ +` 放大、`Ctrl/⌘ −` 缩小、`Ctrl/⌘ 0` 重置 ×1（修饰键与既有 `←/→`、`Enter`、`n` 不冲突）；**契约**：`useShortcut` id = `calendar.dayzoom.in` / `calendar.dayzoom.out` / `calendar.dayzoom.reset`         |
| 鼠标     | `.day-body` 内 `Ctrl/⌘ + 滚轮` 缩放（`@wheel.ctrl.prevent`，不触发浏览器页面缩放）                                                                                                                              |

### 5.5 持久化（Q10=A）

- 写入**现有日历偏好层**（与 `CALENDAR_WEEK_START` / 专注徽标同处，即 entry 级 `CALENDAR_VIEW_CONTEXT` 偏好），localStorage 新键 `CALENDAR_DAY_ZOOM`。
- 非法 / 缺失值 → **回退 ×1** 并规范写回（沿用现有偏好的回退范式）。
- 跨会话保留；切月/周后回日视图**沿用**；**不做**跨设备同步；本单**不提供**「重置为默认」独立入口（`Ctrl/⌘ 0` 即重置）。

### 5.6 随缩放变化的范围（Q11=A）

- **仅刻度密度变化**；任务条**字号 / 内边距 / 高度不随缩放变化**（与今日一致）。
