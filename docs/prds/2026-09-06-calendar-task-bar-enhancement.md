## 1. 主题与背景（5 Whys 摘要）

表面诉求"条上加颜色/时间/过期提示" → 条体同色中性、扫读靠逐条读名 → 月历承担"当天/当月执行决策"却无法一眼排序 → 无时刻感、无状态差权、过期任务易漏 → **深层需求：月历是执行决策面而非陈列面**。

**假设命题**：优先级/时刻/逾期信息进入条面可提升决策扫读效率（置信中低，无历史埋点，验收后验证）。

## 2. 目标指标与埋点口径

- 北极星（任务完成）不拆新指标；中间指标（**埋点未落地，归 P1 建议**）：
    - `calendar.defer_click`（延期按钮点击）
    - 逾期任务在日历内完成勾选占比
    - 日历页留存（前后 2 周）
- 无埋点期间以可用性冒烟为准；埋点口径：逾期 = `endAt < 今日 0 点` 且 `state ≠ done`。
