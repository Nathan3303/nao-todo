## 5. 业务规则

### 5.1 新建入口改为「点击刻度文本 → 创建对话框」（Q1=C / Q7=A）

- **移除**：时间轴空白点击触发内联新建（`onTrackClick` → `quickCreate`）；日视图**不再渲染** `day-quick-create` 内联编辑器（`quick-create.vue` 组件本身保留，月/周仍在用）。
- **新增**：点击**带文本的刻度列**（整点/半点，即 `label !== ''` 的列头单元）→
    ```ts
    dialogManager.open(TASK_CREATOR_DIALOG_KEY, { startAt, endAt })
    ```
    - `startAt` = 该刻度时间（锚点日 + 刻度分钟）；`endAt` = `startAt + 30 分钟`（与 `DAY_SNAP_MINUTES` / 最小条宽同口径）。
    - 依据：`packages/presentation/task/components/dialogs/creator/creator.vue` 的 `open(createTaskOptions)` 支持按 `states` 键预填（含 `startAt`/`endAt`）；应用级已由 `apps/web/src/components/app/dialog-adapter.vue` 挂载注册；**日历上下文已持有同一 `appDialogManager` 单例**（`calendar-view.ts:198/232`、`context.ts:15`）⇒ **零新增管道**。
- **注意**：`open` 对 falsy 预填值跳过（`if (!presetVal) return`）⇒ 传 ISO 字符串安全。
- **可点范围**：仅带文本列（空文本列不可点）；空文本列不响应，也不触发 pan（避免误触）。

### 5.2 全天任务渲染为任务条（Q2=A）

- 复用 `task-bar` 组件渲染全天任务（替换 `.day-allday-chip` 原生按钮），保留点击打开详情。
- **只读**：**不**提供拖拽/拉伸手柄。
- **必须说明不可拖拽原因**：悬停提示文案按原因区分，至少覆盖「跨度超过 24 小时」（跨整天）与「仅设了截止时间（无开始时间）」两种来源；文案为 `title`/`nue-tooltip`，可被结构断言。
- 多任务排布：单行换行 + 泳道纵向生长（沿用 TASK-19 §5.3），溢出由主体纵向滚动承接。

### 5.3 名称贴边（sticky）与裁切提示（Q3=A / Q10=A）

- 任务条内名称：`position: sticky; left: 0`（**建议实现路径**：sticky 元素的包含块 = 自身 `.day-seg`，故名称会停在视口左缘、**但不会越出自身条右缘** —— 正好满足「除了超过任务条」；待架构确认）。
- 条整体滚出可视区后：名称随之消失（不越出条是硬约束）。
- **裁切提示**：时间轴区**左右缘各加一层渐隐遮罩**（提示该侧仍有内容被裁切）；**不引入**计数徽标（避免与刚退休的纵向 `+N` 混淆）。

### 5.4 左缘拉伸（Q4 / Q6）

- 任务条**左右缘各一个手柄**：右缘改 `endAt`（现状不变）；**左缘改 `startAt`**（`endAt` 不变）。
- 约束沿用：领域不变量 `start <= end`；最短时长 `DAY_SNAP_MINUTES`（30 分钟）；吸附模式左缘 = `round`（与右缘一致；TASK-16 D4 语义不变）。
- **续接段（`isStart === false`，本段起点被裁剪到 `00:00`）禁止左拉**：**不出**左缘手柄（PM 定案，用户 2026-09-22 采纳）。理由：左拉实际会改**前一天**的开始时间 —— 改动落在当前视图不可见处，且视觉上条不会左延，用户会看到「拖了没反应」；与 TASK-16 C13（真实值锚）/ D2（离开视图不夹取）一致。
- 同理，`isEnd === false` 的续接段右缘是否禁止右拉：**本单不做特殊处理**（现状即允许，且改动落在次日 = 与既有行为一致），登记为遗留。

### 5.5 空白拖拽横向平移（Q5，PM 默认口径）

- 在时间轴空白区（`.day-axis-track` / `.day-body` 非任务条区域）**左键按下并移动超过 4px 阈值** → 进入 pan 模式，横向滚动（纵向不变）。
- 未超过阈值 → 不滚动（防误触）；`pointercancel`/`pointerup` 退出。
- 与 §5.1 的刻度点击不冲突（刻度在列头，pan 在时间轴区）。
- 触摸/触控板手势沿用浏览器原生（不在本单范围）。

### 5.6 刻度进一步细分（Q4=A / Q8=A）

- **×4 档粒度 10 分钟 → 5 分钟**：列数 **288**（`1440 / 5`），满足不变量 I1（`30 % 5 === 0`），`MIN_SPAN_MIN = 30` ⇒ 最小条宽 = **6 列**。
- **标签规则不变**（仅整点/半点 `HH:MM`，48 个）⇒ 每 6 列一个标签，间距 ≫ 标签宽，**无重叠**。
- **标签相对刻度线水平居中**（`translateX(-50%)`）；`00:00` 首列做边界保护（避免半个标签被裁）；末列同理。
- **格线四级**：60min（实线）> 30min > 10min > 5min（透明度递减）；仍**全部** CSS 渐变绘制（禁 `列数 × N` DOM）。
- **列宽下限优先**：`总宽 = max(k × 容器宽, 列数 × 20px)` ⇒ 1200px 容器下 ×4 实际取 5760px（等效 4.8×），列宽 20px。**ADR 不变量 I2（列宽 ≥25px）据此降级**（见 §6）。
