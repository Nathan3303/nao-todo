## 1. 问题证据（5 Whys）

| 层         | 内容                                                                                                                                                          |
| :--------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ① 现象     | 桌面端**每次启动都要输密码**；web 端**离线刷新一次即彻底进不去**；desktop **读不到最新任务**                                                                  |
| ② 机制     | 本地数据加密 ⇒ 解钥来自密码（`UnlockGate`）；web 离线检入失败即 `localStorage.clear()`（**DEF-5**）；本地镜像按「≤200 行/表/次启动」填充且无补全（**DEF-6**） |
| ③ 历史原因 | SHELL-03/05/06 按**桌面端**立项离线能力，并把「业务数据加密存 IndexedDB」作为**已接受事实**；web 从未接入本地数据面                                           |
| ④ 决策盲区 | 「web 保持远端直连」**既无决策也无护栏**，而两端只差一行 alias（`@/hooks`）⇒ 未来可能被顺手翻转而无人察觉                                                     |
| ⑤ **命题** | 把「本地数据」的访问门槛从**密码**改为**设备持有 + 用户显式选择**，并让 **web 与 desktop 具备同一套**离线数据面                                               |

**用户反馈（原话）**：「主要就是 Web 端和 Desktop 端都可以**不让用户输入密码就进入应用**」；web 离线需求 = **是**。

**实测证据（非推断）**：

| 证据                                                                                       | 来源   |
| :----------------------------------------------------------------------------------------- | :----- |
| desktop 620 行账号：本地 count **0→200→399→598→620**，**最新 3 条 id 在 M1–M3 均不在本地** | P1 T2  |
| web 离线刷新：`USER_JWT` **变空串**、`localStorage` 仅剩该键                               | P1 T6  |
| web 断网写：**5 项连 toast 都没有**（静默丢失）                                            | P1 T3  |
| 服务端 `user_sessions` **61 行/11 用户/12 行空 device_id**，单用户最多 19 行含 17 过期     | P2 Z11 |

## 5. 业务规则

| 类           | 规则                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| :----------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **不变量**   | ① 本地业务数据**明文**落盘 ② **登出 / 切换账号**触发清库（**同一 `wipeUserData` 原语**）；**10041 与到期未注销不清** ③ 迁移**全库成功后**才写完成标记；**`key-bundle` 删除是唯一不可逆开关**，须在全库迁移完成 + 观察窗口后**单独决策**（ADR C-47/C-51） ④ 阶段一**不得产生任何 `markDirty`** ⑤ `userId` 隔离**硬失败**（null/空拒绝库操作）                                                                                                                                                                                                       |
| **边界**     | ① 「无密码」上限 = **7 天**（服务端会话绝对期，不滚动）；JWT 48h ② **登出 + 离线 = 死路**（需联网重登；**文案明示**）③ 空库 vs 未同步完成**必须区分**（`lastSyncAt === null`）④ **web 驱逐风险 100% 暴露**（不申请 `persist()`，作为事实过期机制 —— **属风险接受，非边界**）⑤ **清库范围** = IndexedDB 11 张业务表 + `meta` + `deletionSchedules` + `syncQueue` + `syncCursor` + localStorage 业务键；**切换账号 = 先登出清库语义**（明文下不得保留双方数据）⑥ **i18n 要求**：离线标识 / 「待升级」/ 清库确认文案须走 `t()` 并**同步三处 locales** |
| **权限**     | 无密码门 ⇒ **设备即凭据**；暴露窗口 = 登录 → 主动登出（**desktop 无上界**）⇒ 必须写入 ADR + 用户提示                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **安全姿态** | 接受**不可逆**；两端**同一姿态**；web 语境**禁用「加密」字样**；设置页标注端差异（实际已统一）                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
