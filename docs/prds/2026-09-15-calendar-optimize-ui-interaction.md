## 4. 用户场景

- **场景卡**：用户打开日历 → 头部选排序字段（或默认名称序）→ 月/周视图按序展示；拖拽改期不改变排序；标题点击展开年月选择（NueDropdown）；任务条三点展开改期菜单（NueDropdown）；右键无响应。
- **关键路径**：日历头部（排序下拉 / 标题 NueDropdown / 左右箭头）→ 网格（边框/N+/任务条）→ 任务条三点 → 改期菜单。
- **页面状态清单**：默认（名称序）；已排序；busy（改期中禁用）；空态（无任务）；跨周续接（圆点已移除）。

## 5. 业务规则

- 排序字段四项（优先级/开始时间/截止时间/创建时间），升降序；未选字段时按名称升序（`localeCompare`）。
- 排序仅影响日历展示顺序，**不回写服务端、不产生 `sort_id` 残留**；拖拽仅改日期。
- 排序选择持久化于独立 localStorage 键（`naotodo.calendar.sort`），月/周共享。
- 右键完全禁用（`@contextmenu.prevent`，不弹浏览器原生菜单）。
- 改期菜单项：今天/明天/[下周同日（已排期）]/选择日期…（未安排裁剪三项）；`group="calendar-reschedule"` 保证同时仅一个展开。
- 年月跳转：月视图跳月；周视图落周（不切回月视图）。
