## 4. 用户场景

- **场景卡**：搜索页 → 侧栏「快捷搜索」点「高优先级」即出结果；设置条件后点筛选栏「保存为常用搜索」具名保存；下次在侧栏「常用搜索」点击一键复现；「常用搜索」「最近搜索」可折叠、空态有引导文案；历史可清除。
- **关键路径**：搜索框 / 筛选栏（保存入口）→ 结果区；侧栏（快捷 + 常用 + 最近）→ 复现/管理。
- **页面状态清单**：无常用搜索 / 无历史（空态）；多条（含拖拽排序）；折叠 / 展开；移动端抽屉；收集箱筛选。

## 5. 业务规则

- **常用搜索**：`SavedSearch { id, name, query, createdAt }`；存储键 `naotodo.search.saved`（与关键词历史 `naotodo.search.history` 并存不合并）；上限 20；**允许重名**；自动命名（关键词 · 清单 · 标签 · 优先级 · 状态，`·` 拼接）；容错降级（存储不可用/损坏 → 空列表，不阻断）。
- **复现**：完整条件（含 `includeExcluded`）→ 引擎 `applyQuery` → URL 同步 → 立即搜索 + 回焦搜索框。
- **侧栏**：快捷搜索**固定常显**；常用/最近**可折叠**（默认全展开、非 accordion、**不持久化**）；空态标题恒显 + 提示文案；折叠头为 `nue-button`（图标随展开态切换）+ 条目计数，清除按钮位于折叠按钮之后的 actions 区；桌面端**整行可拖**排序（无独立手柄）、移动端禁用拖拽。
- **快捷搜索**：只读预置 4 项（高优先级 `priorities:['high']` / 待办 `states:['todo']` / 进行中 `states:['in-progress']` / 已完成 `states:['done']`）；点击即复现；不可重命名/删除/拖拽。
- **收集箱**：搜索内部哨兵 `''`；任务数据 `'inbox'`；**入口归一 + 过滤两端归一**；URL 契约（`?project=inbox` ↔ `''`）与内建清单查询 `projectId:'inbox'` **不变**。

## 6. NFRs

- 纯函数层（`saved-search.ts` / `search-history.ts` / `search-query.ts`）**零改动**；状态**单一真源**（provide/inject，禁 module 单例）。

## 9. 决策留痕

- **Q1–Q8（常用搜索）**：完整条件 / 命名默认自动可改 / localStorage / 上限 20 / 展示于侧栏（原为空词态，后因 T26 迁侧栏）/ 管理含拖拽 / 允许重名（1B）/ 与关键词历史并存不合并。
- **T26 侧栏化（arch 探查）**：路径 = `setControllOption({useSlot,useDrawerSlot})` + `#SubPageAsideTeleportSlot` teleport + 两段式延时；**整体搬迁不抽子组件**（消费点唯一）；**单一真源 provide/inject**（禁 module 单例，避免 `use-saved-search.test.ts` 串扰）。
- **T27 SmartList 评估（arch）**：**可折叠能力来自底层 `nue-collapse`**，非 SmartList；复用 SmartList 属"借壳"（需 `count>0` 骗 v-if、空态限 `emptyText`、残余 route/drag 语义）→ **否决 P1**，采用 **P2（`nue-collapse` + `nue-collapse-item theme="menu"`）**；**硬约束：`theme="smart-list"` 是 scoped CSS，跨组件不可用**。
- **T28 收集箱修复（arch 根因）**：断点 = `search-tasks.ts` 本地等值过滤；**Fix B（入口归一，主）+ Fix A（两端归一，防御）**；**否决 Fix C（全局 VO 边界归一）**（blast radius 大，需跨端+后端评审）。
- **D2 移动端**：本期不动（红线）；若数据侧确为 `'inbox'` 且移动端同源失效，另立单。
- **D3 共享归一**：本期在 search 域内抽 `normalizeProjectId`（含单测），**不提升共享包、不立 ADR**（注释约束）。
- **T29 UI**：箭头曾改 `#header` 插槽内 `nue-icon`（size 0.75rem）+ `aria-hidden` + rotate 过渡，**弃用库类 `nue-collapse-item-state-icon`**；清除按钮移至「最近搜索」头部 + `@click.stop`；键盘 `.self`。
- **T31 用户手工打磨（`30555aee`，作者 = 项目所有者）**：折叠头由 `nue-icon` 改为 **`nue-button`**（图标随展开态切换 `arrow-right`/`arrow-down`）+ **显示条目计数**；条目改 `nue-text`（单行截断）+ `nue-icon` 操作组；**移除拖拽手柄**（改为桌面端整行 `draggable`，移动端禁用）；修正常用搜索条目误用 `search-history__reuse` 类名；快捷搜索预置图标改 `priority-3`/`circle`；空态块补背景/内边距；`prompt.css` 遮罩动画时长 `long → short`。同步更新 `aside.test.ts`（折叠头与响应式用例）。
