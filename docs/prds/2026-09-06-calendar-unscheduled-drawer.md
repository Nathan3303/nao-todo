## 1. 主题与背景（5 Whys 摘要）

日历只展示有截止日任务 → 未定时间任务看不见 → 无法在日历上下文快速安排 → 只能回任务页逐条翻 → **深层需求：日历应承担"无期→有期"的排期入口**。假设：收纳 + 一键安排提升当日计划录入完整率（置信中低，待埋点验证）。

## 2. 目标指标与埋点口径

- 中间指标（埋点未落地，P1）：`calendar.unscheduled_arrange`、抽屉打开率。
- 口径：**未安排 = `endAt` 为空**（含仅 startAt；桌面 `''`/null 同空）。
