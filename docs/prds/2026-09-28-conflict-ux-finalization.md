## 2. 逐条需求与验收口径

**2.1 计数同源（`T331`）**

- 现象根因：**列表读 journal 实时数据**，徽标读 `syncStatus.conflictCount` **一次性快照**；两条恢复动作只删条目 + 刷新列表，**未把同源剩余数写回计数** ⇒ 徽标滞留
- 口径：**单一真源** —— 成功处理后取同源 `remaining` 写回计数
- 验收：处理一条 ⇒ 减一；全清 ⇒ 归零；**不依赖重启**

**2.2 diff 展示（`T332`）**

- 新增纯函数 `conflict-diff.ts`：**三态分类**（added / removed / changed）· 技术字段判定 · **按对象分组** · 长值格式化 + 单测
- 渲染：按对象分组（组头「表名 · 标题 · N 条」· 可折叠·默认展开）+ **三态高亮**（**颜色 + 符号 `+ − ~` + 文字**三重冗余）+ 技术字段可展开 + 长值截断可展开 + 来源标注「我的版本 / 服务端版本」
- 验收：三态在**去色**情况下仍可区分（符号/文字）· 分组标题**非空**（降级链 `name/title → entityId → 本地化 kind → 未知对象`）

**2.3 对话框化 + C 端化（`T338`–`T346`）**

- 冲突面板改为**对话框** + 左右布局（<900px 堆叠）· 左栏只留名称 · 细节进右栏 · 字段名说人话 · 去内部术语
- 验收：无「后台管理台气质」；文案不含 `stale` / `OCC` / `derivedUpdates` / `revision` 等内部键名

**2.4 视觉走查修复（`T347`–`T357`）**

- 浅色对比度（按**真实渲染底色**重算，`DEF-52`）· 深色硬编码改 token（`DEF-53`）· `×` 关闭后焦点归还（`DEF-54`）· 空态图路径改 `assetUrl`（`DEF-55`）· 「关闭」= 关闭对话框（`DEF-56`，并移除孤儿 API）· 遮罩点击只关本对话框（`DEF-57`，判定改**节点身份**）
- 验收：见缺陷池各行（均已闭环，含真机证据或明确说明）

## 3. 决策与口径（含被推翻项）

- **计数口径 = 对象数**（非 journal 条目数）—— 用户明确认可
- **技术字段常显**（移除开关）—— 用户决策
