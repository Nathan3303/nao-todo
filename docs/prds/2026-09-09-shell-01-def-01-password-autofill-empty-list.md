# SHELL-01-DEF-01：设置对话框切「修改密码」致背景任务列表置空（浏览器自动填充）

> 归档日期：2026-09-09（交付终签日）· 发布批次：`v1.3.3` · 修复提交：`5bc18ecd`

## 主题与背景（5 Whys 摘要）

| Why                      | 结论                                                                                                                          |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| 为什么列表空了？         | 任务视图收到一次 `GET /tasks?name=<邮箱>` 空返回，`loadFirstPage(true)` 把本地 taskIds 替换为空集                             |
| 为什么带 name=<邮箱>？   | 账号邮箱被写入了任务名筛选关键词（`preference.getTasksOptions.name`），经 watch → `RefreshData` 触发重拉                      |
| 为什么邮箱会进筛选框？   | 浏览器凭据自动填充把已保存账号邮箱写入页面唯一的无 `autocomplete` 常驻文本输入——任务名筛选框                                  |
| 为什么此时触发自动填充？ | 设置对话框切到「修改密码」挂载 3 个 password 输入，浏览器误判为登录表单开始填充                                               |
| 为什么此前无此形态？     | SHELL-01（v1.3.2）把设置从独立路由页改为对话框覆盖层：改密表单挂载时任务页仍存活于背景（旧版切改密=整页导航，任务视图已卸载） |

## 目标指标

- 切「修改密码」后背景任务列表零变化（无空态闪现、无数据丢失、无多余网络请求）。
- 验收 = AC1–AC5 全绿 + 生产构建双端实测 + 回归单测防护。

## 9 模块要点

### 问题证据

- 用户报障（Web 生产 v1.3.2）：任意任务视图切「修改密码」→ 空状态；Network 出现 `GET /tasks/?relativeDate=tomorrow&limit=20&isGivenUp=false&name=<用户邮箱>`（name=账号邮箱为空返回关键特征）。
- RD 受控复现矩阵（dev / 本地生产包 / 真实生产 × 全部/项目/标签/收集箱 × 表/列/看板 × 8/20/41 条 × 6 种切换序列）headless 全绿——因无浏览器自动填充环境；机制经「请求形态 + 静态写入链 + DOM 注入实验（set value+input → 360ms 后精确发出该请求 → 20→0 行空态）」三重闭环实锤。

### 范围 / 非范围

- 做：源侧（改密表单 autocomplete 语义）与受害字段（任务名筛选框 autocomplete=off）双保险修复 + 组件级回归单测。
- 不做：不动任务 loader/RefreshData 语义；不动设置三区表单逻辑；不含移动端；不含日历/搜索页同类输入排查（单独立项）。

### 业务规则 / 边界

- 改密表单三输入语义：旧密码 `current-password`、新密码/确认 `new-password`（浏览器不再视其为登录表单）。
- 任务名筛选框非身份字段，恒 `autocomplete="off"`（一处组件覆盖 全部/项目/标签 三视图同名筛选框）。
- 由于 `nue-input@1.11.0` 不透传 autocomplete 至内层 input，属性经组件暴露的 `innerInputRef` 于挂载期设置。

### 用户场景（复现路径，供回归）

```
前置：Web 生产 v1.3.2，浏览器已保存站点账号凭据，进入任意任务视图（含数据）
1. 打开设置对话框（齿轮 / ⌘,）→ 默认「个人资料」
2. 点击「修改密码」
旧行为：背景任务列表空态（name=<邮箱> 空返回）
新行为：背景列表保持原样；改密表单正常
```
