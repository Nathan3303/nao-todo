## 1. 问题证据与 5 Whys

**现象（用户实测）**：某个含大量子任务的顶层任务详情中，子任务列表撑开并出现滚动条；滚动到底部时，**任务标签栏（`TaskTagBar`）异常覆盖在子任务列表之上**。

| 层  | 追问                                                                                                                                  |
| :-- | :------------------------------------------------------------------------------------------------------------------------------------ |
| ①   | 滚动到底部时标签栏压住子任务列表                                                                                                      |
| ②   | 子任务弹性区收缩、内容逸出，与下方标签栏在视觉上重叠                                                                                  |
| ③   | `.tasks-details-view__subtasks { flex:1; min-height:0 }` + 内部滚动容器的 `overflow:unset` 组合，使子任务内容未在自身区域内被完全收口 |
| ④   | 详情面板早前为"让标签栏/评论区贴底"引入弹性占位（`65d30deb`/`daedf495`），弹性收缩边界在极端子任务数下失效                            |
| ⑤   | **命题：收口子任务弹性区、固定标签栏所在行，使子任务滚动不逸出、不覆盖标签栏**                                                        |

## 4. 方案与决策

用户手动定稿采用 **flex 约束方案**，而非最初提出的 `position: sticky; bottom: 0`：

- 标签栏所在行 `flex="none"` → 该行不参与弹性收缩，固定在正常流位置；
- 子任务区移除 `min-height:0` → 避免弹性区在极端内容下收缩到逸出；
- 结合既有子任务内部滚动容器，子任务列表在自身区域内滚动，不再覆盖下方标签栏。
