## 1. 问题证据与 5 Whys

**问题证据**：SHELL-01 交付的 `apps/web/src/components/settings/dialog/index.vue` 采用「上 Tab 条 + 下内容区」布局，且 `.nue-dialog--settings` 仅锁宽度、高度由内容撑开（`max-height` 兜底）。三区内容体量差异显著（个人资料 ≫ 应用设置 ≫ 修改密码），用户切换分区时对话框高度剧烈伸缩，产生大面积视觉跳动；同时上下布局在宽屏下浪费横向空间。

**5 Whys**：

| 层  | 追问                                                                     |
| :-- | :----------------------------------------------------------------------- |
| ①   | 切区时对话框忽高忽低，视觉不适、阅读位置漂移                             |
| ②   | 因为对话框高度未约束，由当前内容自适应                                   |
| ③   | 因为壳层只锁了宽度（`min(46rem, …)`），未锁高度                          |
| ④   | 因为三区内容天然不等高，外框却未与之解耦                                 |
| ⑤   | **命题：外框定尺、内容区内滚 —— 切区零跳动；左右分栏提升宽屏空间利用率** |

**动机**：低频偏好操作应先得「稳定」，再谈「好看」。尺寸抖动是明确的体验缺陷（期望型不满足），修复成本低。
