## 4. 用户场景

- **场景卡**：打开日历 → 格子头部左见日期号、右见专注角标；任务条显示「名称 + 截止时间（HH:mm）」；点截止时间弹出改期下拉；网格线穿过任务条背景但名称文字清晰可读。
- **关键路径**：日历网格 → 格头（日期/角标）→ 任务条（名称/触发器/层叠）。
- **页面状态清单**：有/无专注角标；有/无截止时间；真末段/非末段；busy（触发器禁用）；拖起占位。

## 5. 业务规则

- 头部：日期号靠左、专注角标靠右；**无角标时数字仍靠左**（列对齐一致）。
- 时刻：显示 `endAt` 的 `HH:mm`；**仅真末段**可见
    - 月视图：`seg.isEnd && row.cells[seg.colEnd].dateKey === dateKeyOf(endAt)`
    - 周视图：`seg.isEnd && endAt 合法`
- 触发器：有截止时刻（showTime 且 endAt 合法）→ 显示时间文本（**常显**），点击开改期下拉；否则 → 回退三点图标（悬停/聚焦出现）；两者共用 `.cal-item-more`（拖拽统一跳过）。
- 层叠（最终态）：网格线在任务条上方；**仅名称文字**抬升至线之上（用户样式）。

## 6. NFRs

## 9. 决策留痕

- **② 整条抬升 → 还原**：T17 采用 `.cal-lanes { z-index: 2 }` 使整条（背景/色条/文字）压在线上；用户实测效果不佳（线条被条背景遮蔽后分区感消失）→ T19 还原（`.cal-lanes` 去 z-index，注释回 TASK-07 口径）。
- **③ 修订（T18）**：原方案「名称后加独立时刻 span」改为「末尾触发器本身显示截止时间」——删除独立 span，时间并入 `reschedule-menu` 的 `#trigger` 槽；原因：减少一个视觉元素，把「信息」与「入口」合并。
- **③ 兜底**：非末段/无 endAt 时回退三点图标，保证改期入口不丢失（若仅按 showTime 门控则非末段无法改期）。
- **可见性**：时间形式常显（信息优先）；图标形式保持悬停出现（避免噪声）。
- **抽取 `segment-time.ts`**：月/周可见性判定抽为纯函数模块（内联不可单测）；月视图原为 provider、依赖重。
- **需求 ④ 抛弃**：用户确认后放弃，不实现。
- **用户样式**：`.cal-lanes` 内嵌套 `.cal-item-text { z-index: 3 }` —— 仅名称文字在线之上（评估：`.cal-lanes`/`.cal-item` 无 transform/filter/isolation，不创建层叠上下文，z-index 同层可比；拖起态 `opacity: 0.35` 会创建层叠上下文，但为半透明占位态，无实际影响）。
