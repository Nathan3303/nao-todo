# PRD：凭证失效口径收口批（`DEF-90/91` + `DEF-92…96`）

> 状态：**设计中（arch 评审待回）** · 批次：`B20261031-credential-coherence` · 范围：web + desktop（移动端红线不动）
> 来源：`docs/reports/T551-auth-credential-audit.md`（`arch-designer-T551` 只读审计）· 缺陷池 `DEF-90…96`

## 一、问题证据

审计已确认「**凭证失效不存在唯一判据**」：客户端有 5 处判断、2 套方向、3 套清理动作；服务端把「解析失败 / JWT 过期 / 会话不存在 / 已轮换 / 被顶号」压成同一个 `10041`。逐条缺陷：

- **`DEF-90`（P1）清理口径分叉**：axios 只清 store；sync 清全套；checkin **不清本地保险库** ⇒ 失效后保险库仍解锁（安全姿态不一致），`10042` 未纳入判定。
- **`DEF-91`（P1）保险库密码与账号密码脱钩**：他设备改密后，桌面「远端登录成功、本地解锁失败」⇒ **硬阻断**，文案说「密码错」且**无任何恢复出口**（除手工清数据）。
- **`DEF-92`（P2）**「到期可见提示」只覆盖续期路径；普通请求先撞 `10041` 时**静默登出**。
- **`DEF-93`（P2）** `sync-service` 无 JWT 时发 `Bearer null`；后台同步不复用 axios 的去重闩。
- **`DEF-94`（P2）** `initRequester` **双初始化**（desktop `main.ts` + web `app.ts`）⇒ 两套去重闩/回调实例 ⇒ 行为取决于请求从哪个实例发出。
- **`DEF-95`（P3）** 注册成功后丢弃 `query.redirect`，注册入口链接也不带 redirect。
- **`DEF-96`（P3）** `getDeviceId` 的 `localStorage` 读写无 `try/catch`，`theme-store` 的 `matchMedia` 无守卫 ⇒ 隐私模式/配额异常时拦截器抛错（连登录都失败）。

**共同根因**：判定、提示、清理、恢复**四个动作没有单一所有者**，散在请求层 / 同步层 / 检入层 / 页面层。

## 二、目标指标

- 凭证类失效的**判定点收敛到 1 处**（含 `10041` / `10042` / 网络类豁免）。
- 清理动作：**同一事件只触发一套动作**，且「会话 / store / 本地业务数据 / 保险库 / 队列」的加减有**明确矩阵**，不留半清状态。
- **恢复出口 100% 可达**：任何「本地解锁失败」必须给出**可自助**的下一步，不得只剩「手工清数据」。
- 静默登出 → **有可见提示**（到期 / 被顶号 / 凭证失效三类至少一类区分）。
- 日志噪音：登出后后台同步**不再发请求**（`Bearer null` = 0 次）。

## 三、范围 / 非范围

**范围**：`DEF-90` · `DEF-91` · `DEF-92` · `DEF-93` · `DEF-94` · `DEF-95` · `DEF-96`（7 条，web + desktop）。
**非范围**：服务端错误码细分（跨仓，另议）· 移动端 `packages/presentation-react` / `apps/mobile` · 保险库加密算法本身 · `DEF-85/86..89` 已闭环项。

## 四、用户场景

- **S1 桌面端在他设备改密后登录**：远端成功 → 本地解锁失败 ⇒ 用户看到**明确说明**（不是「密码错」）+ **一个能自救的入口**。
- **S2 会话 7 天到期**：任何一条请求先撞 `10041` ⇒ 用户看到「登录已过期，请重新登录」，而不是被无声踢回登录页。
- **S3 被顶号 / 被下线**：明确告知「已在其他设备登录」，可选一键重新登录。
- **S4 登出后**：后台同步立即停止发请求（无 `Bearer null`、无 `10041` 噪音）。
- **S5 隐私模式 / 存储受限**：能正常登录（设备 ID 拿不到时降级，不抛错）。
- **S6 深链注册**：从分享链接注册 ⇒ 注册成功后回到原目标页。

## 五、业务规则

- **R1 单一判据**：凭证类 / 网络类 / 业务类的分类与「是否登出」只允许一处定义，各层引用，禁止各自 switch。
- **R2 清理矩阵**：一次失效事件的动作集合固定（哪些清、哪些留）并单点实现；**网络类不登出、业务类不登出**（沿用 `DEF-33` 的 C-67 口径）。
- **R3 恢复出口**：本地保险库解锁失败必须有**可自助**出路（`arch` 给候选方案，PM 定文案）。
- **R4 提示可见**：到期/被顶号至少在 UI 上留痕；不得静默。
- **R5 幂等**：同一失效事件重复触发不产生二次导航/重复提示。
- **R6 移动端零改动**。

## 六、NFRs（业务视角基线）

- 不引入新依赖；不改变既有服务端契约；离线可进入（既有能力不回退）。
- 隐私：恢复出口不得要求用户提供明文口令到日志；任何新文案不得含技术键名（项目「说人话」红线）。

## 七、AC

- **AC1** 凭证类失效（`10041`/`10042`）⇒ 走**同一**处理函数（可用测试断言「唯一调用点」/变异验证）。
- **AC2** 网络类（`NETWORK_ERROR_CODES`）与业务类错误 ⇒ **不登出、不清数据**（既有 C-67 口径不回归）。
- **AC3** 一次失效事件：清理动作集合与矩阵一致；**保险库锁定状态**与矩阵一致（`DEF-90`）。
- **AC4** 他设备改密后桌面解锁失败 ⇒ 出现**可自助**的恢复入口，走该入口后可正常进入（`DEF-91`）；文案不含「密码错」误导。
- **AC5** 到期 / 被顶号 ⇒ 用户可见提示（至少区分类别），不得静默（`DEF-92`）。
- **AC6** 登出后后台同步零请求、零 `Bearer null`（`DEF-93`）。
- **AC7** 全仓仅 **1 处** `initRequester`（或等价单例初始化），去重闩唯一（`DEF-94`）。
- **AC8** 注册成功保留 `query.redirect` 并回到目标页；注册入口链接携带 redirect（`DEF-95`）。
- **AC9** `localStorage` / `matchMedia` 不可用时：登录不失败、功能降级可见（`DEF-96`）。
- **AC10** 移动端 `git status --porcelain -- packages/presentation-react apps/mobile` = 0 行。
