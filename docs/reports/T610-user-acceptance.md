## 执行提示

- **第 2、7、14 项是本批的三处关键收益**：选中态不再只靠颜色、拖拽不再写坏状态、「已归档」键盘可达。
- 第 14 项（真机 Enter）**必须人工走查**：自动化环境不实现原生按钮的 Enter 隐式激活，只能验「原生可激活形态 + 可聚焦 + 有可访问名 + 无祖先剥夺」。
- 第 17–20 项是「组件搬家」的回归：功能没变，**只该有零差异**；若发现任何像素级变化（尺寸/圆角/动画时长），请当作不通过。
- 若某项不通过，请附：页面路径、浏览器/桌面端版本、操作顺序、截图或录屏（能复现即可）。
