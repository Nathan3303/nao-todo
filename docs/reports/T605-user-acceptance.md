## 执行提示

- 第 1–6 项是本次的核心收益：以前这些导航只能用鼠标点，键盘、读屏、中键开新标签都拿不到链接语义；现在应全部可用。
- 第 8 项的焦点环是**新增**的（改前这些链接根本不能聚焦，所以没有焦点态），属修复面；请重点看它是否「清楚但不刺眼」。
- 若某项不通过，请附：页面路径、浏览器/桌面端版本、操作顺序、截图或录屏（能复现即可）。

### 技术细节（可略过）

- 分支 `feat/300-nav-a11y-cleanup`；实现 `c22b9424`，用例红基线 `60e5c52e`。
- 规避方式：导航链接改为原生 `router-link` + 既有主题类名（不改 `nue-ui` 组件库；上游问题另立 `nue-ui#108`）。
- 焦点环：`outline: 2px solid var(--nue-primary-color-600); outline-offset: 2px`，仅在 `:focus-visible`（键盘）出现；浅色 5.26–5.74:1 / 暗色 4.43–6.14:1（均 ≥ 3:1）。
- 会话边界：`onSessionBoundary()` 为唯一清除点（登录成功 / 设置页登出 / 桌面解锁门登出 / 跨标签接收 / 桌面初始同步门登出 共 5 处）。
- 优先级：删除无调用点的第二份三档解析（`parseTaskPriority`），判据仍只来自 `prioritySNMap`。
