## 怎么验

**手机（关键）**

1. **AC1a 抽屉里有同步状态** —— 打开左上抽屉 → 底部应看到「同步状态按钮（上）+ 设置齿轮（下）」，两者都点得到。
2. **AC1b 能进设置** —— 点齿轮 → 设置对话框打开 → 「个人资料 / 修改密码 / 应用设置」三个入口在**顶部横排** → 逐个点一遍都能切换 → 能关闭。
3. **AC2 同步面板不溢出** —— 点同步状态按钮 → 面板展开，看得到时间、待推送/失败数量等信息，**不超出屏幕、不被抽屉切掉**。
4. **AC3 窄屏不裁字** —— 若方便，把窗口/字体放大或换一台更窄的手机再看一遍：三个设置入口**不挤成竖排、文字不被截断**。
5. **AC5 一种感觉** —— 同步状态在齿轮**上方**；齿轮样式与桌面侧栏一致，不像"外来件"。

**桌面（回归，重点）**

6. **AC4a 桌面零变化** —— 桌面浏览器打开同一预览 → 左侧竖排侧栏与**改动前完全一致**（同步状态在齿轮上方、齿轮外观不变、设置对话框仍是**左栏竖排**三区）。
7. **AC4b 拉宽拉窄** —— 桌面浏览器把窗口从宽拖到 <445px 再拖回：抽屉出现时两件套在、拖回后桌面侧栏恢复、**不出现两个设置对话框/两个同步按钮**。
