# 数据同步 A 批（v1.17.0）用户走查清单（人工验收）

- 用途：**用户本人**按项勾选；PM/QA 不代执行、不做浏览器自动化截图对比
- 版本：`v1.17.0` A 批（`T320`）· 清单版本：2026-11-03（`T644`）
- 交接来源：`docs/reports/T644-sync-a-batch-verify.md`（自动化复验：26 红全绿 · 4 变异捕获）
- 口径：C 端「说人话」——**看得懂、找得到、敢点**；不是看实现细节

## ⛔ 前置（不满足先别开始）

1. **`A2`「保留服务端」当前存在已知缺陷（P1）**：服务端返回的真实当前行含空数组/空串哨兵，客户端写回时会抛错（点按钮无反应或报错）。**第 3 组需等该缺陷修复后走查**；其余 1、2、4、5、6 组可先做。
    - 证据与红基线：`docs/reports/T644-sync-a-batch-verify.md` §5.4 / `t644-a2-real-server-shape.test.ts`
2. 环境：**本地 dev + 本地后端**（`http://localhost:5173` + `http://localhost:3302/api`），可随便造数据；不要用 Vercel 预览。
3. 请用**两个浏览器配置**（A / B，同一账号）造多端场景；或 A 用「离线」再上线。

## 造冲突的最小步骤（通用）

1. A、B 都登录并完成一次同步（看到数据）。
2. A 断网（或退出登录前先改，模拟离线队列）：把任务「名称」改成 `A-名字`。
3. B 在线：把**同一任务**的「优先级」改成「紧急」并等 2–5 秒让同步跑完。
4. A 恢复网络（或重新登录）触发同步 ⇒ 打开冲突面板（有冲突徽标）。
5. 按下面各组逐项看。
