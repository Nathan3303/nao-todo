## A. 优先级排序

- [ ] **1. 按优先级降序 = 高 → 中 → 低**（AC1）
      操作：打开首页任务列表 → 点表头「**优先级**」列，让列头出现 ↓（降序）。
      预期：顺序为 **高 → 中 → 低**；「没有优先级」的任务与「低」排在一起，**不再**出现「高 → 低 → 中」这种按字母排的错序。
- [ ] **2. 按优先级升序 = 低 → 中 → 高**（AC1 · AC2）
      操作：再点一次「优先级」列头（↑ 升序）。
      预期：顺序整体反过来 **低（含无优先级）→ 中 → 高**；同样优先级的多条任务，来回点两次列头，它们的**相对顺序保持稳定**（不会乱跳）。

## B. 深链（带目标地址的链接）

- [ ] **3. 带目标地址的链接直接落到那个任务**（AC4）
      操作：先正常点开任意一个任务详情 → 复制地址栏整条地址（形如 `.../#/tasks/all/kanban/<任务 id>`）→ 到 设置 → 账户 → **退出登录** → 把刚才复制的地址粘到新标签页打开 → 完成登录。
      预期：登录成功后**直接落在**那条地址的视图，且**该任务的详情面板是打开的**（不是跳到「上次访问的位置」）。
      补充（可选）：保持登录状态下直接打开同一条地址，也应落在该任务。
- [ ] **4. 没有目标地址时回到上次位置**（AC4）
      操作：关掉标签页 → 重新打开预览链根地址（只有 `.../#/`，后面不带具体路径）。
      预期：回到你上次停的那个页面（与以前一致）。

## C. 设置：键盘与读屏

- [ ] **5. 设置左栏可用键盘切分类**（AC7）
      操作：打开设置（侧栏底部齿轮）→ 按 `Tab` 把焦点移到左栏分类（账户 / 外观与语言 / 提醒 / 数据与关于）→ 按 `↓` / `↑` 切换，按 `End` 跳到最后一类、`Home` 回到第一类。若方便，把窗口缩窄到 ≤445px 再用顶部分段切一遍。
      预期：每按一次切一类，右侧内容随之切换；**焦点框跟着移到新分类上**，选中态（底色 + 左侧竖线 + 字重）与焦点始终在同一个分类；窄屏分段切换与以前一致。
- [ ] **6. 改密表单的读屏播报（可选）**（AC6）
      操作：用 VoiceOver（macOS：`Cmd + F5`）或 NVDA（Windows）打开 设置 → 账户 → 密码修改 → 展开表单 → 逐个 `Tab` 到三个密码框。
      预期：读屏分别念出「**旧密码**」「**新密码**」「**确认新密码**」（不是只念「请输入…」，也不会三个都念一样）。
      无读屏环境 → 直接标注「无读屏，跳过」。

## D. 回归抽查（本批不应改动这些行为）

- [ ] **7. 提醒到点仍会弹**（AC8）
      操作：随便建一条任务，把提醒设在 1–2 分钟后 → 等到点。
      预期：应用内提醒照常弹出（若开着系统通知，系统通知也照常）。
- [ ] **8. 日历改期与撤销仍可用**（AC8）
      操作：到日历（月 / 周视图）把某条任务拖到另一天 → 立刻点撤销。
      预期：拖动成功改期；撤销后回到原来的日期，提示与按钮表现与以前一致。
