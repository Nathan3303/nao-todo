## 一、前置

1. **打包**（三平台各自在对应机器上执行；`apps/desktop/package.json` 的 `build` 目标已含 AppImage/deb · nsis · dmg/zip）

    ```bash
    pnpm install
    pnpm run desktop:build          # 先确认能构建
    pnpm run desktop:dist           # 出安装包：apps/desktop/release/
    # 想跳过安装、直接跑解包版：pnpm run desktop:dist:dir
    # 开发态快速看观感（不含安装包行为）：pnpm run desktop:dev
    ```

    - 托盘图标随包走 `resources/tray/`（`build/tray/*`，≤40KB）；**dev 态取源码目录**，观感与打包态一致。

2. **账号与环境**：用**真实账号**登录（会走本地库解锁流程）；准备**至少 2 个任务**（下面 C 组要用通知点击回到任务详情）。
3. **提醒设置**（应用内 设置 → 提醒）：系统通知 **开**、通知声音按喜好、**免打扰关闭**；系统侧允许 NaoTodo 发通知。
4. **探针任务**：建 1 条任务，提醒时间设为「**5 分钟后**」；再建 1 条，提醒时间设为「**10 分钟后**」（用于「点通知回到任务详情」）。
5. 记录 **复现环境**（每组开头填一次）：OS 版本 / 桌面环境（GNOME/KDE/Windows 11/…） / 安装方式（AppImage·deb·nsis·dmg） / 应用版本 `v1.13.0`。

> 回报方式：每组表格勾选 **□通过 / □不通过**，不通过项写「现象 + 证据文件名（截图/录屏）」，并把证据放到
> `docs/reports/evidence/2026-10-25-T545/`（或直接贴在 Issue #254 评论）。

**本机可做的「异常态」模拟法**（Linux；只在需要验证 F-3/F-5/H-1 时用，验完请恢复）：

1. **F-3（GNOME 无扩展 / 可能不显示图标）**：在 GNOME 下**禁用** AppIndicator 扩展（或
   `XDG_CURRENT_DESKTOP=GNOME` 的会话里去掉扩展）后启动应用 ⇒ 应显示「已开启，但可能不显示托盘图标」。
2. **F-5（托盘不可用 / 不支持）**：临时用 `--ozone-platform=wayland` 之外的异常组合不一定能触发；
   更可靠的方式是**临时移走托盘图标文件**再启动（`resources/tray/tray-22.png` 重命名）⇒ `new Tray()` 抛错路径
   ⇒ 设置块应显示「当前环境不支持」；验完恢复文件。
3. **H-1（会话到期）**：在另一台设备/浏览器用同一账号登录，触发会话被顶替（10041）；
   或等服务端把该会话置为失效。**注意**：不要用「清空本地数据」代替（那是另一种路径，判据不同）。

## 十一、已知限制（验收时不算失败）

- **休眠/关机期间不送达**：唤醒后 ≤10s 补弹一次（PRD §二 / R3）。
- **关机/休眠累计 >48h ⇒ JWT 已过期，需重新登录**（会话 7 天绝对期不变，D2）。
- **托盘图标可见性无法程序化判定**：GNOME 无 AppIndicator 扩展时「创建成功但不可见」是**已知**，故有 `unconfirmed` 态与设置页退出入口。
- **Linux 部分 DE 不派发通知点击 action**：点通知可能只唤回窗口、不跳任务详情（D-4）。
- **macOS ad-hoc 签名**：登录项可能登记失败（`DEF-75` B 档）⇒ 走「需系统批准 / 未生效 + 重试」路径，不算失败。
- **卸载/移动安装包后自启条目残留**：Win 指向不存在路径（系统忽略）、Linux `TryExec` 阻止启动（R13）。
- **dev 态**：`pnpm run desktop:dev` 下首次提示可能不显示（R12）。
