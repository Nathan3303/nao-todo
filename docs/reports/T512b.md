## 二、方案选择：为何走「方案 a（恢复类名）」而非「方案 b（删死选择器 + 改测试定位）」

- 用户改后的 CSS 仍以 `.weekstart-label` 为选择器（`color: var(--nue-primary-color-700)`），但模板已无该类 ⇒ 该规则**空转**，标签色退回继承的默认文本色。

- ⚠️ 供用户核对（一行可回退）：恢复类名后 `--nue-primary-color-700` 才真正生效；若用户视觉走查时恰处于「无类名」状态，则当时看到的是继承色。**若用户要的就是继承色 ⇒ 请回一句，我改成方案 b。**
