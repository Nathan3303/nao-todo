## 一、前置（每次走查都一样）

1. **本地 dev（走查唯一载体，⛔ 不用 Vercel 预览）**

    ```text
    cd apps/web && setsid nohup pnpm dev --host 0.0.0.0 > /tmp/webdev.log 2>&1 < /dev/null &
    ```

    访问固定用 **`http://localhost:5173`**（用 `127.0.0.1` 会被后端 CORS 拦）。

2. **本地后端**：`nao-todo-server` 的 `docker compose up -d`（API = `http://localhost:3302/api`，`.env.development` 默认值，**不要**改成生产 API）。
3. **10 秒排障**：`ss -ltn | grep 5173` → `tail -30 /tmp/webdev.log` → 进程是否还在。
4. **数据准备**：登录态有效；至少有 1 个自建清单、1 个标签、1 个带「开始/截止时间」的任务（用于 ⑤ ⑧）、一个头像已上传的账号（用于 ⑥）。

### ⑧ 日期只选日期时，时刻显示为 **00:00**（行为变更）

- **你会看到什么**：给任务选「截止时间」时，如果你**只点了某一天**、没有调整时/分，那么显示出来的时刻是 **00:00**（以前会带上「当前时刻」）。若该任务原本已有时间（从列表/日历带过来的完整时间），点改日期后**时刻保持不变**。
- **操作**：① 新建任务 → 设截止时间 → 只点日期，看触发条与保存后的显示；② 打开一个**已有完整时间**的任务 → 改日期，观察时刻是否保持。
- **期望**：① 只点日期 ⇒ 显示 `00:00`（且保存后仍是该日 00:00）；② 已有完整时间 ⇒ 改日期后**时刻不变**；两种情况下任务不会「莫名挪到别的一天」。
- **对应 AC**：AC7 / R-D（`00:00` 只影响「没给时刻」的输入；本仓正常链路不产生这种输入，故日常使用应感知不到变化）
