## 1. 主路径（AC1 / AC2 / AC5）

### A. 不同字段：一台改标题，另一台改描述/优先级

- **测什么**：两端改**不同**字段时，是否**不产生冲突记录**且两端字段互不覆盖
- **怎么操作**：
    1. 端 1 打开某任务的**编辑**，把「名称」改成 `A-标题`
    2. **在端 2**（无痕窗口）等 / 刷新，把**同一个任务**的「描述」改成 `B-描述`，优先级改成「高」
    3. 两端各触发一次同步（P4），再各刷新一次
- **预期**（全部满足才勾）：
    - [ ] 两端看到**同一条**任务：名称 = `A-标题`、描述 = `B-描述`、优先级 = 高（**三处都在，没有互相覆盖**）
    - [ ] 两端「冲突 N」**都没有增加**
- 对应 AC：AC1 / AC5 ｜ 失败记录：

### B. 同字段冲突：两台都改「描述」

- **测什么**：同字段冲突仍然**可见、可复制、可二选一**；且面板按**字段**呈现（人话标签）
- **怎么操作**：端 1 描述改 `A-描述`；端 2 描述改 `B-描述`；两端触发同步 ⇒ 打开冲突面板
- **预期**：
    - [ ] 面板出现 1 条该任务的冲突记录（两端「冲突 N」各 +1）
    - [ ] 对象信息区有一行「**字段**」，显示**中文标签**（如「描述」），**不出现** `description` 之类英文键名
    - [ ] 「差异详情」能看到两版内容，且可**复制**
    - [ ] 点「**用云端的**」⇒ 本地变成云端那版；点「**保留我的修改**」⇒ 本地保留我的版本（两种都试一次，可用另一个任务分别验）
- 对应 AC：AC5 / AC9（R-7 文案）｜ 失败记录：

### C. 标签并集：两端各加一个标签

- **测什么**：集合合并**不丢**
- **怎么操作**：端 1 加标签 `#工作`；端 2 加标签 `#紧急`；两端触发同步
- **预期**：
    - [ ] 两端该任务标签 = `#工作` + `#紧急`（**两个都在**，无重复）
    - [ ] 无新增冲突记录

### D. 提醒组：两端分别改提醒相关设置

- **测什么**：提醒四个字段**按组原子**，不产出「我的时刻 + 对方的重复」这类混搭
- **怎么操作**：端 1 设提醒「重复=每天 / 时刻 08:00」；端 2 设「重复=每周 / 星期 1,3,5」；两端触发同步
- **预期**：
    - [ ] 面板「字段」行显示**四个**中文标签：提醒时间 / 提醒重复 / 提醒时刻 / 提醒星期（不缺项）
    - [ ] 两端该任务的提醒设置是**同一套完整组合**（要么全是我这侧、要么全是对方那侧），**不出现混搭**
- 对应 AC：AC2 / AC15（提醒组）｜ 失败记录：

### E. 删除 vs 改字段并发

- **测什么**：删除优先，且**不产生「我的修改已覆盖云端」类假账**
- **怎么操作**：端 1 删除某任务；**同一时间**端 2 把该任务的描述改掉；两端触发同步
- **预期**：
    - [ ] 该任务在两端都被删除（不会因字段合并在任一端「复活」）
    - [ ] 端 2 看到的是**「已被删除」**类提示，而**不是**「我的修改已覆盖云端」
    - [ ] 若面板出现记录，其类型文案是「云端最新 / 已删除」这类**如实描述**，不是「我覆盖了云端」
