# 2026-10-07 搜索筛选栏细化 ADR —— `includeExcluded` 移除与下拉项间隙全局收紧

- **日期**：2026-10-07（评审终签日）
- **状态**：✅ 已采纳（PM 2026-10-07 采纳评审结论；实现随 `T505` / Issue #181）
- **任务 / 范围**：`T505`（PRD §5 ① ③）；②④ 属纯展示层，不在本 ADR。
- **硬约束**：不改服务端契约 · 移动端零改动（`packages/presentation-react` / `apps/mobile`）· 不新增 `nue-*` token / 组件。

## 1. 背景（≤5 行）

- `includeExcluded` 是**纯客户端**能力（UI 开关 + URL `?excluded=1` + localStorage 常用搜索字段），改的是**客户端持久契约字段**，非服务端契约。
- 该开关在组件层**无可见文字**（`NueSwitch` 静默丢弃默认插槽），且与「已删除任务不该被搜到」直觉冲突 ⇒ PRD 决定彻底移除。
- ③ 间隙取自主题 `.nue-dropdown--menu > .nue-div--block { gap: var(--nue-gap-xs) }`，PRD 拟全局收紧一档；待裁定 ① 兼容口径与 ③ 收紧范围。

## 2. 决策（1–3 句）

1. **① 彻底移除 `includeExcluded`**（UI + 引擎 + URL + 常用搜索 / 快捷预置 + i18n 死键 + 测试）；兼容口径 = **旧字段一律忽略、不报错、无迁移、不回写**。
2. **③ 全局**把 `apps/web/src/themes/dropdown.css` 的 `--menu > .nue-div--block` `gap: var(--nue-gap-xs) → var(--nue-gap-2xs)`（保留 `padding: 0`），**不做搜索栏局部覆盖**。

## 3. 理由（四步法要点，每点一行）

1. **业务匹配**：① 消除不可理解开关 + 与「搜索结果不含已删除」一致；③ 满足 AC4「任务 / 日历 / 搜索三处下拉观感一致」。
2. **技术成熟度**：改动落在**仓内可单测纯函数 + 一层 CSS 覆盖**，无新机制。
3. **团队能力**：无新概念；②④ 由展示层独立承接。
4. **成本效益**：① 净删码、无迁移；③ 一行 CSS；两者均无服务端 / 移动端波及。

## 4. 对照模式（模式 → 适用条件 → 代价 → 不采纳理由）

- **① 彻底移除 + 忽略旧字段**（**采纳**）：适用 = 能力确认退役、旧数据允许静默忽略；代价 = 旧 URL 残留惰性 `?excluded=1`（不报错、结果正确）。
- **① 中间态「保留 URL 解析但恒 `false`」**（不采纳）：适用 = 近期可能快速回滚；代价 = 保留死常量 / 死测试 + 误导路径。**不采纳理由：不改善兼容（与移除同为忽略）却留误导性死路径**。
- **① 维持现状（保留开关）**（不采纳）：适用 = 能力仍需可达；代价 = 两个无文字开关不可理解。**不采纳理由：与用户裁定（移除）冲突**。
- **③ 全局覆盖 `.nue-dropdown--menu` gap**（**采纳**）：适用 = AC4 要求全站一致；代价 = 波及 7 组件 11 处，需视觉走查对照。
- **③ 搜索栏局部覆盖**（不采纳）：适用 = 仅搜索页需变；代价 = 任务 / 日历下拉与搜索不一致。**不采纳理由：直接违反 AC4**。
- **③ 维持现状 `--nue-gap-xs`**（不采纳）：适用 = 现观感可接受；代价 = 间隙偏松、未满足用户要求。**不采纳理由：与用户要求冲突**。

## 5. 关键事实（评审纠正）

- **影响面更正**：`theme="menu"` 共 13 处，其中 **2 处是 `nue-collapse--menu`**（`calendar/aside`、`search/aside`），**不含 `.nue-dropdown` 类、不被该选择器命中** ⇒ 实际受影响 = **7 组件 / 11 处**。
- **无布局假设被破坏**：改动只作用于容器直接子项间距；项高 / 点击区由 `.nue-dropdown-item { height: var(--nue-box-size-*) }` 独立决定，项内图标↔文字 `gap` 是另一条选择器；覆盖生效依赖 `themes/index.ts` 先引上游主题（L2）后引本地 `dropdown.css`（L15）。
- **无服务端契约变更**：`includeExcluded` 不在 `GetTasksOptions` / infrastructure / 服务端；引擎排除靠 `buildRootQuery` 的 `isDeleted` / `isGivenUp` 变体。

## 6. 后果与风险

- **正面**：① 净删死码 + 消除无文字开关；③ 一行改动达成全站一致。
- **负面 / 风险与缓解**：① 旧 URL 残留惰性 `?excluded=1`（不清理、不写回、无迁移副作用）；③ 7 组件 11 处观感变化（含标题 / 分隔线间距），列入用户视觉走查清单按 7 组件对照。
