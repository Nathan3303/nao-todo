# B. 真实浏览器命中抽检（AC10 / ADR C12）

**为什么必须做**：本批「任务条拖不动」的根因是**覆盖层吞掉命中**，而 **jsdom 用例绕过命中测试 ⇒ 恒绿**，只有真实浏览器能发现。

在 DevTools Console 里粘这段（先确保日视图有至少 1 个日内任务条）：

```js
const bar = document.querySelector('.day-seg .cal-item')
const r = bar.getBoundingClientRect()
const at = (x, y) => {
    const e = document.elementFromPoint(x, y)
    return e ? e.className : null
}
console.log('bar-mid  =', at(r.left + r.width / 2, r.top + r.height / 2))
console.log('bar-left =', at(r.left + 2, r.top + r.height / 2))
console.log('blank    =', at(r.left + r.width + 40, r.top + r.height + 40))
```

| #   | 期望                                                              |
| :-- | :---------------------------------------------------------------- |
| B1  | `bar-mid` 与 `bar-left` 命中**任务条**（className 含 `cal-item`） |
| B2  | `blank` 命中空白层（**不含** `cal-item`）                         |

> 只要 `bar-mid` 命中任务条，A2-1「能拖」就有了机械证据；若命中空白/其它层，说明又有覆盖层吞命中，直接报我。
