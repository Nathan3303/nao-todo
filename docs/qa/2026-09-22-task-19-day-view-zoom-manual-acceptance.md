## A. 缩放入口（三个入口都要能用）

| #   | 操作                                               | 期望                                                                   |
| :-- | :------------------------------------------------- | :--------------------------------------------------------------------- |
| A1  | 看头部控制条右组                                   | 出现 `−` / `+` 两个图标按钮；**没有**额外的「复位」按钮                |
| A2  | 连点 `+`                                           | 档位逐级 ×1 → ×1.5 → ×2 → ×3 → ×4；到达 ×4 后 `+` 变灰不可点           |
| A3  | 连点 `−`                                           | 逆向逐级回到 ×1；到达 ×1 后 `−` 变灰不可点                             |
| A4  | 按 `Ctrl/⌘ +` / `Ctrl/⌘ −`                         | 与按钮等效                                                             |
| A5  | 按 `Ctrl/⌘ 0`                                      | 无论当前第几档，**直接回 ×1**                                          |
| A6  | 鼠标在**时间轴区域**内 `Ctrl/⌘ + 滚轮` 上滚 / 下滚 | 上滚放大一档、下滚缩小一档；**不触发浏览器页面缩放**（页面整体不缩放） |
| A7  | 鼠标在时间轴区域**普通滚轮**（不带 `Ctrl/⌘`）      | 只做滚动，**不改变档位**                                               |

## B. 刻度与视觉（核心变化）

| #   | 操作                                  | 期望                                                                                                     |
| :-- | :------------------------------------ | :------------------------------------------------------------------------------------------------------- |
| B1  | ×1 档                                 | **与改动前一致**：时间轴铺满、**无横向滚动条**、列头只有整点文本（形如 `09`，共 24 个）                  |
| B2  | ×2 档                                 | 出现**半点标签**（形如 `09:30`，共 48 个）；时间轴总宽约为容器宽 **2 倍** ⇒ 出现横向滚动条               |
| B3  | ×4 档                                 | 粒度为 **10 分钟**（标签仍为整点/半点 `HH:MM`，共 48 个）；总宽约为容器宽 **4 倍**；任务条标题明显更好读 |
| B4  | ×1 → ×4 观察任务条本身                | **任务条的字号、行高不随缩放变化**（变的是时间尺度和可读性，不是条本身）                                 |

## I. 已知可接受（**不算缺陷，无需报**）

1. **×4 档下吸附仍按 30 分钟**：拖动落点会「跳」到 30 分钟刻度 —— 这是 ADR §3-D2 的**有意裁决**（吸附是手势量化，与视觉缩放解耦；同一手势在任何档位落到同一时间）。若你仍觉得「放大后落点太粗」，我另立单改吸附量子（30 → 15）。
2. **首次切换可能极短延迟**：三视图为路由级懒加载，偶有 chunk 加载等待（非白屏）。
3. **日视图按 `n` 无可见效果**：TASK-18 遗留 INFO-1（日视图以「点击轨道定位」为新建入口），本轮未处理。
4. **切视图后「返回」回不到切换前 URL**：TASK-18 D2 已拍板的 `replace` 代价。
