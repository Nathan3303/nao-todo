### A2 `DEF-119` 三分判据（60s 窗口 / 复位）

**判据现状**（`check-in.vue:79-92` + `checkin-window.ts:79-104`）：

| 场景                                       | 文案                            | 主按钮   |
| :----------------------------------------- | :------------------------------ | :------- |
| `10022` + token 已过期                     | `conflictExpired`               | 重新登录 |
| `10022` + 未过期 + 第 1 次（60s 内计数=1） | `conflictRevoked`（含「密码」） | 重新登录 |
| `10022` + 未过期 + 第 2+ 次（60s 内）      | `conflictConcurrent`            | **重试** |
| token 缺失/不可解析                        | `conflict`（不猜）              | 重试     |

**① 反向误判：成立（PM 的担心是对的）。** 真撤销场景下用户点一次「重试」⇒ 计数=2 ⇒ 文案变「短时间内多次验证未完成」、**主按钮降级为「重试」**（`t596` 用例 `AC7 短时并发` 本身即断言这一行为）⇒ 用户被引导进重试循环；只有**空闲 60s** 后窗口过期才回到「密码可能被改」。判据方向与其理由相反：`AuthUseCase.resolveCheckInConflict` 在用例层**已自动重试一次**（≥300ms；token 已变即放弃）⇒ 走到页面的 `10022` 通常已吸收掉「真并发」；**用户手动再试仍得 `10022`，本该提高「非并发」的置信度**，而不是降低。

**② 复位：缺失。** `resetCheckInWindow()` 全仓**仅测试调用**（`grep` 4 处全在 `__tests__`）；检入**成功**、页面**卸载**、**登出/换账号**均不清 `conflictStreak` ⇒ 与 `checkin-window.ts:90` 注释「同一个检入页生命周期内」**不符**（实现是模块级全局 + 纯时间窗）。另注：`resetCheckInWindow()` 会同时把 `inFlight/planned` 归零 ⇒ **不可**直接用于生产（会关掉 T558 的「在途 10041 延后处置」），需单开 `resetCheckInConflictStreak()`。

**建议**（不属本批产品改动，交 PM 裁定）：窗口收窄到 **2–5s**（真并发在同一 tick/刷新内），或改用「并发证据」（两次 `10022` 对应**并行**请求）而非「用户点了重试」；若保留降级，也**不要**把主按钮从「重新登录」改成「重试」。

### A4 `DEF-117` 棘轮 + `lynx.ts` 语义

**① 常量确实下调，不是删断言**：`auth-seam-scan.test.ts:83-100` 现为 `persistence-go: 0` / `lynx.ts: 1` / `KNOWN_CREDENTIAL_LITERAL_COMPARISONS = 0`，断言用 `toBe(...)`（**双向**：多一处红、少一处未同步下调也红）。棘轮文件被 `t596-def117` 以「必须仍含 `lynx.ts`」反向锁住 ⇒ 不会被无声删除。

**② `lynx.ts`：`=== 10041` → `isCredentialCode`（含 `10042`）**

- 与 ADR D6 **一致**（D6 原文：`isSessionExpiredCode` 改用 D1 判据（纳入 `10042`）），也与 axios 侧 `isCredentialCode` 同语义。
- 服务端 `10042` = JWT 校验通过但 `userId <= 0`（`nao-todo-server/interfaces/middlewares/jwtValidator.go:70/78`）⇒ 同属「凭证不可用」，触发登出**合理**，未发现行为回归（非凭证失败仍不登出）。
- ⚠️ **需知会**：`lynx.ts` 被 `apps/mobile/src/App.tsx:71` 使用 ⇒ 这是**移动端运行时语义变化**（移动端现在也会因 `10042` 触发 `onAuthExpired`）；PRD 表头写「`lynx.ts` 除外需授权」⇒ 建议在台账补一句授权/知会留痕（红线文件 0 改动成立）。
- 棘轮小缺口：正则只覆盖 `10041`，`=== 10042` 字面量不在内（当前 0 处）；建议扩为 `(===|!==)\s*1004[12]\b`。
